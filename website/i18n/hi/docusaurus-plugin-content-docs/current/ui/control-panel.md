# निचला पैनल

Rayforge विंडो के नीचे का निचला पैनल आपके लेज़र कटर की स्थिति पर मैन्युअल नियंत्रण, वास्तविक समय की
मशीन स्थिति, ऑपरेशनों की निगरानी के लिए लॉग दृश्य, और एक G-code व्यूअर देता है.

## अवलोकन

निचला पैनल कई फ़ंक्शन एक सुविधाजनक इंटरफ़ेस में जोड़ता है:

1. **टैब्ड दृश्य**: बाईं ओर की आइकन पट्टी का उपयोग करके Console और G-code Viewer के बीच स्विच करें
2. **जॉग नियंत्रण**: मैन्युअल गति और स्थापना (हमेशा दिखाई देते हैं)
3. **मशीन स्थिति**: वास्तविक समय की स्थिति और कनेक्शन अवस्था
4. **वर्क निर्देशांक प्रणाली (WCS)**: त्वरित WCS चयन (हमेशा दिखाई देता है)

पैनल की बाईं ओर एक टैब आइकन पट्टी है जो आपको **Console** और **G-code Viewer** के बीच स्विच करने देती
है. दाईं ओर के जॉग नियंत्रण और WCS नियंत्रण किसी भी टैब सक्रिय होने पर दिखाई देते रहते हैं.

![निचला पैनल](/screenshots/bottom-panel-console.webp)

## निचले पैनल तक पहुँच

निचला पैनल मुख्य विंडो के नीचे हमेशा दिखाई देता है. इसे टॉगल किया जा सकता है:

- **मेनू**: View → Bottom Panel
- **कीबोर्ड शॉर्टकट**: Ctrl+L

<!-- prettier-ignore-start -->
:::note[कनेक्शन आवश्यक]
जॉग नियंत्रण केवल तब उपलब्ध होते हैं जब जॉगिंग ऑपरेशन समर्थन करने वाली मशीन
से कनेक्टेड हों.
:::
<!-- prettier-ignore-end -->

## जॉग नियंत्रण

जॉग नियंत्रण आपके लेज़र कटर की स्थिति पर मैन्युअल नियंत्रण देते हैं, जिससे आप सेटअप, संरेखण, और
परीक्षण उद्देश्यों के लिए लेज़र हेड को सटीक रूप से खिसका सकें.

### होमिंग नियंत्रण

संदर्भ स्थिति स्थापित करने के लिए अपनी मशीन के अक्ष होम करें:

| बटन      | फ़ंक्शन      | विवरण                                   |
| -------- | ------------ | --------------------------------------- |
| Home X   | X अक्ष मूल   | X अक्ष को उसकी मूल स्थिति पर ले जाता है |
| Home Y   | Y अक्ष मूल   | Y अक्ष को उसकी मूल स्थिति पर ले जाता है |
| Home Z   | Z अक्ष मूल   | Z अक्ष को उसकी मूल स्थिति पर ले जाता है |
| Home All | सभी अक्ष मूल | सभी अक्ष एक साथ मूल पर ले जाता है       |

<!-- prettier-ignore-start -->
:::tip[होमिंग अनुक्रम]
सटीक स्थापना सुनिश्चित करने के लिए कोई भी जॉब शुरू करने से पहले सभी अक्ष
मूल पर ले जाने की अनुशंसा की जाती है.
:::
<!-- prettier-ignore-end -->

### दिशात्मक गति

जॉग नियंत्रण दिशात्मक गति के लिए बटन देते हैं:

```
  ↖  ↑  ↗
  ←  •  →
  ↙  ↓  ↘
```

| बटन             | गति                            | कीबोर्ड शॉर्टकट |
| --------------- | ------------------------------ | --------------- |
| ↑               | Y+ (Y- यदि मशीन Y-फ़्लिप्ड हो) | ऊपर का ऐरो      |
| ↓               | Y- (Y+ यदि मशीन Y-फ़्लिप्ड हो) | नीचे का ऐरो     |
| ←               | X- (बाएँ)                      | बायाँ ऐरो       |
| →               | X+ (दाएँ)                      | दायाँ ऐरो       |
| ↖ (ऊपरी-बायाँ)  | X- Y+/- (तिरछा)                | -               |
| ↗ (ऊपरी-दायाँ)  | X+ Y+/- (तिरछा)                | -               |
| ↙ (निचला-बायाँ) | X- Y-/+ (तिरछा)                | -               |
| ↘ (निचला-दायाँ) | X+ Y-/+ (तिरछा)                | -               |
| Z+              | Z अक्ष ऊपर                     | Page Up         |
| Z-              | Z अक्ष नीचे                    | Page Down       |

<!-- prettier-ignore-start -->
:::note[फ़ोकस आवश्यक]
कीबोर्ड शॉर्टकट केवल तब काम करते हैं जब मुख्य विंडो फ़ोकस में हो.
:::
<!-- prettier-ignore-end -->

### दृश्य प्रतिक्रिया

जॉग बटन दृश्य प्रतिक्रिया देते हैं:

- **सामान्य**: बटन सक्षम और उपयोग के लिए सुरक्षित है
- **चेतावनी (नारंगी)**: गति सॉफ़्ट लिमिट के पास या उनसे बाहर जाएगी
- **अक्षित**: गति समर्थित नहीं या मशीन कनेक्ट नहीं है

### जॉग सेटिंग्स

जॉग ऑपरेशनों का व्यवहार कॉन्फ़िगर करें:

**जॉग गति:**

- **सीमा**: 1-10,000 mm/min
- **डिफ़ॉल्ट**: 1,000 mm/min
- **उद्देश्य**: नियंत्रित करता है कि लेज़र हेड कितनी तेज़ चले

<!-- prettier-ignore-start -->
:::tip[गति चयन]
- सटीक स्थापना के लिए कम गतियाँ (100-500 mm/min) उपयोग करें
- बड़ी गतियों के लिए अधिक गतियाँ (1,000-3,000 mm/min) उपयोग करें
- बहुत अधिक गतियाँ कुछ मशीनों पर छूटे स्टेप कारण बन सकती हैं
:::
<!-- prettier-ignore-end -->
