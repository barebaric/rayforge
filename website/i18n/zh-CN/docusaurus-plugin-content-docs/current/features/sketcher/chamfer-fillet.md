# 倒角与圆角

草图绘制器提供两种修改两条线相交角落的工具：

- **倒角**（`C+H`）：用斜切边替换尖角。
- **圆角**（`C+F`）：用圆滑边替换尖角。

![倒角矩形与圆角矩形对比](/screenshots/addons-sketcher-tool-chamfer-fillet.webp)

要应用其中一种工具：

1. 选择恰好有两条线相交的连接点。
2. 按 `C+H` 应用倒角或按 `C+F` 应用圆角，或从饼形菜单中选择工具。

角会在一步之内被替换。两条线被修剪，新的边插入其间，同时会创建保持
修剪后的线段与原线段共线、并保持角对称的约束。倒角的斜切长度默认为
较短邻线的一部分；圆角的弧半径会自动选择以适配。之后拖动插入边的
端点即可调整其大小，约束会保持角完好无损。
