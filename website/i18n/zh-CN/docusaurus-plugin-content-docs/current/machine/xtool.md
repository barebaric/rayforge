# xTool Wi-Fi

Rayforge 包含用于通过 Wi-Fi 连接的 xTool 机器的实验性驱动程序。它们使用 xTool 的专有网络 API，
而不是 GRBL Telnet 或 FluidNC / ESP3D 接口，因此必须使用机器自带的 xTool 驱动程序进行设置。

## 支持的机器

| 配置             | 驱动程序         | 功能                                                             |
| ---------------- | ---------------- | ---------------------------------------------------------------- |
| **xTool D1 Pro** | xTool (Wi-Fi)    | 上传并启动作业、回零、点动、暂停、继续和取消                     |
| **xTool M2**     | xTool M2 (Wi-Fi) | 监控机器、回零、点动，以及暂停、继续或取消已在机器上准备好的作业 |

两个驱动程序都标记为 **实验性**。在依赖它们进行生产之前，请先用边角料测试，并在报告问题时附上
调试日志。

## 设置 xTool 机器

1. 将机器连接到与计算机相同的网络，并找到它的 IP 地址（例如在 xTool 应用中或路由器的设备
   列表里）。
2. 添加机器并选择 **xTool D1 Pro** 或 **xTool M2** 配置。该配置已经预设了驱动程序和机器尺寸。
3. 输入机器的 **主机名或 IP 地址**。
4. 除非网络环境另有要求，否则保持默认端口：
   - D1 Pro：HTTP 端口 `8080`，WebSocket 端口 `8081`
   - M2：端口 `28900`
5. 连接。

如果 Rayforge 提示没有 xTool 机器响应，请检查 IP 地址、机器是否已开机，以及计算机和机器是否在
同一网络中。

## D1 和 D1 Pro

**xTool (Wi-Fi)** 驱动程序会把作业上传到机器、启动作业，并通过 WebSocket 作业事件跟踪进度。
回零、点动和绝对移动、暂停、继续和取消均可正常使用。

机器的网络 API 不报告位置，因此 Rayforge 根据作业状态驱动位置显示。回零仅支持所有轴同时回零，
单轴回零已禁用。此驱动程序不支持写入固件设置、工件坐标偏移和探测。

## xTool M2

**xTool M2 (Wi-Fi)** 驱动程序连接到 M2 在端口 `28900` 上的 TLS 服务。它监控机器状态，并支持回
零、点动，以及暂停、继续或取消已在机器上准备好的作业。

M2 的网络 API 尚不能接收 G-code，因此 Rayforge 无法向它发送自己的作业。请在 xTool Studio 中
准备作业并在那里启动，然后使用 Rayforge 进行监控和控制。不支持 Z 轴移动、换刀、远程激光功率
控制、固件设置和工件坐标偏移。

## TLS 证书

M2 驱动程序会验证机器的 TLS 证书。如果机器使用自签名证书，请在驱动程序设置中启用
**允许无效的 TLS 证书**。只应在你信任的网络上这样做。
