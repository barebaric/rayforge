# Штрихкоди

Додаток «Штрихкоди» додає QR-коди та штрихкоди як робочі елементи. Вони малюються як векторні
контури із заливкою, тому операція Гравіювання гравіює їх чисто, а операція Контур усе одно може їх
обвести.

## Додавання штрихкоду

Виберіть **Об'єкт - Додати штрихкод**. У центрі робочої області з'являється QR-код, і він виділений.
Редагуйте його в групі **Штрихкод** панелі властивостей:

- **Вміст** — текст для кодування. Натисніть `Enter` або кнопку застосування, щоб оновити код.
- **Тип** — QR-код, Code 128 або EAN-13.
- **Корекція помилок** (QR) — яку частину коду може бути пошкоджено, щоб він усе ще читався: Низька,
  Середня, Квартиль або Висока. Вищі рівні роблять код більшим.
- **Розмір модуля** — ширина найвужчої смуги або одного квадрата QR. Розмір модуля та висота смуг
  показуються у вибраній вами одиниці довжини. Робочий елемент набуває розміру коду, тож саме цей
  параметр задає розмір.
- **Висота смуг** (Code 128, EAN-13) — висота смуг.
- **Показувати текст** (Code 128, EAN-13) — друкує вміст під смугами. EAN-13 використовує звичне
  компонування, у якому обмежувальні смуги заходять між цифрами.
- **Інвертувати** — гравіює натомість світлі частини, для темного матеріалу: код стає світлим на
  темній рамці. **Тиха зона** задає цю рамку в модулях і змінюється лише тоді, коли **Інвертувати**
  увімкнено; за замовчуванням це мінімум, потрібний для типу.

Залишайте вільне поле навколо неінвертованого коду: 4 модулі для QR-кодів, 10 для Code 128 і 9 для
EAN-13.

## Типи

- **QR-код** містить будь-який текст, зокрема посилання.
- **Code 128** містить друковані символи ASCII. Послідовності цифр автоматично пакуються парами.
- **EAN-13** приймає 12 цифр, контрольна цифра додається. З 13 цифрами контрольна цифра
  перевіряється. Поле вмісту стає червоним, коли вміст не підходить для типу; наведіть на нього
  курсор, щоб побачити причину.

## Шаблони

Вміст може містити вирази `{...}`, як текстовий блок, наприклад `{2 * 21}`. З
[Лічильником завдань](../features/job-counter.md) `SN-{counter:05d}` дає кожній деталі власний
номер, а копії масиву продовжують відлік.
