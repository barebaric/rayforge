# Параметричний 2D-ескізер

Параметричний 2D-ескізер — це потужна функція Rayforge, яка дозволяє створювати
та редагувати точні двовимірні проекти на основі обмежень безпосередньо в
програмі. Ця функція дає змогу проектувати власні деталі з нуля без необхідності
в зовнішньому програмному забезпеченні САПР.

## Огляд

Ескізер надає повний набір інструментів для створення геометричних фігур та
застосування параметричних обмежень для визначення точних зв'язків між
елементами. Такий підхід гарантує, що ваші проекти зберігатимуть бажану
геометрію навіть після зміни розмірів.

## Створення та редагування ескізів

### Створення нового ескізу

1. Відкрийте нижню панель і натисніть кнопку **Новий ескіз**, або
   клацніть правою кнопкою миші на полотні та виберіть **Новий ескіз**
   у контекстному меню.
2. Відкриється новий порожній робочий простір з інтерфейсом редактора ескізів
3. Почніть створювати геометрію за допомогою інструментів малювання з
   кругового меню або клавіатурних скорочень
4. Застосуйте обмеження для визначення зв'язків між елементами
5. Натисніть «Завершити ескіз», щоб зберегти роботу та повернутися до
   основного робочого простору

### Редагування наявних ескізів

1. Двічі натисніть на заготовку на основі ескізу в основному робочому просторі
2. Або виберіть ескіз і натисніть «Редагувати ескіз» у контекстному меню
3. Внесіть зміни за допомогою тих самих інструментів та обмежень
4. Натисніть «Завершити ескіз», щоб зберегти зміни, або «Скасувати ескіз»,
   щоб відкинути їх

## Поради щодо робочого процесу

1. **Починайте з грубої геометрії**: Спочатку створіть базові форми, а потім
   уточнюйте за допомогою обмежень
2. **Застосовуйте обмеження заздалегідь**: Застосовуйте обмеження під час
   побудови, щоб зберегти задум проекту
3. **Перевіряйте стан обмежень**: Система показує, коли ескізи повністю
   обмежені
4. **Слідкуйте за конфліктами**: Обмеження, що конфліктують між собою,
   підсвідчуються червоним і відображаються на панелі обмежень для зручного
   визначення
5. **Використовуйте симетрію**: Обмеження симетрії можуть значно прискорити
   створення складних проектів
6. **Використовуйте сітку**: Увімкніть сітку для точного вирівнювання та
   використовуйте Ctrl для прив'язки до сітки
7. **Ітеруйте та уточнюйте**: Не соромтеся змінювати обмеження для досягнення
   бажаного результату

## Можливості редагування

- **Повна підтримка скасування/повторення**: Повний стан ескізу зберігається
  з кожною операцією
- **Динамічний курсор**: Курсор змінюється відповідно до активного інструменту
  малювання
- **Візуалізація обмежень**: Застосовані обмеження чітко позначені в
  інтерфейсі
- **Оновлення в реальному часі**: Зміни обмежень негайно оновлюють геометрію
- **Редагування подвійним натисканням**: Подвійне натискання на розмірних
  обмеженнях (Відстань, Радіус, Діаметр, Кут, Співвідношення сторін) відкриває
  діалогове вікно для редагування їхніх значень
- **Параметричні вирази**: Розмірні обмеження підтримують вирази, що дозволяє
  обчислювати значення з інших параметрів (наприклад, `width/2` для радіуса,
  що дорівнює половині ширини)
