# 矩形与圆角矩形

草图绘制器提供两种共享相同手势和修饰键的矩形工具：**矩形**工具
（`G+R`）和**圆角矩形**工具（`G+O`）。

![一个矩形和一个圆角矩形](/screenshots/addons-sketcher-tool-rectangle.webp)

## 绘制矩形

通过指定两个对角来绘制矩形，或在第一个角按下、拖动并在对角释放。
修饰键对两种工具的作用相同：

- 按住 `Shift` 可让矩形围绕起点对称放置。
- 按住 `Ctrl` 可将其约束为正方形。

每个矩形都会自动创建一个约束在几何中心上的**中心点**，因此你可以对
形状的中部进行尺寸标注或捕捉。

预览处于活动状态时，你可以输入精确尺寸：状态栏会显示 `W` 和 `H`
字段（圆角矩形还会显示角半径的 `R`）。输入数值，按 `Tab` 在字段
之间切换，按 `Enter` 应用。两种工具都同样接受两次点击和点击拖动
手势；`Esc` 可取消预览。

圆角矩形的角半径之后也可以通过编辑其约束来更改——角是完全受约束
的，因此半径始终保持可调。
