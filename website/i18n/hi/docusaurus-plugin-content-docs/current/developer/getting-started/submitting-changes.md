# बदलाव सबमिट करना

यह गाइड Rayforge में कोड सुधार योगदान देने की प्रक्रिया कवर करती है.

## फ़ीचर शाखा बनाएँ

अपने बदलावों के लिए एक वर्णनात्मक शाखा बनाएँ:

```bash
git checkout -b feature/your-feature-name
# or
git checkout -b fix/issue-number-description
```

## अपने बदलाव करें

- मौजूदा कोड शैली और परंपराओं का पालन करें
- स्पष्ट संदेशों के साथ साफ़, केंद्रित कमिट करें
- नई कार्यक्षमता के लिए परीक्षण जोड़ें
- आवश्यकता अनुसार दस्तावेज़ीकरण अपडेट करें

## अपने बदलावों का परीक्षण करें

कुछ भी टूटा न हो सुनिश्चित करने के लिए पूर्ण परीक्षण सूट चलाएँ:

```bash
# Run all tests and linting
pixi run test
pixi run lint
```

## अपस्ट्रीम के साथ सिंक करें

पुल अनुरोध बनाने से पहले, अपस्ट्रीम रिपॉज़िटरी के साथ सिंक करें:

```bash
# Fetch the latest changes
git fetch upstream

# Rebase your branch on the latest main
git rebase upstream/main
```

## पुल अनुरोध सबमिट करें

1. अपनी शाखा अपने फ़ोर्क पर पुश करें:

   ```bash
   git push origin feature/your-feature-name
   ```

2. GitHub पर एक पुल अनुरोध बनाएँ जिसमें:
   - बदलाव वर्णित करने वाला एक स्पष्ट शीर्षक
   - आपने क्या और क्यों बदला इसका एक विस्तृत विवरण
   - किसी भी संबंधित समस्या का संदर्भ
   - यदि बदलाव UI को प्रभावित करता है तो स्क्रीनशॉट

## कोड समीक्षा प्रक्रिया

- सभी पुल अनुरोधों को मर्ज होने से पहले समीक्षा चाहिए
- प्रतिक्रिया पर तुरंत कार्य करें और अनुरोधित बदलाव करें
- चर्चा को केंद्रित और रचनात्मक रखें

## मर्ज आवश्यकताएँ

पुल अनुरोध तब मर्ज होते हैं जब वे:

- [ ] सभी स्वचालित परीक्षण पास करते हैं
- [ ] परियोजना की कोडिंग शैली का पालन करते हैं
- [ ] नई कार्यक्षमता के लिए उपयुक्त परीक्षण शामिल करते हैं
- [ ] आवश्यकता होने पर दस्तावेज़ीकरण अपडेट रखते हैं
- [ ] कम से कम एक अनुरक्षक द्वारा स्वीकृत हों

## अतिरिक्त दिशानिर्देश

### कमिट संदेश

स्पष्ट, वर्णनात्मक कमिट संदेश उपयोग करें:

- बड़े अक्षर से शुरू करें
- पहली पंक्ति 50 वर्णों से कम रखें
- आज्ञार्थ भाव उपयोग करें ("Add feature", "Added feature" नहीं)
- आवश्यकता होने पर मुख्य भाग में अधिक विवरण शामिल करें

### छोटे, केंद्रित बदलाव

पुल अनुरोधों को एकल सुविधा या ठीक पर केंद्रित रखें. बड़े बदलाव छोटे, तार्किक टुकड़ों में तोड़े जाने
चाहिए.
