# 刀具切割

Rayforge 除了激光器之外也可以驱动刀具架。两个内置步骤使用刀具切割矢量轮廓：**拖刀切割**用于
拖刀刀架，**切向刀切割**用于电机驱动的旋转刀片。刀具步骤只会出现在装有匹配刀具机头的机器上，
因此同一台机器可以在同一个项目中混合激光和刀具操作。

## 要求

- 装有 **拖刀** 或 **切向刀** 机头的机器。在
  [机器设置 → 机头](../machine/general.md) 中通过 **添加新机头** 添加机头。
- 能够在不使用激光的情况下移动机器的 G-code 控制器。刀具步骤沿中心线切割，不使用激光功率。
- 内置的 Drag Knife 插件。它随 Rayforge 一起提供；如果已被禁用，请在 **设置 → 插件** 中启用。

## 设置刀具机头

1. 打开 **机器 → 当前机器设置 → 机头**。
2. 点击 **添加新机头**，选择 **拖刀** 或 **切向刀**。
3. 为机头命名。对于拖刀，输入 **刀片偏移**：刀尖到机器旋转中心之间的距离。
4. 关闭设置。添加操作时就会提供相应的刀具步骤。

刀具机头也是一种机器能力：需要刀具的操作只有在当前机器装有相应机头时才可用。

## 拖刀切割

拖刀的刀片跟在旋转中心后面。Rayforge 会自动补偿偏移，使刀片沿轮廓而不是旋转中心移动。

1. 选择要切割的轮廓。
2. 添加一个 **拖刀切割** 操作。
3. 选择 **刀具** 机头，并设置 **刀片偏移**、**安全 Z 高度**、**旋转角度** 和切割速度。

![拖刀切割设置](/screenshots/step-settings-drag-knife-general.webp)

该步骤会把每个轮廓重写为机器实际需要走的路径：切入圆弧让刀片对准初始切割方向，直线段向前
偏移刀片偏移量，旋转角度以内的拐角在刀片放下时转过去，更尖的拐角先抬起刀片在空中转向，切出
圆弧再越过路径末端。

根据刀架文档设置 **刀片偏移** 或进行测量。值太小会留下圆角，值太大会切过头。**旋转角度** 限制
刀片放下时能转多少；更尖的拐角会先抬起刀具，以免刀片横向拖拽。

## 切向刀切割

切向刀有一个电机，用来旋转刀片使其始终与路径相切。该步骤会把路径方向作为 **A** 轴值添加到
每个切割移动中，以便控制器转动刀片。

1. 选择要切割的轮廓。
2. 添加一个 **切向刀切割** 操作。
3. 选择 **刀具** 机头，并设置 **角度容差**、**半径容差**、**主轴转速**、**安全 Z 高度** 和
   切割速度。

![切向刀切割设置](/screenshots/step-settings-tangential-knife-general.webp)

方向变化超过 **角度容差** 或圆弧半径小于 **半径容差** 时，刀具会抬到安全 Z、旋转后再下刀。
较小的变化则在刀具放下时原地转动刀片。**主轴转速** 会作为 M3 指令发送给刀片电机；Rayforge
从不使用 M4，因为刀片电机只能顺时针旋转。

## 提示

- 先用降低的速度运行作业，尤其是在厚材料或纤维材料上。
- 使用一次性切割垫或较小的下刀深度，避免刀片划伤床面。
- 刀具步骤是普通的 G-code 操作：可以与其他激光步骤组合、重新排序、复制，并像其他操作一样
  保存到配方中。
