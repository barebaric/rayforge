# 收缩包裹

收缩包裹通过生成一个向对象"收缩"的边界，为多个对象创建高效的切割路径。它对于从板材上切割多个零件并最小化浪费很有用。

## 概述

收缩包裹操作：

- 在对象组周围创建边界路径
- 最小化材料浪费
- 通过合并路径减少切割时间
- 支持用于间隙的偏移距离
- 适用于任何矢量形状组合

## 何时使用收缩包裹

对以下情况使用收缩包裹：

- 从板材上切割多个小零件
- 最小化材料浪费
- 创建高效的嵌套边界
- 分离零件组
- 减少总切割时间

**不要将收缩包裹用于：**

- 单个对象（改用[轮廓](contour)）
- 需要单独边界的零件
- 精确的矩形切割

## 收缩包裹如何工作

收缩包裹使用计算几何算法创建边界：

1. **开始**于所有对象的凸包
2. **向内**朝对象收缩边界
3. **紧贴**对象组包裹
4. **向外**偏移指定距离

结果是一条高效的切割路径，它跟随零件整体形状，同时保持间隙。

## 创建收缩包裹操作

### 第 1 步：排列对象

1. 将要包裹的所有零件放在画布上
2. 以所需的间距定位它们
3. 多个单独的组可以一起进行收缩包裹

### 第 2 步：选择对象

1. 选择收缩包裹中要包含的所有对象
2. 可以是不同的形状、大小和类型
3. 所有选定的对象将一起被包裹

### 第 3 步：添加收缩包裹操作

- **菜单：** 操作 → 添加收缩包裹
- **右键点击：** 上下文菜单 → 添加操作 → 收缩包裹

### 第 4 步：配置设置

## 关键设置

步骤设置对话框包含三个选项卡：**步骤设置**、**激光**和**后处理**。设置按选项卡顺序说明如下。

### 收缩包裹

![收缩包裹步骤设置](/screenshots/step-settings-shrink-wrap-general.webp)

*步骤设置*选项卡上的**收缩包裹**组控制包络如何贴合内容。

#### 平滑度

控制边界跟随对象形状的紧密程度：

**高平滑度：**

- 更紧密地跟随对象
- 更复杂的路径
- 更长的切割时间
- 更少的材料浪费

**低平滑度：**

- 更简单、更圆润的路径
- 更短的切割时间
- 略多的材料浪费

**推荐：** 大多数情况下使用中等平滑度

#### 切割侧

控制激光相对于收缩包裹路径的切割位置：

| 切割侧     | 描述             | 用于           |
| ---------- | ---------------- | -------------- |
| **中心线** | 直接在路径上切割 | 标准切割       |
| **外部**   | 在边界外切割     | 使切割略微变大 |
| **内部**   | 在边界内切割     | 使切割略微变小 |

#### 偏移距离

**偏移（mm）：**

- 零件周围的间隙量
- 从对象到收缩包裹边界的距离
- 更大的偏移 = 零件周围留下更多材料

**典型值：**

- **2-3mm：** 紧密包裹，浪费最少
- **5mm：** 舒适的间隙
- **10mm+：** 用于处理的额外材料

**为什么偏移很重要：**

- 太小：有切割到零件的风险
- 太大：浪费材料
- 考虑：缝隙宽度、切割精度

### 激光设置

![激光设置](/screenshots/step-settings-shrink-wrap-laser.webp)

功率、速度和激光头选择位于步骤设置对话框的**激光**页面。

与其他切割操作一样：

**功率（%）：**

- 切割的激光强度
- 与[轮廓](contour)切割使用的相同

**速度（mm/min）：**

- 激光移动的速度
- 匹配材料的切割速度

要多次切割边界，请添加[多次遍](../multi-pass.md)后处理器。

## 用例

### 批量零件生产

**场景：** 从大板材上切割 20 个小零件

**没有收缩包裹：**

- 切割完整的板材边界
- 浪费零件周围的所有材料
- 切割时间长

**使用收缩包裹：**

- 围绕零件组切割紧密边界
- 为其他项目节省材料
- 更快的切割（更短的周长）

### 嵌套优化

**工作流程：**

1. 在板材上高效地嵌套零件
2. 将零件分组为若干部分
3. 对每个部分进行收缩包裹
4. 单独切割各部分

**好处：**

- 可以在继续作业时移除已完成的部分
- 更容易处理切割零件
- 降低零件移动的风险

### 材料节约

**示例：** 昂贵材料上的小零件

**过程：**

1. 紧密排列零件
2. 以 3mm 偏移进行收缩包裹
3. 从板材上切割出来
4. 保存剩余材料

**结果：** 最大的材料效率

## 与其他操作结合

### 收缩包裹 + 轮廓

常见工作流程：

1. 对单个零件进行**轮廓**操作（切割细节）
2. 围绕组进行**收缩包裹**（从板材上切割出来）

**执行顺序：**

- 首先：切割零件中的细节（在固定时）
- 最后：收缩包裹将组切割出来

有关详细信息，请参阅[多层工作流程](../multi-layer.md)。

### 收缩包裹 + 光栅

**示例：** 雕刻和切割的零件

1. 在零件上**光栅**雕刻标志
2. **轮廓**切割零件轮廓
3. 围绕整个组进行**收缩包裹**

**好处：**

- 所有雕刻都在材料固定时进行
- 最终的收缩包裹将整个批次切割出来

## 后处理

![收缩包裹后处理设置](/screenshots/step-settings-shrink-wrap-post.webp)

收缩包裹操作支持多种后处理选项：

- **[平滑路径](../smooth.md)** - 减少边界路径中的锯齿状边缘
- **[固定标签](../holding-tabs.md)** - 保持切割件与材料连接
- **[裁剪到材料](../crop-to-stock.md)** - 将切割限制在材料边界内
- **[路径优化](../path-optimization.md)** - 减少行程距离
- **[多次遍](../multi-pass.md)** - 为厚材料重复切割
- **[引入/引出](../lead-in-out.md)** - 添加零功率接近和退出移动，使切割端更干净

### 零件间距

**最佳间距：**

- 零件之间 5-10mm
- 足以让收缩包裹区分单独的对象
- 不会浪费太多材料

**太近：**

- 零件可能被一起包裹
- 收缩包裹可能桥接间隙
- 切割后难以分离

**太远：**

- 浪费材料
- 切割时间更长
- 板材利用效率低

### 材料考虑

**最适合：**

- 生产运行（许多相同的零件）
- 大板材上的小零件
- 昂贵的材料（最小化浪费）
- 批量切割作业

**不适合：**

- 单个大零件
- 填满整个板材的零件
- 当需要切割完整板材时

### 安全

**始终：**

- 检查边界不与零件重叠
- 验证偏移足够
- 在[3D 预览](../../ui/3d-preview.md)中预览
- 先在废料上测试

**注意：**

- 收缩包裹切割到零件中（增加偏移）
- 零件在收缩包裹完成前移动
- 材料翘曲将零件拉离位置

## 高级技术

### 多个收缩包裹

为不同的组创建单独的边界：

**过程：**

1. 将零件排列成逻辑组
2. 对组 1（顶部零件）进行收缩包裹
3. 对组 2（底部零件）进行收缩包裹
4. 单独切割各组

**好处：**

- 可以在作业期间移除已完成的组
- 更好的组织
- 更容易取回零件

### 嵌套收缩包裹

在更大的边界内进行收缩包裹：

**示例：**

1. 内部收缩包裹：小的详细零件
2. 外部收缩包裹：包括较大的零件
3. 轮廓：完整的板材边界

**用途：** 复杂的多零件布局

### 间隙测试

在生产运行之前：

1. 创建收缩包裹
2. 使用[3D 预览](../../ui/3d-preview.md)预览
3. 验证间隙足够
4. 检查没有零件被相交
5. 在废料材料上运行测试

## 故障排除

### 收缩包裹切割到零件中

- **增加：** 偏移距离
- **检查：** 零件是否离得太近
- **验证：** 预览中的收缩包裹路径
- **考虑：** 缝隙宽度（激光束宽度）

### 边界不跟随形状

- **增加：** 平滑度设置
- **检查：** 是否正确选择了零件
- **尝试：** 较小的偏移（可能包裹得太远）

### 零件被一起包裹

- **增加：** 零件之间的间距
- **添加：** 单个零件周围的手动轮廓
- **拆分：** 为多个收缩包裹操作

### 切割时间太长

- **降低：** 平滑度（更简单的路径）
- **增加：** 偏移（更直的边界）
- **考虑：** 多个较小的收缩包裹

### 切割期间零件移动

- **添加：** 小标签以保持零件（参见[固定标签](../holding-tabs.md)）
- **使用：** 切割顺序：从内到外
- **确保：** 材料平坦并固定
- **检查：** 板材未翘曲

## 技术细节

### 算法

收缩包裹使用计算几何：

1. **凸包** - 找到外部边界
2. **Alpha 形状** - 向对象收缩
3. **偏移** - 按偏移距离扩展
4. **简化** - 基于平滑度设置

### 路径优化

边界路径针对以下方面进行优化：

- 最小总长度
- 平滑的曲线（基于平滑度）
- 高效的开始/结束点

### 坐标系统

- **单位：** 毫米（mm）
- **精度：** 典型 0.01mm
- **坐标：** 与工作区相同
