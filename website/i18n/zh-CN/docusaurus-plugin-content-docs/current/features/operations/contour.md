# 轮廓切割

轮廓切割沿矢量形状的轮廓进行切割，将它们从材料上切下来。这是创建零件、标志和装饰品最常见的激光操作。

## 概述

轮廓操作：

- 沿矢量路径（线、曲线、形状）行进
- 沿对象周边切割
- 支持厚材料的单次或多次遍
- 可使用内部、外部或在线切割路径
- 适用于任何闭合或开放的矢量形状


## 何时使用轮廓

对以下情况使用轮廓切割：

- 从材料上切割零件
- 创建轮廓和边框
- 从木材、亚克力、纸板上切割形状
- 打孔或划线（降低功率）
- 创建模板和样板

**不要将轮廓用于：**

- 填充区域（改用[雕刻](engrave)）
- 位图图像（先转换为矢量）

## 创建轮廓操作

### 第 1 步：选择对象

1. 在画布上导入或绘制矢量形状
2. 选择要切割的对象
3. 确保形状为闭合路径，以实现完整切割

### 第 2 步：添加轮廓操作

- **菜单：** 操作 → 添加轮廓
- **快捷键：** <kbd>ctrl+shift+c</kbd>
- **右键点击：** 上下文菜单 → 添加操作 → 轮廓

### 第 3 步：配置设置

![轮廓步骤设置](/screenshots/step-settings-contour-general.webp)

## 关键设置

步骤设置对话框包含三个选项卡：**步骤设置**、**激光**和**后处理**。设置按选项卡顺序说明如下。

### 轮廓设置

![轮廓步骤设置](/screenshots/step-settings-contour-general.webp)

*步骤设置*选项卡上的**轮廓设置**组控制轮廓的描迹方式。

#### 切割侧与路径偏移

控制激光相对于矢量路径的切割位置：

| 偏移      | 描述               | 用于                           |
| --------- | ------------------ | ------------------------------ |
| **中心线**| 直接在路径上切割   | 中心线切割、划线               |
| **内部**  | 在形状内部切割     | 必须精确配合尺寸的零件         |
| **外部**  | 在形状外部切割     | 零件装入的孔                   |

**偏移距离：**

- 向内/向外偏移多远（mm）
- 通常设置为缝隙宽度的一半
- 缝隙 = 激光移除的材料宽度
- 示例：0.3mm 缝隙对应 0.15mm 偏移

#### 切割顺序

控制嵌套路径的处理顺序：

**从内到外：**

- 先切割内部特征，然后向外进行
- 使材料的外围部分保持最久完好

**从外到内：**

- 先切割外部周边，然后向内进行
- 使工件最久保持固定于原材料上

**推荐：** 从内到外（默认）

#### 移除内部路径

对于带有孔洞或内部镂空的设计，您可以选择只描迹最外层的边界：

- **移除内部路径**：启用后，仅描迹最外层的轮廓
- 内部孔洞和镂空将被忽略

当您想切出一个形状但保留其内部时，这很有用，例如创建框架或轮廓而不切割内部细节。

#### 过切

将闭合切割路径延伸过起点，使激光束与切割起点重叠：

**过切：**

- 以机器单位表示的距离，将切割延伸至起点/终点连接处之外
- 设置为 **0** 以禁用（默认）
- 典型值：大多数材料为 1–5
- 最大值：100

**为什么使用过切：**

在闭合轮廓的起点和终点，由于加速和减速，激光可能无法完全穿透。过切确保光束在连接处重叠，从而形成干净、完全切断的切口。这对于以下情况特别有用：

- 完全穿透较为勉强的厚材料
- 加速效应更明显的高速切割
- 需要无需后处理即可自行脱落的零件

过切同时适用于外部轮廓和内部孔洞。

:::tip 引入/引出 vs 过切
[引入/引出](../lead-in-out.md) 在切割路径前后添加零功率的接近和退出运动。过切则将切割路径本身延伸过连接处。两者可以结合使用以获得最佳切割质量。
:::

#### 带自定义阈值的重新描迹

当处理已转换为矢量的位图图像时，您可以控制描迹哪些部分：

- **重新扫描内容**：启用用于描迹的自定义亮度阈值
- **描迹阈值（0.0-1.0）**：启用重新扫描时的亮度截止值
  - 较低的值仅描迹较暗的区域
  - 较高的值包含较亮的区域

当默认描迹无法捕获所需的细节水平时，这很有用。

### 激光设置

![激光设置](/screenshots/step-settings-contour-laser.webp)

功率、速度和激光头选择位于步骤设置对话框的**激光**页面。

#### 功率和速度

**功率（%）：**

- 激光强度从 0-100%
- 较厚的材料使用较高功率
- 划线或标记使用较低功率

**速度（mm/min）：**

- 激光移动的速度
- 较慢 = 更多能量 = 更深的切割
- 较快 = 较少能量 = 较浅的切割

#### 缝隙补偿

缝隙是激光束移除的材料宽度：

**为什么重要：**

- "在线"切割的圆将比设计略小
- 激光移除约 0.2-0.4mm 材料（取决于光束宽度）

**如何补偿：**

1. 在测试切割上测量缝隙
2. 使用路径偏移 = 缝隙/2
3. 对于零件：**向内**偏移 缝隙/2
4. 对于孔：**向外**偏移 缝隙/2

有关详细指南，请参阅[缝隙](../kerf.md)。

## 后处理

![轮廓后处理设置](/screenshots/step-settings-contour-post.webp)

轮廓操作支持多种后处理选项：

- **[平滑路径](../smooth.md)** - 减少切割路径中的锯齿状边缘
- **[固定标签](../holding-tabs.md)** - 保持切割件与材料连接
- **[裁剪到材料](../crop-to-stock.md)** - 将切割限制在材料边界内
- **[路径优化](../path-optimization.md)** - 减少切割之间的行程距离
- **[多次遍](../multi-pass.md)** - 为厚材料重复切割
- **[引入/引出](../lead-in-out.md)** - 添加零功率接近和退出移动，使切割端更干净

### 多次遍切割

对于单次遍无法切透的材料：

**次数：**

- 重复切割的次数
- 每遍切割更深

**遍深度（Z 步）：**

- 每遍降低 Z 轴多少（如果支持）
- 需要机器上的 Z 轴控制
- 实现真正的 2.5D 切割
- 对于相同深度的多次遍设置为 0

:::warning 需要 Z 轴
:::

遍深度仅在您的机器具有 Z 轴控制时有效。对于没有 Z 轴的机器，请在相同深度上使用多次遍。

## 提示和最佳实践

### 材料测试

**始终先测试：**

1. 在废料上切割小测试形状
2. 从保守设置开始（较低功率、较慢速度）
3. 逐渐增加功率或降低速度
4. 记录成功的设置

### 切割顺序

**最佳实践：**

- 先雕刻再切割（保持材料固定）
- 先切割内部特征，再切割外部周边
- 为可能移动的零件使用固定标签
- 先切割最小的零件（振动较小）

## 故障排除

### 切割未穿透材料

- **增加：** 功率设置
- **降低：** 速度设置
- **添加：** 更多次数
- **检查：** 对焦正确
- **检查：** 光束干净（透镜脏污）

### 过度烧焦或燃烧

- **降低：** 功率设置
- **增加：** 速度设置
- **使用：** 空气辅助
- **尝试：** 多次较快的遍而不是一次慢遍
- **检查：** 材料适合激光切割

### 切割期间零件掉落

- **添加：** [固定标签](../holding-tabs.md)
- **使用：** 切割顺序优化
- **切割：** 先内部特征后外部
- **确保：** 材料平坦并固定

### 切割深度不一致

- **检查：** 材料厚度均匀
- **检查：** 材料平坦（未翘曲）
- **检查：** 对焦距离一致
- **验证：** 激光功率稳定

### 错过角落或曲线

- **降低：** 速度（尤其在角落处）
- **检查：** 机器加速度设置
- **验证：** 皮带张紧
- **减少：** 路径复杂度（简化曲线）

## 技术细节

### 坐标系统

轮廓操作的工作环境：

- **单位：** 毫米（mm）
- **原点：** 取决于机器和作业设置
- **坐标：** X/Y 平面（Z 用于多次遍深度）

### 路径生成

Rayforge 将矢量形状转换为 G 代码：

1. 偏移路径（如果是内部/外部切割）
2. 优化路径顺序（最小化行程）
3. 添加固定标签（如果已配置）
4. 生成 G 代码命令

### G 代码命令

典型的轮廓 G 代码：

```gcode
G0 X10 Y10          ; 快速移动到起点
M3 S204             ; 激光开，80% 功率
G1 X50 Y10 F500     ; 以 500 mm/min 切割到点
G1 X50 Y50 F500     ; 切割到下一个点
G1 X10 Y50 F500     ; 继续切割
G1 X10 Y10 F500     ; 完成方形
M5                  ; 激光关
```
