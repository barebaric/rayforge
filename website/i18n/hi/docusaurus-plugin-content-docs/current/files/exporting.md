# Rayforge से निर्यात करें

Rayforge भिन्न उद्देश्यों के लिए कई निर्यात विकल्प समर्थन करता है:

- **G-code** - जॉब चलाने के लिए मशीन नियंत्रण आउटपुट
- **ऑब्जेक्ट निर्यात** - व्यक्तिगत वर्कपीस वेक्टर फ़ॉर्मेट में निर्यात करें
- **दस्तावेज़ निर्यात** - सभी वर्कपीस एक एकल फ़ाइल के रूप में निर्यात करें

---

## ऑब्जेक्ट निर्यात करना

आप किसी भी वर्कपीस को डिज़ाइन सॉफ़्टवेयर, CAD एप्लिकेशन, या संग्रहण के लिए वेक्टर फ़ॉर्मेट में
निर्यात कर सकते हैं.

### कैसे निर्यात करें

1. कैनवस पर **एक वर्कपीस चुनें**
2. **Object → Export Object...** चुनें (या राइट-क्लिक → Export Object...)
3. **फ़ॉर्मेट और सहेजने का स्थान चुनें**

### उपलब्ध फ़ॉर्मेट

| फ़ॉर्मेट | एक्सटेंशन | विवरण                                                                                                                       |
| -------- | --------- | --------------------------------------------------------------------------------------------------------------------------- |
| **RFS**  | `.rfs`    | Rayforge का नेटिव पैरामीट्रिक स्केच फ़ॉर्मेट. सभी कॉन्स्ट्रेंट सुरक्षित रखता है और संपादन के लिए पुनः आयात किया जा सकता है. |
| **SVG**  | `.svg`    | Scalable Vector Graphics. Inkscape, Illustrator, और वेब ब्राउज़र जैसे डिज़ाइन सॉफ़्टवेयर के साथ व्यापक रूप से संगत.         |
| **DXF**  | `.dxf`    | Drawing Exchange Format. AutoCAD, FreeCAD, और LibreCAD जैसे अधिकांश CAD एप्लिकेशन के साथ संगत.                              |

### निर्यात नोट

- **SVG और DXF** हल की गई ज्यामिति निर्यात करते हैं (पैरामीट्रिक कॉन्स्ट्रेंट नहीं)
- निर्यात **मिलीमीटर इकाइयों** का उपयोग करते हैं
- ज्यामिति वास्तविक विमाओं तक स्केल होती है (विश्व स्थान)
- कई सबपाथ (असंबद्ध आकृतियाँ) अलग तत्वों के रूप में सुरक्षित रहते हैं

### उपयोग प्रसंग

**डिज़ाइन साझा करना:**

- Inkscape उपयोगकर्ताओं के साथ साझा करने के लिए SVG में निर्यात करें
- CAD सॉफ़्टवेयर उपयोगकर्ताओं के लिए DXF में निर्यात करें

**आगे संपादन:**

- SVG/DXF निर्यात करें, बाहरी सॉफ़्टवेयर में संपादित करें, पुनः आयात करें

**संग्रहण:**

- स्केच-आधारित डिज़ाइनों के लिए संपादन योग्यता सुरक्षित रखने के लिए RFS उपयोग करें
- दीर्घकालिक भंडारण या गैर-Rayforge उपयोगकर्ताओं के लिए SVG/DXF उपयोग करें

## दस्तावेज़ निर्यात करना

आप दस्तावेज़ के सभी वर्कपीस को एक एकल वेक्टर फ़ाइल में निर्यात कर सकते हैं. यह पूरी परियोजनाएँ साझा
करने या मानक फ़ॉर्मेट में बैकअप बनाने के लिए उपयोगी है.

### कैसे निर्यात करें

1. **File → Export Document...** चुनें
2. **फ़ॉर्मेट चुनें** (SVG या DXF)
3. **सहेजने का स्थान चुनें**

### उपलब्ध फ़ॉर्मेट

| फ़ॉर्मेट | एक्सटेंशन | विवरण                                                                                                               |
| -------- | --------- | ------------------------------------------------------------------------------------------------------------------- |
| **SVG**  | `.svg`    | Scalable Vector Graphics. Inkscape, Illustrator, और वेब ब्राउज़र जैसे डिज़ाइन सॉफ़्टवेयर के साथ व्यापक रूप से संगत. |
| **DXF**  | `.dxf`    | Drawing Exchange Format. AutoCAD, FreeCAD, और LibreCAD जैसे अधिकांश CAD एप्लिकेशन के साथ संगत.                      |

### निर्यात नोट

- सभी लेयरों के सभी वर्कपीस एक एकल फ़ाइल में जोड़े जाते हैं
- वर्कपीस स्थितियाँ सुरक्षित रहती हैं
- रिक्त वर्कपीस छोड़ दिए जाते हैं
- बाउंडिंग बॉक्स सारी ज्यामिति को घेरता है

### उपयोग प्रसंग

- **परियोजना साझाकरण**: सहयोग के लिए पूरी परियोजना निर्यात करें
- **बैकअप**: अपने काम का एक दृश्य संग्रह बनाएँ
- **आगे संपादन**: पूरा डिज़ाइन Inkscape या CAD सॉफ़्टवेयर में ले जाएँ

## G-code निर्यात करना

जनरेट किया गया G-code सब कुछ ठीक वैसे रखता है जैसा मशीन को भेजा जाएगा. सटीक फ़ॉर्मेट, कमांड,
संख्यात्मक परिशुद्धता आदि वर्तमान में चयनित मशीन की सेटिंग्स और उसके G-code डायलेक्ट पर निर्भर करते
हैं.

---

### निर्यात विधियाँ

### विधि 1: फ़ाइल मेनू

**File Export G-code** (Ctrl+E)

- फ़ाइल सहेजने का संवाद खोलता है
- स्थान और फ़ाइल नाम चुनें
- G-code जनरेट होकर सहेजा जाता है

### विधि 2: कमांड लाइन

```bash
# Export from command line (if supported)
rayforge --export output.gcode input.svg
```

---

### G-code आउटपुट

जनरेट किया गया G-code सब कुछ ठीक वैसे रखता है जैसा मशीन को भेजा जाएगा. सटीक फ़ॉर्मेट, कमांड,
संख्यात्मक परिशुद्धता आदि वर्तमान में चयनित मशीन की सेटिंग्स और उसके G-code डायलेक्ट पर निर्भर करते
हैं.
