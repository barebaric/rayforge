# 床面网格

大幅面工作台很少完全平整。当床面高度的变化超过激光的焦深时，切割效果会在材料上不一致。床面网格功能会在网格上探测表面高度，并补偿刀具路径的 Z 轴，使焦点跟随真实表面。

![床面网格](/screenshots/machine-settings-bed-mesh.webp)

## 前提条件

床面网格需要带有 Z 轴的机器以及支持探测的驱动程序（目前为 GRBL、Marlin、Smoothie 和 OctoPrint）。只有同时满足这两个条件时，**设置 → 机器**
中才会显示**床面网格**页面。该页面位于设备页面之后。

## 探测床面

打开**设置 → 机器**，导航到**床面网格**页面。

1. **探测网格**：定义要探测的区域（X/Y 原点、宽度、高度）以及网格密度（列数和行数）。页面会显示探测点数量并估算探测时长。网格越密，对表面的跟踪越精确，但耗时越长。
2. **探测**：配置探测进给速度、每个点上头部向下搜索表面的最大距离（最大行程），以及点间移动时使用的安全 Z 高度。
3. 点击**开始探测**。机器以蛇形路径访问每个网格点并触碰表面；3D 视图会随着结果实时填充。您可以随时停止；只有完整网格完成后才会保存网格。

网格与机器配置一起保存，并以彩色 3D 曲面显示：蓝色区域较低，红色区域较高。如果不再需要高度补偿，可使用**删除网格**按钮将其移除。

:::note探测时，头部会移过整个网格区域。请清除床面上可能阻挡探测头的物体，并确保您的探测尖端（或激光十字线）能够触及每个网格点处的表面。:::

## 应用网格

探测只是记录高度图——是否应用则按作业控制：

- **默认应用到作业**：在床面网格页面上打开此开关，即可补偿此机器上每个作业的 Z 轴。
- **按层覆盖**：在图层设置（图层设置 → 后处理）中，机器默认值会显示**自定义**和**禁用**操作。自定义会将该校正复制到图层中，你可以在那里调整 Z 偏移（例如聚焦在表面稍上方）；禁用则仅在该图层关闭校正。删除图层的条目后会回退到机器默认值。

该校正同等作用于切割移动和空移，且圆弧保持圆弧（变为螺旋线）。它在最终刀具路径上以机器坐标运行，因此不受工作坐标系或机器原点角的影响。
