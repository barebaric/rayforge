# Notes

La page Notes dans les Paramètres Machine regroupe toutes les informations sur votre machine en un
seul endroit. Elle combine vos propres notes avec le guide fourni avec le profil d'appareil de votre
machine.

![Paramètres des Notes](/screenshots/machine-settings-notes.webp)

## Mes notes

Mes notes est votre carnet personnel pour la machine : la maintenance effectuée, les réglages qui
ont bien fonctionné avec un matériau, les commandes de pièces de rechange ou tout autre chose qui
mérite d'être retenue. Les notes sont rédigées en Markdown et affichées directement sur la page.

Cliquez sur **Modifier mes notes** pour ouvrir l'éditeur. Il affiche le Markdown brut à gauche et un
aperçu en direct à droite, avec une barre d'outils pour les formats pris en charge : titres, texte
en gras et en italique, listes à puces et numérotées, liens, code en ligne, blocs de code, citations
et sections de détails dépliables. La disposition peut être basculée entre côte à côte et empilée.

![Modifier mes notes](/screenshots/machine-settings-notes-editor.webp)

Vos notes sont stockées avec la machine et ne sont jamais écrasées par les mises à jour du profil
d'appareil : une mise à jour du profil les laisse intactes.

## Notes de l'appareil

Les machines créées à partir d'un profil d'appareil qui fournit un guide de configuration
l'affichent ici sous forme de Notes de l'appareil en lecture seule — par exemple des instructions de
configuration pas à pas ou des conseils d'utilisation pour cette machine spécifique. Le groupe est
masqué pour les machines dont le profil ne fournit pas de guide.

Les Notes de l'appareil sont gérées par le profil : lorsque le profil est mis à jour, le guide est
actualisé automatiquement. Elles ne peuvent pas être modifiées ici.

## Assistant de Configuration

Lorsque vous créez une machine avec
l'[assistant de configuration](../getting-started/first-time-setup.md), le guide du profil est
affiché sur la page de révision avant la création de la machine, afin que vous puissiez le lire
pendant la configuration. Il reste ensuite disponible sur la page Notes.
