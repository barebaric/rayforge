# Масиви

Ескізер надає два інструменти масивів для створення параметричних масивів:
**Круговий масив** та **Масив вздовж кривої**.

## Кругові масиви

Інструмент **Круговий масив** (`G+Y`) створює параметричну полярну
розмітку з поточного виділення:

1. Виберіть елементи, які ви хочете розмістити по колу.
2. Активуйте інструмент з панелі інструментів, меню **Ескіз → Масиви**
   або `G+Y`.
3. На полотні з'являється напрямне коло та відкривається немодальний діалог
   з попереднім переглядом.
4. Встановіть **кількість** та **загальний кут**. Копії генеруються
   параметрично навколо центру напрямного кола.
5. Перетягуйте центр напрямного кола для зміщення масиву або перетягуйте
   початковий елемент для зміни радіуса — поля діалогу оновлюються
   наживо.
6. **Розмірна позначка** напрямного кола змінює розмір усього масиву.
   **Подвійне натискання** на напрямне коло повторно відкриває діалог
   редагування та регенерує відсутні або перерозподіляє елементи.

Копії є статичною запеченою геометрією без обмежень розв'язувача:
вони регенеруються з шаблону, коли масив редагується. Видалення
елемента видаляє лише геометрію цього елемента і ніколи не
перерозподілює решту.

## Масив вздовж кривої

Інструмент **Масив вздовж кривої** розподіляє копії однієї або кількох
елементів вздовж напрямного шляху (лінії, дуги або кривої Безьє). Копії
розміщуються безпосередньо на шляху та дотримуються його дотичної в кожній
позиції.

### Створення масиву вздовж кривої

1. Намалюйте форму, яку ви хочете розподілити (шаблон), та напрямний шлях,
   якому ви хочете слідувати.
2. Виберіть обидва: спочатку клацніть на **напрямному шляху**, потім
   Shift-клацніть на **елементах шаблону**.
3. Активуйте інструмент з панелі інструментів, меню **Ескіз → Масиви**
   або `G+W`.
4. Відкривається немодальний діалог з попереднім переглядом копій,
   розподілених вздовж шляху.
5. Налаштуйте **кількість** (загальна кількість членів, включаючи шаблон
   на початку шляху) або встановіть значення **відстані**, щоб визначити
   кількість автоматично з довжини шляху.
6. За бажанням увімкніть **Вирівняти по дотичній**, щоб кожна копія
   оберталася відповідно до напрямку шляху в своїй позиції.
7. Використовуйте **Зміщення від початку**, щоб пропустити початкову
   ділянку шляху перед розміщенням першої копії.

### Редагування масиву вздовж кривої

- **Подвійне натискання** на напрямному шляху (або клацніть **Редагувати**
  на панелі інструментів) для повторного відкриття діалогу та зміни
  кількості, відстані, зміщення або налаштувань вирівнювання.
- **Перетягніть** будь-який кінець напрямного шляху для його зміни. Коли ви
  відпустите, всі копії автоматично перерозподіляться вздовж нової
  геометрії шляху — включаючи оновлення обертання, коли *Вирівняти по
  дотичній* увімкнено.
- Форму шаблону можна редагувати як будь-яку іншу геометрію ескізу;
  зміни поширюються на всі копії при наступному оновленні.

### Як це працює

Копії є статичною запеченою геометрією — вони не пов'язані з шаблоном
через обмеження розв'язувача. Коли напрямний шлях редагується,
`sync_arrays` виявляє зміну та регенерує всі копії з нуля,
використовуючи поточну геометрію шляху. Це підтримує оновлення швидкими
та уникне перевантаження розв'язувача.

Шаблон (слот 0) розміщується на початку шляху. Його позиція та
орієнтація оновлюються автоматично, коли шлях редагується. Оригінальні
елементи шаблону видаляються при створенні масиву; скасування відновлює
їх.
