# Preenchimento de áreas

A ferramenta de preenchimento (`G+F`) preenche regiões fechadas de um esboço com uma área sólida.
Preenchimentos são úteis para regiões que serão gravadas como uma única peça.

![Um retângulo preenchido](/screenshots/addons-sketcher-tool-fill.webp)

## Criando e removendo preenchimentos

1. Desenhe um ou mais contornos fechados (por exemplo com as ferramentas de
   [retângulo](rectangle.md) ou de [caminho](path.md)).
2. Escolha a ferramenta de preenchimento no menu circular, no menu **Esboço**, ou pressione `G+F`.
3. Clique em qualquer lugar dentro de uma região fechada para preenchê-la.
4. Clique novamente em uma região preenchida para remover seu preenchimento.

Clicar dentro de uma caixa de texto alterna o preenchimento dos glifos do texto em vez de criar um
preenchimento de região.

## Cor de preenchimento

A cor de preenchimento para novos preenchimentos é escolhida com o botão **Cor de preenchimento** na
barra de ferramentas do esboçador. Preenchimentos existentes mantêm sua cor até serem removidos e
recriados.

Como tudo no esboçador, um preenchimento está vinculado ao seu contorno: redimensione a geometria ao
redor e o preenchimento acompanha.
