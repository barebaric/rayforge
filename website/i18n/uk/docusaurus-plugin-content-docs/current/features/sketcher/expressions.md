# Вирази та параметри

Ескіз стає справді параметричним, коли його розміри керуються іменованими значеннями замість жорстко
заданих чисел. Ескізер підтримує це у двох місцях: розмірні обмеження приймають **вирази**, а
текстові блоки — **шаблонні вирази**. Обидва обчислюються розв'язувачем, тому ескіз оновлюється
автоматично щоразу, коли змінюється значення.

## Параметри ескізу

Кожен ескіз має власний список параметрів, показаний у панелі **Параметри ескізу** ліворуч в
редакторі ескізів. **Додати параметр** створює новий, дозволяючи обрати ціле число, число з
плаваючою комою, повзунок або один рядок тексту. Кожен параметр має ім'я — стовпець `key` — і саме
на це ім'я посилаються вирази.

Типове налаштування для коробки зі змінною товщиною стінки — два параметри: `width` та `thickness`.
Нічого ще не обмежує геометрію; параметри — це лише імена для чисел, поки їх не використає вираз.

## Вирази в обмеженнях

Двічі клацніть розмірне обмеження (див. [Обмеження](constraints.md)) та введіть вираз замість
простого числа:

```
width / 2
```

Значення обмеження стає результатом цього виразу, який переобчислюється щоразу під час розв'язання
ескізу. Змініть параметр `width` — і обмежена геометрія підлаштується: одне редагування тепер
оновлює кожен розмір, що посилається на нього. Обмеження, що керуються виразом, малюють свій маркер
оранжевим, а підпис показує обчислене значення.

Вирази можуть поєднувати параметри з арифметикою та стандартними математичними функціями Python:

```
width - 2 * thickness
sqrt(area) / 2
2 * pi * radius
```

Функції на кшталт `sqrt`, `sin`, `cos` і `tan`, а також константи на кшталт `pi`, походять з модуля
`math` Python — саме цей модуль разом з параметрами є тим, на що може посилатися вираз обмеження.
Можна посилатися і на строкові параметри, що найкорисніше в текстових блоках.

## Шаблонні вирази в текстових блоках {#template-expressions-in-text-boxes}

Текстові блоки вирішують вирази, укладені у фігурні дужки, під час розв'язання, тому підписи та
гравійований текст показують живі значення:

```
W = {width}, H = {height}
```

Будь-який параметр можна підставити за іменем, а результат можна відформатувати специфікатором
формату Python після двокрапки:

- `{width}` — поточне значення параметра `width`
- `{name}` — значення строкового параметра
- `{width:.1f}` — одна десяткова
- `{timestamp():.0f}` — без десяткових у результаті функції

Математика працює і тут: як вираз на кшталт `{width * 2}`, так і через функцію на кшталт
`{sqrt(area):.2f}`. Порівняно з виразами обмежень, текстові шаблони мають багатший набір
інструментів: разом з математичним модулем вони надають вбудовані функції нижче, а для них можна
реєструвати кастомні функції (див. [нижче](#custom-template-functions)).

### Вбудовані шаблонні функції

| Функція         | Тип повернення | Опис                                                   |
| --------------- | -------------- | ------------------------------------------------------ |
| `{today()}`     | `date`         | Поточна дата UTC (напр., `2026-08-26`)                 |
| `{date()}`      | `date`         | Псевдонім для `today()`                                |
| `{now()}`       | `datetime`     | Поточна дата та час UTC                                |
| `{time()}`      | `time`         | Поточний час UTC (напр., `15:30:00.123456+00:00`)      |
| `{timestamp()}` | `float`        | Мітка часу Unix (секунди з епохи)                      |
| `{uuid4()}`     | `str`          | 8-символьний шістнадцятковий рядок (напр., `a1b2c3d4`) |
| `{uuid8()}`     | `str`          | Псевдонім для `uuid4()`                                |
| `{uuid()}`      | `str`          | Повний рядок UUID v4 (36 символів)                     |

Типові застосування включають унікальні серійні номери при кожному розв'язанні
(`Деталь #{uuid4()}`), живі мітки розмірів (`Ш={width:.1f} В={height:.1f}`), датування кожної деталі
(`Дата: {today()}`), лічильники виробництва (`{name} - {count:.0f}шт`) або мітки часу Unix для
виробничого журналу (`{timestamp():.0f}`).

## Кастомні функції шаблонів {#custom-template-functions}

Ви можете зареєструвати власні функції для використання у шаблонах текстових блоків. Це корисно для
отримання серійних номерів з бази даних, читання зовнішніх даних або створення кастомних міток.

### Написання скрипту реєстрації

Створіть Python файл (напр. `~/.config/rayforge/my_functions.py`):

```python
"""Register custom template functions for text box expressions."""
import sqlite3

from sketcher.core.template_functions import register_template_function

DB_PATH = "/home/you/production.db"


def next_serial() -> str:
    """Fetch and reserve the next serial number from the database."""
    conn = sqlite3.connect(DB_PATH)
    try:
        cur = conn.execute(
            "UPDATE counters SET value = value + 1 "
            "WHERE name = 'serial' RETURNING value"
        )
        row = cur.fetchone()
        conn.commit()
        return f"SN-{row[0]:06d}"
    finally:
        conn.close()

register_template_function("next_serial", next_serial)
```

Викличте `register_template_function(name, callable)` для кожної функції. Функція може робити все,
що може Python: відкривати файли, з'єднуватися з базами даних, викликати API — і вона викликається
при **кожному рендерингу**, тому має бути швидкою (використовуйте кешування, якщо вихідні дані не
змінюються між рендерингами). Функції є thread-safe, якщо ваш callable є таким.

### Запуск Rayforge зі скриптом

Використовуйте прапор `--script`, щоб завантажити ваші функції перед відкриттям вікна:

```bash
rayforge --script ~/.config/rayforge/my_functions.py mydoc.ryp
```

Це запускає ваш скрипт на початку запуску — до завантаження аддонів та до створення головного вікна
— щоб функція була доступна, коли ескіз розв'язується вперше.

### Використання функції у текстовому блоці

В ескізері створіть текстовий блок з:

```
{next_serial()}
```

Специфікації формату також працюють:

```
{next_serial():>20}
```

### Реєстрація функцій програмно

Якщо ви пишете аддон або бібліотеку для повторного використання, ви можете викликати
`register_template_function` з будь-якого Python коду, який виконується перед розв'язанням ескізу:

```python
from sketcher.core.template_functions import register_template_function

register_template_function("part_number", lambda: f"P-{hash('x') % 10000:04d}")
```

### Вбудовані функції не можна видалити

Вбудовані функції (`today`, `now`, `uuid` тощо) не можуть бути видалені. Якщо вам потрібно змінити
їхню поведінку, зареєструйте функцію з іншою назвою.
