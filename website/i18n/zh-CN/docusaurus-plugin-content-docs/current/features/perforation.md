# 穿孔

并不是每条切割线都是为了把零件从材料上取下来。有些线的意义在于让材料沿着它折叠、干净地撕开，或预先标出缝针的走向。**穿孔**后处理正是为此而生：它把连续切割变成虚线切割。激光不再从头到尾一直出光，而是按**切割长度**出光，再关闭激光走过**跳过长度**，并沿工件的每条轮廓重复这一节奏。留下的是一串小切割，它们把材料连在一起——直到你想让它折或撕开的那一刻。

![轮廓步骤后处理页面中的穿孔设置](/screenshots/step-settings-contour-post-perforation.webp)

## 典型用途

凡是需要削弱材料而又不把它切开的场合，都值得考虑穿孔切割。常见的例子：

- 卡纸和瓦楞纸板上的**折线**沿虚线切口干净利落地折叠——比如盒子、卡片和立体弹出设计。
- **撕线**让门票、优惠券和包装不需要剪刀就能打开。
- 皮革上的**缝线孔**在缝纫前标出针的走向。
- **虚线轮廓**本身就是一种装饰效果，适合木材、纸张和亚克力。

## 启用穿孔

穿孔位于[轮廓](operations/contour)步骤设置中的**后处理**页面，与其他后处理并列。它默认关闭；打开开关后会出现两个数值：

- **切割长度**：每个间隙前激光持续出光的距离。
- **跳过长度**：两段切割之间关闭激光移动的距离。

图案从每条轮廓的起点的一段完整切割开始，并在每条轮廓上重新开始，因此工件上所有虚线都以同样的方式起头。短到连一段切割加一段跳跃都放不下的轮廓会被完整切下。

## 效果

在画布上，虚线取代了实线切割轮廓——刀具路径上的每个间隙就是成品零件上的每个间隙。

![矩形和圆形以虚线形式切入桦木胶合板](/screenshots/operations-perforation.webp)

## 提示

对于不应切穿的折线，可以先让跳过长度与切割长度大致相同，并降低功率——浅浅的压痕和深深的虚线切口一样容易折，而且背面保持整洁。

非常短的长度（零点几毫米）会让激光快速开关，降低有效功率，还可能留下不均匀的痕迹。如果图案看起来不一致，试试更长的数值。

穿孔与后处理的其他功能配合良好：[固定标签](holding-tabs)、[引入 / 引出](lead-in-out)和
[多次遍](multi-pass)都照常工作。
