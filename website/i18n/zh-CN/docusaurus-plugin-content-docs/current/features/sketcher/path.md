# 路径工具

路径工具（`G+P` 或
`G+L`）在同一个统一的工作流程中绘制由直线和平滑贝塞尔曲线组成的连续链条。它是草图绘制器中最灵活的绘图工具：点击放置点，拖动即可把线段弯成曲线。

![由一条贝塞尔线段连接两条线组成的路径，及其路径点和控制柄](/screenshots/addons-sketcher-tool-path.webp)

## 绘制路径

1. 从饼形菜单或 **草图** 菜单中选择路径工具，或按 `G+P`。
2. 点击放置第一个点。实时预览会跟随光标。
3. 再次点击且不拖动，即可完成一段直线——下一段立即从该点开始。
4. 在一个点上按下并在释放前拖动，即可把该线段变成贝塞尔曲线。拖动控制曲线的"弓度"。
5. 继续添加点以构建你的路径。
6. 按 `Escape` 或双击以完成路径。

预览处于活动状态时，状态栏会列出适用的修饰键，`Esc` 可将其取消。

## 使用贝塞尔曲线

贝塞尔曲线可以创建平滑、自然的形状：

- **调整控制柄**：选中一条贝塞尔曲线并拖动圆形控制柄的端点即可修改曲线形状。每个控制柄只弯曲路径点在其一侧的曲线。
- **连接到现有点**：绘制时，磁性捕捉会把新线段吸附到草图中的现有点上，并自动创建相应的约束。

### 路径点类型

路径中两条线段相交的点是一个*路径点*。路径点类型控制曲线流经它的方式：

- **尖角**：两侧的控制柄相互独立，产生一个拐角。
- **平滑**：两侧控制柄共享同一切线，产生连续、圆润的过渡。
- **对称**：与平滑类似，但控制柄还会镜像，使两侧弯曲程度相等。

要更改路径点的类型，右键点击它（或相邻的贝塞尔线段），然后从饼形菜单中选择类型。新绘制的贝塞尔路径点默认为对称类型。

![选中贝塞尔路径点上的饼形菜单，包含拉直、尖角、平滑和对称工具](/screenshots/addons-sketcher-tool-path-pie-menu.webp)

### 将曲线转换为直线

同一个饼形菜单中的 **拉直**
工具可以把贝塞尔曲线转换回直线，当你需要干净、简单的几何图形时非常有用。选中要转换的贝塞尔线段，然后应用拉直操作。线段会收缩为其端点之间的直连线。

## 自动约束

路径工具和其他绘图工具一样参与磁性捕捉。绘制过程中捕捉参考线显示对齐时，会自动创建相应的水平和垂直约束，从一开始就让草图保持整洁，而不是事后修补。按住
`Shift`
可将新线段约束到最近的坐标轴。完整的捕捉指示器列表参见[网格与捕捉](index.md#grid-and-snapping)。
