# Заливка областей

Інструмент заливки (`G+F`) заповнює замкнені області ескізу суцільною заливкою. Заливки зручні для
областей, які гравіюватимуться як єдине ціле.

![Заповнений прямокутник](/screenshots/addons-sketcher-tool-fill.webp)

## Створення та видалення заливок

1. Накресліть один або кілька замкнених контурів (наприклад, інструментами
   [прямокутника](rectangle.md) або [шляху](path.md)).
2. Виберіть інструмент заливки в круговому меню, меню **Ескіз** або натисніть `G+F`.
3. Клацніть будь-де всередині замкненої області, щоб заповнити її.
4. Клацніть заповнену область ще раз, щоб прибрати її заливку.

Клацання всередині текстового блоку перемикає заливку літер тексту замість створення заливки
області.

## Колір заливки

Колір заливки для нових заливок обирається кнопкою **Колір заливки** на панелі інструментів
ескізера. Наявні заливки зберігають свій колір, доки їх не буде видалено та створено знову.

Як і все в ескізері, заливка прив'язана до своєї межі: змініть розмір навколишньої геометрії, і
заливка піде слідом.
