# 备注

机器设置中的备注页面将有关机器的所有信息集中在一处。它将您自己的备注与机器设备配置文件附带的指南组合在一起。

![备注设置](/screenshots/machine-settings-notes.webp)

## 我的备注

我的备注是您这台机器的个人笔记本——做过的维护、对某种材料效果良好的设置、备件订单，或其他任何值得记住的事情。备注使用 Markdown 书写，并直接呈现在页面上。

点击**编辑我的备注**打开编辑器。编辑器左侧显示原始 Markdown，右侧显示实时预览，并提供受支持格式的工具栏：标题、粗体和斜体文本、无序和有序列表、链接、行内代码、代码块、引用以及可展开的详情部分。布局可以在并排和堆叠之间切换。

![编辑我的备注](/screenshots/machine-settings-notes-editor.webp)

您的备注随机器一起保存，永远不会被设备配置文件更新覆盖，因此更新配置文件不会改动它们。

## 设备备注

如果机器由附带设置指南的设备配置文件创建，该指南会在这里显示为只读的设备备注——例如针对该机器的逐步设置说明或使用提示。配置文件不带指南时，此分组会隐藏。

设备备注由配置文件维护：配置文件更新时，指南会自动刷新。这里无法编辑它们。

## 设置向导

当您使用[设置向导](../getting-started/first-time-setup.md)创建机器时，配置文件的指南会在创建机器前显示在检查页面上，方便您在设置过程中阅读。之后它仍可在备注页面查看。
