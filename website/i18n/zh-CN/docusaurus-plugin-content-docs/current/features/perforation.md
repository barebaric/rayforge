# 穿孔

**穿孔**后处理会把连续切割变成虚线切割。激光在**切割长度**内出光，然后在**跳过长度**内关闭激光移动，并沿工件的每条轮廓重复。

## 何时使用

- 卡纸和瓦楞纸板的折线
- 撕线（门票、优惠券、包装）
- 皮革上的缝线孔
- 装饰性虚线

## 设置

穿孔位于**轮廓**操作的后处理设置中，默认关闭。

- **切割长度**：每个间隙前激光出光的距离。
- **跳过长度**：两段切割之间关闭激光移动的距离。

图案沿工件的每条轮廓测量，并在每条轮廓的起点重新开始，总是以一段完整的切割开始。短于一段切割加一段跳过的轮廓会被完整切割。

## 提示

- 对于不应切穿的折线，可以先让跳过长度与切割长度大致相同，并降低功率。
- 非常短的长度（零点几毫米）会让激光快速开关，从而降低有效功率。
- 穿孔可与[固定标签](holding-tabs)、[引入/引出](lead-in-out)和[多次切割](multi-pass)一起使用。
