# Команда

Крок команди вставляє власний машинний код у завдання саме в тому місці, яке цей крок займає в
робочому процесі шару. Використовуйте його, щоб надсилати команди, які не охоплюються геометричними
операціями: позиціювання голови, увімкнення/вимкнення повітряного помічника або іншого обладнання
навколо певних операцій, а також надсилання кодів, специфічних для машини.

![Налаштування кроку команди](/screenshots/step-settings-command-general.webp)

## Огляд

Крок команди:

- Містить багаторядковий блок машинного коду, одна команда на рядок
- Виводить кожен рядок без змін у місці розташування кроку під час кодування завдання
- Виконується один раз на шар, у своїй позиції робочого процесу — він не діє на деталі
- Працює без жодної деталі в шарі, тому шар, що містить лише крок команди, все одно може створити
  завдання
- Підтримує ті самі змінні шляху, що й макроси (див. нижче)

Текст зберігається в проєкті нерозгорнутим, тому він подорожує разом із файлом `.ryp` і точно
документує, що саме і куди надсилається.

## Коли використовувати крок команди

Використовуйте крок команди для:

- Попереднього позиціювання голови (наприклад, піднімання Z перед початком різання)
- Увімкнення/вимкнення повітряного помічника, охолодження або іншого обладнання між операціями
- Надсилання кодів, специфічних для контролера, навколо завдання
- Короткої паузи з витримкою (dwell) між двома операціями

**Не використовуйте крок команди для:**

- Повторення G-code на межах шарів або деталей — [Макроси та хуки](../../machine/hooks-macros.md)
  спрацьовують автоматично і працюють також на машинах без G-code
- Запуску програм на комп'ютері (це не підтримується на цьому етапі)

## Додавання кроку команди

1. Відкрийте робочий процес шару в правій панелі.
2. Натисніть кнопку **Додати крок** і виберіть **Команда**.
3. Введіть машинний код у текстове поле, одна команда на рядок. Порожні рядки пропускаються.

Крок можна розмістити перед, між або після інших кроків, і його можна використовувати кілька разів у
шарі. Його позиція в робочому процесі — це позиція, яку його рядки займають у згенерованому
машинному коді.

## Змінні шляху

Як і макроси, рядки можуть містити змінні шляху, які розв'язуються під час кодування завдання.
Невідомі змінні залишаються недоторканими, а змінні `layer.*` розв'язуються навіть тоді, коли крок
виконується в середині шару.

| Змінна             | Приклад    | Опис                                      |
| ------------------ | ---------- | ----------------------------------------- |
| `{machine.name}`   | `My Laser` | Назва активної машини                     |
| `{layer.name}`     | `Layer 1`  | Назва шару, який обробляється             |
| `{job.extents[0]}` | `210.0`    | Розмір завдання по осі X (мм)             |
| `{wcs_offset[0]}`  | `5.0`      | Зсув X активної робочої системи координат |

Наприклад, коментар на кшталт `; різання {layer.name} на {machine.name}` кодується з підставленими
назвами.

## Підтримка машин

Крок команди доступний на кожній машині, але рядки виводяться лише для драйверів, які споживають
машинний код. Якщо драйвер активної машини цього не робить (наприклад, Ruida), крок показує
попередження, а його рядки не входять до згенерованого результату.
