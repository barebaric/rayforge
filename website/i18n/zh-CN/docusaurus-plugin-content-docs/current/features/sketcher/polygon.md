# 多边形与星形

**多边形**工具（`G+X`）可绘制正多边形（例如用作杯垫的六边形）或星形。

## 绘制多边形

在中心所在位置单击，移动指针后再次单击；或在中心按下、拖动并释放。指针确定第一个角，因此同时决定大小和旋转。新多边形有 6 个角。

- 按住 `Ctrl` 可改为绘制星形：在每两个外角之间添加一个内角，位于外半径的一半处。

预览处于活动状态时，你可以输入精确数值：状态栏会显示 `R`、`N` 和 `Star` 字段。`R`
是从中心到各角的半径，`N` 是角的数量（3 到 100），`Star` 是内半径占外半径的比例（0 到 1 之间）。输入
`Star` 值会把多边形变成星形。输入数值，按 `Tab` 切换到下一个字段，按 `Enter` 创建形状；`Esc`
可取消预览。该工具会为下一个多边形记住角的数量。

## 得到的结果

多边形不是特殊对象：它由普通的点和线组成，因此圆角、倒角、偏移和布尔运算对它的作用与对其他任何形状相同。

约束使其保持规则。所有边长度相等，各角位于围绕中心点的构造圆上；星形还有第二个构造圆用于内角，并保持两个半径之间的比例。如果你输入了半径，半径约束会将其固定。之后你可以拖动中心来移动多边形，或拖动某个角来缩放和旋转它，它始终保持规则。之后要更改大小，请编辑半径约束，或为构造圆添加一个半径约束。
