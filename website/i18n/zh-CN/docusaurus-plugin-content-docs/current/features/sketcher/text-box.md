# 文本框

文本框工具（`G+T`）将文本作为可编辑几何图形放置在草图上——雕刻文本、标签和序列号。文本框完全参数化：字形位于一个受约束的框架内，因此每当框架被移动或标注尺寸时，它们都会重新求解。

![一个文字标识和一个零件标签](/screenshots/addons-sketcher-tool-text-box.webp)

## 创建和编辑文本

1. 从饼形菜单或 **草图** 菜单中选择文本框工具，或按 `G+T`。
2. 单击希望文本开始的位置：文本框出现在单击点，工具随即直接进入编辑状态。
3. 输入文本——文本框会随着你的输入自动调整大小。
4. 按 `Enter` 或 `Escape` 结束编辑。

要编辑现有文本框，请单击其内部。双击选择一个单词，三击选中整行，文本可以像在任何文本编辑器中一样被选中和替换，包括
`Ctrl+C`/`Ctrl+V`、撤销/重做以及编辑中途粘贴。

## 字体属性

![字体属性面板](/screenshots/addons-sketcher-tool-text-box-font-properties.webp)

侧边栏中的 **字体属性** 面板控制画布中选中的文本框的外观：

- **字体系列** —— 从已安装的系统字体中选择。
- **字体大小** —— 以磅为单位。
- **粗体** 和 **斜体** 开关。

## 参数化框架

文本框不是光栅图像：它的字形是真正的草图几何图形，排列在一个由原点以及宽度和高度点定义的框架内。框架以虚线绘制，属于构造几何，因此它作为布局参考，在草图加工时绝不会进入刀具路径。与草图绘制器中的其他一切一样，框架也带有约束，因此它可以像任何其他几何图形一样标注尺寸——更改宽度约束，文本就会重新求解以填满文本框。

用[填充工具](fill.md)在文本框内部点击会切换文字字形的填充，而不是创建区域填充。

## 模板表达式

文本框接受**模板表达式**：花括号中的任何内容都会在草图求解时被求值，因此标签可以显示实时值，例如尺寸、日期或唯一序列号。有关详细信息及内置函数，请参阅[文本框中的模板表达式](expressions.md#template-expressions-in-text-boxes)。
