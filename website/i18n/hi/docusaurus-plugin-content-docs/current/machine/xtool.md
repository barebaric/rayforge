# xTool वाई-फ़ाई

Rayforge में वाई-फ़ाई से जुड़ी xTool मशीनों के लिए प्रयोगात्मक ड्राइवर शामिल हैं। ये GRBL Telnet या FluidNC /
ESP3D इंटरफ़ेस के बजाय xTool के स्वामित्व वाले नेटवर्क API से बात करते हैं, इसलिए मशीन को उसके अपने xTool ड्राइवर के
साथ सेट किया जाना चाहिए।

## समर्थित मशीनें

| प्रोफ़ाइल          | ड्राइवर             | यह क्या कर सकता है                                                   |
| ---------------- | ------------------ | ------------------------------------------------------------------ |
| **xTool D1 Pro** | xTool (वाई-फ़ाई)    | जॉब अपलोड और शुरू करना, होमिंग, जॉग, पॉज़, रिज़्यूम और कैंसल                |
| **xTool M2**     | xTool M2 (वाई-फ़ाई) | मशीन की निगरानी, होमिंग, जॉग, और तैयार जॉब को पॉज़, रिज़्यूम या कैंसल करना |

दोनों ड्राइवर **प्रयोगात्मक** चिह्नित हैं। उत्पादन में भरोसा करने से पहले स्क्रैप टुकड़े पर उनका परीक्षण करें, और समस्या
होने पर डिबग लॉग के साथ रिपोर्ट करें।

## xTool मशीन सेट करना

1. मशीन को अपने कंप्यूटर के समान नेटवर्क से जोड़ें और उसका IP पता पता करें (उदाहरण के लिए xTool ऐप में या राउटर की
   डिवाइस सूची में)।
2. मशीन जोड़ें और **xTool D1 Pro** या **xTool M2** प्रोफ़ाइल चुनें। प्रोफ़ाइल ड्राइवर और मशीन के आयाम पहले से सेट
   कर देता है।
3. मशीन का **होस्टनेम या IP पता** दर्ज करें।
4. जब तक आपका नेटवर्क कुछ और न कहे, पोर्ट को उनके डिफ़ॉल्ट मान पर रखें:
   - D1 Pro: HTTP पोर्ट `8080`, WebSocket पोर्ट `8081`
   - M2: पोर्ट `28900`
5. कनेक्ट करें।

यदि Rayforge कहता है कि किसी xTool मशीन ने उत्तर नहीं दिया, तो IP पता जाँचें, मशीन चालू है या नहीं देखें, और पुष्टि
करें कि कंप्यूटर और मशीन एक ही नेटवर्क पर हैं।

## D1 और D1 Pro

**xTool (वाई-फ़ाई)** ड्राइवर जॉब को मशीन पर अपलोड करता है, शुरू करता है और WebSocket जॉब इवेंट के माध्यम से
प्रगति देखता है। होमिंग, जॉग और निरपेक्ष मूव, पॉज़, रिज़्यूम और कैंसल सामान्य रूप से काम करते हैं।

मशीन का नेटवर्क API अपनी स्थिति नहीं बताता, इसलिए Rayforge जॉब स्थिति से स्थिति प्रदर्शन चलाता है। होमिंग एक
साथ सभी अक्षों के लिए उपलब्ध है; प्रति-अक्ष होमिंग बंद है। फ़र्मवेयर सेटिंग्स, वर्क कोऑर्डिनेट ऑफ़सेट और प्रोबिंग इस ड्राइवर
द्वारा समर्थित नहीं हैं।

## xTool M2

**xTool M2 (वाई-फ़ाई)** ड्राइवर पोर्ट `28900` पर M2 की TLS सेवा से जुड़ता है। यह मशीन की स्थिति की निगरानी
करता है और होमिंग, जॉग, तथा मशीन पर पहले से तैयार जॉब को पॉज़, रिज़्यूम या कैंसल करने का समर्थन करता है।

M2 का नेटवर्क API अभी G-code प्राप्त नहीं कर सकता, इसलिए Rayforge अपनी जॉब उसे नहीं भेज सकता। जॉब को xTool
Studio में तैयार करें, वहीं से शुरू करें, और निगरानी व नियंत्रण के लिए Rayforge का उपयोग करें। Z मूव, टूल चेंज, रिमोट
लेज़र पावर नियंत्रण, फ़र्मवेयर सेटिंग्स और वर्क कोऑर्डिनेट ऑफ़सेट समर्थित नहीं हैं।

## TLS प्रमाणपत्र

M2 ड्राइवर मशीन का TLS प्रमाणपत्र सत्यापित करता है। यदि मशीन स्व-हस्ताक्षरित प्रमाणपत्र का उपयोग करती है, तो
ड्राइवर सेटिंग्स में **अमान्य TLS प्रमाणपत्र अनुमत करें** सक्षम करें। ऐसा केवल उस नेटवर्क पर करें जिस पर आप भरोसा करते हैं।
