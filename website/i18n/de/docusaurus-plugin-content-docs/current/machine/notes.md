# Notizen

Die Seite „Notizen" in den Maschineneinstellungen hält alle Informationen über deine Maschine an
einem Ort fest. Sie kombiniert deine eigenen Notizen mit den Hinweisen, die mit dem Geräteprofil
deiner Maschine mitgeliefert werden.

![Notizen-Einstellungen](/screenshots/machine-settings-notes.webp)

## Meine Notizen

„Meine Notizen" ist dein persönliches Notizbuch für die Maschine — durchgeführte Wartung,
Einstellungen, die für ein Material gut funktioniert haben, Ersatzteilbestellungen oder alles
andere, was es sich zu merken lohnt. Notizen werden in Markdown geschrieben und direkt auf der Seite
dargestellt.

Klicke auf **Eigene Notizen bearbeiten**, um den Editor zu öffnen. Er zeigt das rohe Markdown links
und eine Live-Vorschau rechts, mit einer Symbolleiste für die unterstützten Formatierungen:
Überschriften, fetter und kursiver Text, Aufzählungs- und nummerierte Listen, Links, Inline-Code,
Codeblöcke, Zitate und ausklappbare Detailabschnitte. Das Layout lässt sich zwischen nebeneinander
und gestapelt umschalten.

![Eigene Notizen bearbeiten](/screenshots/machine-settings-notes-editor.webp)

Deine Notizen werden mit der Maschine gespeichert und niemals von Geräteprofil-Aktualisierungen
überschrieben — ein Profil-Update lässt sie unangetastet.

## Gerätehinweise

Maschinen, die aus einem Geräteprofil erstellt wurden, das Einrichtungshinweise mitliefert, zeigen
diese hier als schreibgeschützte Gerätehinweise — zum Beispiel Schritt-für-Schritt-Anleitungen zur
Einrichtung oder Verwendungstipps für genau diese Maschine. Die Gruppe ist ausgeblendet, wenn das
Profil keine Hinweise mitliefert.

Gerätehinweise werden vom Profil gepflegt: Wird das Profil aktualisiert, werden die Hinweise
automatisch aktualisiert. Sie lassen sich hier nicht bearbeiten.

## Konfigurations-Assistent

Wenn du eine Maschine mit dem [Einrichtungsassistenten](../getting-started/first-time-setup.md)
erstellst, werden die Hinweise des Profils auf der Überprüfungsseite angezeigt, bevor die Maschine
erstellt wird, sodass du sie während der Einrichtung lesen kannst. Danach bleiben sie auf der
Notizen-Seite verfügbar.
