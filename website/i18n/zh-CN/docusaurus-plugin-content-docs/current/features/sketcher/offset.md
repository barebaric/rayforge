# 偏移轮廓

偏移工具（`O+F`）按给定距离放大或缩小选中的轮廓，或将开放路径扩展为槽形。选择构成轮廓的实体（或双击以选择相连的几何图形），然后按
`O+F`，或使用饼形菜单中的 **偏移** 项。

![偏移轮廓对话框](/screenshots/addons-sketcher-offset-dialog.webp)

对话框要求输入偏移距离，并在你输入时在画布上实时预览结果：

- **闭合轮廓**在距离为正时放大，为负时缩小。偏移超过轮廓将塌缩的程度时会被拒绝。
- **开放路径**会变成给定宽度的闭合槽形轮廓，两端带有圆形端帽。

![贝塞尔轮廓](/screenshots/addons-sketcher-offset-before.webp)
![偏移为槽形的贝塞尔曲线](/screenshots/addons-sketcher-offset-after.webp)

偏移会用结果替换选中的轮廓：

- 孤立的圆、弧和椭圆保持其实体类型并就地更新，因此它们仍像以前一样可编辑、可约束。
- 相连线段组成的链条（包括贝塞尔曲线）会被多边形实体替换。多边形作为整体编辑：拖动其中心点可移动它，拖动控制柄点可旋转或等比缩放它。

如果选中内容包含多个互不相连的轮廓，每个轮廓会在一步中独立偏移。
