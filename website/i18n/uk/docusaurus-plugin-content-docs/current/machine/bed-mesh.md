# Мережа столу

Великі робочі поверхні рідко бувають ідеально рівними. Коли висота столу змінюється більше, ніж
глибина фокусу вашого лазера, різи виходять неоднаковими по всьому матеріалу. Функція мережі столу
досліджує висоту поверхні по сітці та компенсує вісь Z траєкторії, щоб точка фокусу слідкувала за
реальною поверхнею.

![Мережа столу](/screenshots/machine-settings-bed-mesh.webp)

## Вимоги

Для мережі столу потрібна машина з віссю Z та драйвер із підтримкою зондування (наразі GRBL, Marlin,
Smoothie та OctoPrint). Сторінка **Мережа столу** з'являється у **Налаштування → Машина** лише коли
виконуються обидві умови. Вона розташована після сторінки пристрою.

## Зондування столу

Відкрийте **Налаштування → Машина** та перейдіть на сторінку **Мережа столу**.

1. **Сітка зондування**: Визначте область зондування (початок X/Y, ширина, висота) та щільність
   сітки (стовпці та рядки). Сторінка показує кількість точок зондування та орієнтовну тривалість.
   Щільніші сітки точніше слідкують за поверхнею, але потребують більше часу.
2. **Зондування**: Налаштуйте швидкість подачі зондування, наскільки глибоко голова може опускатися
   у пошуку поверхні в кожній точці (Максимальний хід) та безпечну висоту Z для переміщень між
   точками.
3. Натисніть **Почати зондування**. Машина відвідує кожну точку сітки серпантинним порядком і
   торкається поверхні в кожній; 3D-перегляд заповнюється в реальному часі в міру надходження
   результатів. Ви можете зупинити процес будь-коли; мережа зберігається лише після завершення всієї
   сітки.

Мережа зберігається разом із профілем машини та відображається як кольорова 3D-поверхня: сині
ділянки нижчі, червоні — вищі. Якщо компенсація висоти вам більше не потрібна, видаліть мережу
кнопкою **Видалити мережу**.

:::note Під час зондування голова переміщується по всій області сітки. Приберіть зі столу предмети,
які можуть зашкодити зонду, та переконайтеся, що наконечник зонда (або лазерний перехрестя) може
досягти поверхні в кожній точці сітки. :::
