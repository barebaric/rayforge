# Notas

La página de Notas en Configuración de Máquina mantiene toda la información sobre tu máquina en un
solo lugar. Combina tus propias notas con la guía que incluye el perfil de dispositivo de tu
máquina.

![Ajustes de Notas](/screenshots/machine-settings-notes.webp)

## Mis notas

Mis notas es tu cuaderno personal para la máquina: el mantenimiento que has realizado, los ajustes
que funcionaron bien con un material, los pedidos de repuestos o cualquier otra cosa que merezca la
pena recordar. Las notas se escriben en Markdown y se muestran directamente en la página.

Haz clic en **Editar mis notas** para abrir el editor. Muestra el Markdown sin formato a la
izquierda y una vista previa en vivo a la derecha, con una barra de herramientas para el formato
compatible: encabezados, texto en negrita y cursiva, listas con viñetas y numeradas, enlaces, código
en línea, bloques de código, citas y secciones de detalles expandibles. El diseño se puede cambiar
entre lado a lado y apilado.

![Editar mis notas](/screenshots/machine-settings-notes-editor.webp)

Tus notas se almacenan con la máquina y nunca se sobrescriben por actualizaciones del perfil de
dispositivo, por lo que una actualización del perfil las deja intactas.

## Notas del dispositivo

Las máquinas creadas a partir de un perfil de dispositivo que incluye una guía de configuración la
muestran aquí como Notas del dispositivo de solo lectura: por ejemplo, instrucciones paso a paso de
configuración o consejos de uso para esa máquina concreta. El grupo se oculta en las máquinas sin
guía del perfil.

Las Notas del dispositivo las mantiene el perfil: cuando el perfil se actualiza, la guía se
actualiza automáticamente. No se pueden editar aquí.

## Asistente de Configuración

Cuando creas una máquina con el
[asistente de configuración](../getting-started/first-time-setup.md), la guía del perfil se muestra
en la página de revisión antes de crear la máquina, para que puedas leerla durante la configuración.
Después sigue estando disponible en la página de Notas.
