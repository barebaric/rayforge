# Віддалені пристрої

Керуйте машиною з невеликого комп'ютера біля обладнання (наприклад, Raspberry Pi у майстерні), поки
Rayforge працює на вашому ноутбуці чи настільному комп'ютері. Завдання виконуються на хості пристрою
й тривають, навіть якщо Rayforge відключається; повторне підключення точно синхронізує прогрес.

## Як це працює

- **Демон raydriver** обслуговує з'єднання з машиною біля обладнання.
- Rayforge підключається до _пристрою на демоні_ — йому не потрібно знати, яким протоколом
  спілкується пристрій. Демон визначає це та повідомляє Rayforge, що вміє пристрій.
- Віддалені машини використовують єдиний драйвер **Remote machine (raydriver)**. Протокол-специфічні
  драйвери (GRBL, Smoothie, Marlin) призначені для обладнання, підключеного безпосередньо до вашого
  комп'ютера.

## Налаштування хоста пристрою

1. Встановіть raydriver на хості пристрою: `pip install raydriver` (додайте `[daemon]` для виявлення
   в мережі).
2. Виконайте `raydriver daemon add /dev/ttyUSB0` (використовуйте послідовний порт вашої машини;
   `raydriver scan` перелічує їх). Це створює конфігурацію зі згенерованим токеном і реєструє
   пристрій. Додайте `--protocol`/`--baudrate` для нестандартної прошивки.
3. Виконайте `raydriver daemon install`, щоб встановити й запустити фонову службу (systemd у Linux,
   launchd у macOS, завдання входу у Windows), або запустіть `raydriver daemon` на передньому плані.
4. Для доступу з LAN створіть сертифікат за однорядковою командою `openssl`, яку виводить
   `raydriver daemon --setup`, і встановіть `tls_cert` та `tls_key` у конфігурації. Демон на
   не-loopback адресі не запускається без токена й TLS.

Повний довідник дивіться в
[посібнику демона raydriver](https://github.com/barebaric/raydriver/blob/main/docs/daemon.md).

## Підключення Rayforge

- Майстер машин виявляє демони в мережі та перелічує їхні пристрої; виберіть один, щоб додати.
- Або додайте машину вручну з драйвером **Remote machine (raydriver)**: введіть ім'я хоста, порт і
  токен демона, потім виберіть пристрій зі списку, зчитаного з демона.
- Зондування працює через віддалене з'єднання, тож майстер може ідентифікувати обладнання, не
  підключене до вашого комп'ютера.

## Завдання та повторні підключення

- Надіслане завдання виконується до завершення на хості пристрою, навіть якщо Rayforge закрито або
  мережа зникла.
- Підключіться знову, щоб бачити точний прогрес. Контроль утримує один клієнт за раз; інші можуть
  спостерігати.

## Камери на хості пристрою

Відео не передається через керувальне з'єднання. Використовуйте [мережеві камери](camera.md)
Rayforge з потоком, доступним на хості пристрою:

- **IP-камера**: додайте її URL потоку безпосередньо.
- **USB-камера на хості пристрою**: запустіть стандартний стример, як-от `ustreamer`, і додайте його
  MJPEG URL як камеру HTTP-потоку.

Демон оголошує налаштовані кінцеві точки камер, щоб майстер міг попередньо заповнити URL.

## Примітки щодо безпеки

- Лише LAN (або тунель) — без хмари, без облікових записів.
- Токен і TLS обов'язкові для будь-якого не-loopback демона.
- Тримайте потоки камер лише в LAN або за фаєрволом; вони відокремлені від керувального каналу TLS.
