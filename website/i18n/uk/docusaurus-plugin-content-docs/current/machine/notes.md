# Нотатки

Сторінка "Нотатки" у налаштуваннях машини зберігає всю інформацію про вашу машину в одному місці.
Вона поєднує ваші власні нотатки з настановами, що додаються до профілю пристрою вашої машини.

![Налаштування нотаток](/screenshots/machine-settings-notes.webp)

## Мої нотатки

"Мої нотатки" — це ваш особистий зошит для машини: виконане технічне обслуговування, налаштування,
що добре працювали з певним матеріалом, замовлення запчастин або будь-що інше, варте
запам'ятовування. Нотатки пишуться у Markdown і показуються безпосередньо на сторінці.

Натисніть **Редагувати мої нотатки**, щоб відкрити редактор. Він показує сирий Markdown ліворуч і
живий перегляд праворуч, з панеллю інструментів для підтримуваного форматування: заголовки,
напівжирний і курсивний текст, марковані та нумеровані списки, посилання, вбудований код, блоки
коду, цитати та розгортані розділи деталей. Розташування можна перемикати між поруч і стосом.

![Редагувати мої нотатки](/screenshots/machine-settings-notes-editor.webp)

Ваші нотатки зберігаються разом з машиною і ніколи не перезаписуються оновленнями профілю пристрою,
тож оновлення профілю залишає їх недоторканими.

## Нотатки пристрою

Машини, створені з профілю пристрою, що містить настанови з налаштування, показують їх тут як
придатні лише для читання Нотатки пристрою — наприклад, покрокові інструкції з налаштування або
поради з використання для саме цієї машини. Група прихована для машин, чий профіль не містить
настанов.

Нотатки пристрою підтримуються профілем: коли профіль оновлюється, настанови оновлюються
автоматично. Їх не можна редагувати тут.

## Майстер конфігурації

Коли ви створюєте машину за допомогою
[майстра налаштування](../getting-started/first-time-setup.md), настанови профілю показуються на
сторінці перегляду до створення машини, тож ви можете прочитати їх під час налаштування. Після цього
вони залишаються доступними на сторінці Нотатки.
