# Налаштування лазера

Сторінка "Лазер" у налаштуваннях машини налаштовує ваші лазерні головки та їхні властивості.

![Налаштування лазера](/screenshots/machine-settings-laser.webp)

## Лазерні головки

Rayforge підтримує машини з кількома лазерними головками. Кожна лазерна головка має власну
конфігурацію.

### Додавання лазерної головки

Натисніть кнопку **Додати лазер**, щоб створити нову конфігурацію лазерної головки.

### Властивості лазерної головки

Кожна лазерна головка має наступні налаштування:

#### Назва

Описова назва для цієї лазерної головки.

Приклади:

- "10W Діод"
- "CO2 Трубка"
- "Інфрачервоний лазер"

#### Номер інструменту

Індекс інструменту для цієї лазерної головки. Використовується в G-code з командою T.

- Машини з однією головкою: Використовуйте 0
- Машини з кількома головками: Призначте унікальні номери (0, 1, 2 тощо)

#### Максимальна потужність

Максимальне значення потужності для вашого лазера.

- **Типово для GRBL**: 1000 (діапазон S0-S1000)
- **Деякі контролери**: 255 (діапазон S0-S255)
- **Режим відсотків**: 100 (діапазон S0-S100)

Це значення має відповідати налаштуванню $30 вашої прошивки.

#### Потужність обведення

Рівень потужності, що використовується для операцій обведення (контур без різання).

- Встановіть на 0, щоб вимкнути обведення
- Налаштуйте відповідно до вашого лазера та матеріалу

#### Швидкість обведення

Швидкість, з якою лазерна головка рухається під час обведення. Встановлюється окремо для кожної
лазерної головки, тому якщо ваша машина має кілька лазерів з різними характеристиками, ви можете
обрати відповідну швидкість для кожного. Повільніші швидкості полегшують візуальне відстеження шляху
обведення.

#### Потужність фокусу

Рівень потужності, що використовується коли увімкнено режим фокусу. Режим фокусу вмикає лазер на
низькій потужності, щоб діяти як "лазерний вказівник" для позиціонування.

- Встановіть на 0, щоб вимкнути функцію режиму фокусу
- Використовуйте для візуального вирівнювання та позиціонування

:::tip Використання режиму фокусу Натисніть кнопку фокусу (іконка лазера) на панелі інструментів,
щоб перемкнути режим фокусу. Лазер увімкнеться на цьому рівні потужності, допомагаючи вам точно
бачити, де позиціоновано лазер. Дивіться
[Позиціонування заготовки](../features/workpiece-positioning.md) для отримання додаткової
інформації. :::

#### Розмір плями

Фізичний розмір сфокусованого променя вашого лазера в міліметрах.

- Введіть розміри X та Y
- Більшість лазерів мають круглу пляму (наприклад, 0.1 x 0.1)
- Впливає на розрахунки якості гравірування

:::tip Вимірювання розміру плями Для вимірювання розміру плями:

1. Випустіть короткий імпульс на низькій потужності на тестовому матеріалі
2. Виміряйте отриману позначку штангенциркулем
3. Використовуйте середнє з кількох вимірювань :::

#### Колір

Колір, що використовується для відображення операцій цього лазера (різання та гравірування) на
полотні та в 3D перегляді. Це допомагає візуально розрізняти, який лазер виконуватиме кожну операцію
при роботі з кількома лазерними головками.

- Натисніть на зразок кольору, щоб відкрити палітру кольорів
- Виберіть колір, який добре контрастує з попереднім переглядом матеріалу
- Кольори за замовчуванням призначаються автоматично

:::tip Багатолазерні робочі процеси При використанні кількох лазерних головок призначення різних
кольорів кожному лазеру полегшує перегляд того, які операції будуть виконуватися яким лазером.
Наприклад, використовуйте червоний для основного лазера різання та синій для вторинного лазера
гравірування. :::

#### Тип лазера

Виберіть тип лазерної головки з випадаючого списку:

- **Діод**: Стандартні діодні лазери (найпоширеніші для хобі-машин)
- **CO2**: CO2 трубчасті лазери
- **Fiber**: Волоконні лазери

При виборі CO2 або Fiber стають доступними додаткові **налаштування ШІМ** (див. нижче). Для діодних
лазерів розділ ШІМ приховано, оскільки він не застосовується.

Тип лазера також встановлює типову **довжину хвилі** (що використовується фізичною моделлю
випалювання), якщо нижче не введено явне значення.

#### Довжина хвилі (нм)

Довжина випромінювання вашого лазера в нанометрах. Вона живить
[фізичну модель випалювання](../ui/3d-preview.md#physical-burn-model) у 3D-перегляді: разом з даними
[поглинання](../application-settings/materials.md#absorption) матеріалу визначає, скільки лазерної
енергії поглинає заготовка.

Якщо встановлено 0, Rayforge повертається до типової довжини хвилі для обраного типу лазера
(наприклад, 445 нм для діодного, 1064 нм для волоконного, 10600 нм для CO2).

#### Макс. оптична потужність (Вт)

Оптична вихідна потужність вашого лазера на повній потужності, у ватах. Це фактичний світловий
вихід, а не електричний вхід. Разом з розміром плями та швидкістю сканування визначає флуенцію
(Дж/см²), що використовується
[фізичною моделлю випалювання](../ui/3d-preview.md#physical-burn-model).

Якщо встановлено 0, використовується типове значення для настільного лазера середнього класу.

#### Налаштування ШІМ

При виборі типу лазера CO2 або Fiber з'являються наступні елементи керування ШІМ:

- **Частота ШІМ**: Типова частота ШІМ у Гц для цієї лазерної головки. Типові значення від 500 Гц до
  кількох кГц залежно від вашого контролера та джерела живлення.
- **Макс. частота ШІМ**: Верхня межа для налаштування частоти. Це запобігає введенню значень, які
  ваше обладнання не може обробити.
- **Тривалість імпульсу**: Типова тривалість імпульсу в мікросекундах. Це контролює, як довго кожен
  імпульс увімкнений протягом циклу.
- **Мін/Макс тривалість імпульсу**: Межі для налаштування тривалості імпульсу.

Ці типові значення передаються до ваших операційних кроків, де їх можна перевизначити для кожного
кроку за потреби.

#### Зсув вказівника

Якщо ваша машина має окремий лазерний вказівник (маленький лазер із червоною точкою), встановлений
на фіксованій відстані від різального променя, ви можете повідомити Rayforge цю відстань, щоб він її
компенсував.

- **Використовувати зсув вказівника**: вмикає компенсацію. Типово вимкнено.
- **Зсув вказівника X / Y**: відстань у міліметрах від точки різального променя до точки вказівника
  вздовж осей X та Y машини.

Коли зсув увімкнено, змінюються три речі:

1. **Встановити нуль у поточній позиції** (та кнопки Нуль X / Нуль Y) розміщує початок робочих
   координат там, де _точка вказівника_ позначає заготовку, а не там, де знаходиться (невидимий)
   різальний промінь.
2. Полотно показує жовту точку вказівника поруч із червоною точкою променя, позначаючи, де точка
   вказівника знаходиться на вашому матеріалі.
3. У спливальному вікні переміщення стає доступним перемикач **Вирівнювання за вказівником** (див.
   нижче).

#### Вирівнювання за вказівником

Вирівнювання за вказівником — це перемикач часу виконання у спливальному вікні переміщення (іконка
компаса поруч із показами позиції). Коли він увімкнений, усі абсолютні операції прицілювання —
Перемістити до, ярлики кутів, перехід до початку СКР, Клік для переміщення, Перемістити голову сюди
та обрамлення — зміщуються так, щоб _точка вказівника_ опинилася в приціленій позиції. Точка
вказівника на полотні малюється заповненою, коли вирівнювання увімкнено, і порожньою, коли вимкнено.

Типовий робочий процес:

1. Перемістіть машину, доки точка вказівника не позначить реперну точку на заготовці.
2. **Встановіть там робочий нуль** — з увімкненим зсувом вказівника початок координат опиниться
   точно там, де вказував вказівник.
3. Увімкніть **Вирівнювання за вказівником** у спливальному вікні переміщення.
4. Обрамляйте та переміщуйтеся за точкою вказівника: все, у що ви прицілюєтеся, позначається
   вказівником.
5. Коли ви натискаєте **Надіслати**, попередження нагадує, що завдання випалює променем у позиціях
   СКР — ви можете вимкнути вирівнювання та випалити, усе одно випалити або скасувати.

Дві речі ніколи не зміщуються: **jog** (відносний рух не потребує компенсації) та **завдання** —
різання завжди відбувається променем у позиціях СКР, тож ваш вивід G-коду ідентичний, чи ввімкнено
вирівнювання, чи ні. Разом із нуляванням за точкою вказівника це залишається узгодженим: початок
координат знаходиться в `промінь + зсув`, прицілювання зміщує кожну ціль на `-зсув`, а випалювання
не зміщується.

Вирівнювання за вказівником — це налаштування сесії: воно не зберігається в профілі машини та
скидається під час переключення машини.

<!-- prettier-ignore-start -->
:::tip[Вимірювання зсуву]
1. Перемістіть машину, доки точка вказівника не позначить видиму точку на
   заготовці.
2. Увімкніть режим фокусу та переміщуйтеся, доки *різальний промінь* не випалить
   позначку точно в тому самому місці (або обережно перемістіть промінь туди на
   потужності фокусу).
3. Зсув — це позиція вказівника мінус позиція променя. Наприклад, якщо вказівник
   позначив X=100, а вам довелося перемістити промінь до X=88, щоб влучити в те
   саме місце, введіть X = 12.0 — точка вказівника стоїть на 12 мм попереду
   променя.

Якщо тестовий розріз вийшов зі зсувом, змініть знак відповідної осі.
:::

#### 3D модель

Кожна лазерна головка може мати призначену 3D модель. Ця модель відображається у
[3D виді](../ui/3d-preview.md) та слідує за траєкторією під час симуляції.

Натисніть на рядок вибору моделі, щоб переглянути доступні моделі. Після вибору моделі ви можете
налаштувати її масштаб, обертання (X/Y/Z) та фокусну відстань відповідно до вашої фізичної лазерної
головки.
