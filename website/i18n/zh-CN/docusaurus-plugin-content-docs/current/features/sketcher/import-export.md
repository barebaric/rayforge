# 导入和导出

## 导出对象

您可以将任何选定的工件导出为多种矢量格式：

1. 在画布上选择一个工件
2. 选择**对象 → 导出对象...**（或右键点击并从上下文菜单中选择）
3. 选择导出格式：
   - **RFS (.rfs)**：Rayforge 原生参数化草图格式——保留所有约束，可重新导入进行编辑
   - **SVG (.svg)**：标准矢量格式——与设计软件广泛兼容
   - **DXF (.dxf)**：CAD 交换格式——与大多数 CAD 应用程序兼容

## 保存草图

您可以将 2D 草图保存到文件中，以便在其他项目中重用。保存时会保留所有参数化约束，确保您的设计保持其几何关系。

## 导入草图

保存的草图可以导入到任何工作区，允许您创建常用设计元素的库。导入过程会保持所有约束和尺寸关系。
