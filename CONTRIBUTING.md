# Contributing to Rayforge

Thank you for your interest in contributing!

- **Bugs and feature ideas:** open a
  [GitHub issue](https://github.com/barebaric/rayforge/issues/new/choose).
- **Code changes:** read the
  [developer documentation](https://rayforge.org/docs/developer/getting-started)
  to learn how to build, test, and lint your changes.
- **Pull requests** must follow the
  [pull request template](.github/PULL_REQUEST_TEMPLATE.md). PRs that do not
  fill it out are rejected.

## AI-Assisted Code

We welcome the use of AI tools to help write code. However, you are strictly
responsible for the code you submit. You MUST fully understand it and must be
able to explain the architectural choices.

AI-generated code often introduces subtle bugs, architectural mismatches, and
security flaws. PRs that appear to be raw, unreviewed AI output will be closed
to respect maintainer time.
