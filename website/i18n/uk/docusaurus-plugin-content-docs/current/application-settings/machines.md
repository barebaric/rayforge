# Машини

![Налаштування машин](/screenshots/app-settings-machines.webp)

Сторінка «Машини» в налаштуваннях додатку показує список усіх налаштованих машин. Кожен запис
містить назву машини та кнопки для редагування або видалення. Поточна активна машина позначена
іконкою галочки.

## Додавання машини

1. Натисніть кнопку **Add Machine** у нижній частині списку
2. Виберіть профіль пристрою зі списку як шаблон — кожен профіль попередньо налаштовує параметри
   машини та діалект G-code

![Додавання машини](/screenshots/app-settings-machines-add.webp)

3. Відкриється [діалог налаштувань машини](../machine/general.md), де ви зможете скоригувати
   конфігурацію

Крім того:

- Натисніть **Device Not Listed**, щоб запустити
  [Майстер конфігурації](../getting-started/first-time-setup.md), який проведе вас через
  налаштування машини крок за кроком
- Натисніть **Import from File…**, щоб додати машину з раніше експортованого профілю або з профілю
  пристрою LightBurn (.lbdev). Профілі LightBurn містять калібрування камери та налаштування лазера,
  які застосовуються до нової машини.

## Редагування машини

Натисніть іконку редагування поруч із машиною, щоб відкрити
[діалог налаштувань машини](../machine/general.md).

## Нотатки машини

Категорія **Notes**, одразу після **General**, об’єднує рекомендації з профілю пристрою та ваші
власні нотатки для цієї машини. Нотатки пристрою доступні лише для читання; **My Notes** можна
редагувати за допомогою Markdown. Підтримуються заголовки, абзаци, жирний і курсивний текст, списки,
посилання, вбудований код, блоки коду та розгортані секції з `:::details`.

Якщо профіль містить інструкції з налаштування, вони також з’являються на останній сторінці **Review
& Name** майстра й залишаються доступними в **Machine Settings → Notes** після створення машини.
Особисті нотатки зберігаються окремо для кожної машини та не замінюються під час перегляду оновлень
профілю.

## Перемикання активної машини

Використовуйте випадаючий список машин у заголовку головного вікна для перемикання між налаштованими
машинами. Вибір зберігається між сесіями.

## Видалення машини

1. Натисніть іконку видалення поруч із машиною
2. Підтвердьте видалення

:::warning Видалення машини не можна скасувати. Експортуйте профіль перед видаленням, якщо хочете
зберегти конфігурацію. :::
