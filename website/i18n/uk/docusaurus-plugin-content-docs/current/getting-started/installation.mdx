## Системні вимоги

| Ресурс              | Встановлено   | Рекомендовано           |
|---------------------|---------------|-------------------------|
| Дисковий простір    | < 1 ГБ        | Залежить від проекту    |
| Оперативна пам'ять  | 1 ГБ          | Залежить від проекту    |

Фактичні вимоги до диска та пам'яті залежать від складності проекту. Прості проекти
можуть потребувати небагато більше встановленого обсягу, тоді як складні проекти можуть
легко спожити 10 ГБ оперативної пам'яті або більше та вимагати значного додаткового
дискового простору.

## Вимога до процесора в Linux (x86-64-v2)

Пакети для Linux містять власний NumPy, який вимагає рівня набору інструкцій
x86-64-v2 (SSE4.2 та POPCNT). Це стосується пакетів Snap, Flatpak та
AppImage, а також встановлення через pip з PyPI. На старіших процесорах
x86-64 (Intel Core 2 та старіші, AMD Phenom та старіші) Rayforge не
запускається, зазвичай без повідомлення про помилку. Процесори Intel
починаючи з Nehalem (2008) та AMD починаючи з Bulldozer (2011)
підтримують x86-64-v2.

Перевірити, чи відповідає ваш процесор цій вимозі, можна командою:

```bash
grep -m1 flags /proc/cpuinfo | grep -o -w -E 'sse4_2|popcnt' | sort -u
```

Якщо команда не виводить обидва прапорці, встановіть Rayforge з PPA Ubuntu
або зі сховища пакетів вашого дистрибутива. Ці версії використовують NumPy,
що постачається з вашим дистрибутивом, і працюють на старіших процесорах.
