# डिवाइस सेटिंग्स

मशीन सेटिंग्स का डिवाइस पृष्ठ आपको सेटिंग्स को सीधे अपने जुड़े डिवाइस (नियंत्रक) से पढ़ने और उस पर
लागू करने देता है. GRBL में इन्हें "डॉलर सेटिंग्स" या `$$` सेटिंग्स भी कहा जाता है.

![डिवाइस सेटिंग्स](/screenshots/machine-settings-device.webp)

<!-- prettier-ignore-start -->
:::warning[सेटिंग्स बदलते समय सावधानी]
गलत फ़र्मवेयर सेटिंग्स आपकी मशीन को अप्रत्याशित व्यवहार करा सकती हैं,
स्थिति खो सकती है, या हार्डवेयर नुकसान भी कर सकती हैं. बदलाव करने से पहले हमेशा मूल मान रिकॉर्ड
करें, और एक समय में एक ही सेटिंग संशोधित करें.
:::
<!-- prettier-ignore-end -->

## अवलोकन

डिवाइस पृष्ठ आपके नियंत्रक की फ़र्मवेयर सेटिंग्स तक सीधी पहुँच देता है. यहाँ आप:

- डिवाइस से वर्तमान सेटिंग्स पढ़ सकते हैं
- व्यक्तिगत सेटिंग्स संशोधित कर सकते हैं
- बदलाव डिवाइस पर लागू कर सकते हैं

फ़र्मवेयर सेटिंग्स नियंत्रित करती हैं:

- **मोशन पैरामीटर**: गति सीमाएँ, त्वरण, कैलिब्रेशन
- **लिमिट स्विच**: होमिंग व्यवहार, सॉफ़्ट/हार्ड लिमिट
- **लेज़र नियंत्रण**: शक्ति सीमा, लेज़र मोड सक्षम
- **विद्युत कॉन्फ़िगरेशन**: पिन उलटना, पुलअप
- **रिपोर्टिंग**: स्थिति संदेश फ़ॉर्मेट और आवृत्ति

ये सेटिंग्स आपके नियंत्रक पर (Rayforge में नहीं) संग्रहीत होती हैं और पावर चक्रों में बनी रहती हैं.

## सेटिंग्स पढ़ना

जुड़े नियंत्रक से वर्तमान सेटिंग्स लाने के लिए **डिवाइस से पढ़ें** बटन पर क्लिक करें. इसके लिए
चाहिए:

- मशीन का कनेक्टेड होना
- ड्राइवर द्वारा डिवाइस सेटिंग्स पढ़ने का समर्थन

## सेटिंग्स लागू करना

सेटिंग्स संशोधित करने के बाद, बदलाव डिवाइस पर लागू होते हैं. डिवाइस:

- अस्थायी रूप से रीस्टार्ट हो सकता है
- डिस्कनेक्ट होकर पुनः कनेक्ट हो सकता है
- कुछ बदलावों के लिए पावर चक्र की आवश्यकता हो सकती है

## कंसोल पहुँच

आप G-code कंसोल से भी सेटिंग्स देख/संशोधित कर सकते हैं:

**सभी सेटिंग्स देखें:**

```
$$
```

**एकल सेटिंग देखें:**

```
$100
```

**सेटिंग संशोधित करें:**

```
$100=80.0
```

**डिफ़ॉल्ट पुनर्स्थापित करें:**

```
$RST=$
```

<!-- prettier-ignore-start -->
:::danger[डिफ़ॉल्ट पुनर्स्थापना सभी सेटिंग्स मिटा देती है]
`$RST=$` कमांड सभी GRBL सेटिंग्स को
फ़ैक्टरी डिफ़ॉल्ट पर रीसेट कर देता है. आप कोई भी कैलिब्रेशन और ट्यूनिंग खो देंगे. पहले अपनी
सेटिंग्स का बैकअप लें!
:::
<!-- prettier-ignore-end -->

## लेज़रों के लिए महत्वपूर्ण सेटिंग्स

ये सेटिंग्स लेज़र संचालन के लिए सबसे महत्वपूर्ण हैं:

### $32 - लेज़र मोड

**मान:** 0 = अक्षम, 1 = सक्षम

**उद्देश्य:** GRBL में लेज़र-विशिष्ट सुविधाएँ सक्षम करता है

**सक्षम होने पर (1):**

- G0 (तीव्र) गतियों के दौरान लेज़र स्वतः बंद हो जाता है
- त्वरण/मंदन के दौरान शक्ति गतिशील रूप से समायोजित होती है
- स्थापना के दौरान अनजाने जलने से रोकता है

**अक्षम होने पर (0):**

- लेज़र स्पिंडल जैसा व्यवहार करता है (CNC मोड)
- तीव्र गतियों के दौरान बंद नहीं होता
- **लेज़र उपयोग के लिए खतरनाक!**

<!-- prettier-ignore-start -->
:::warning[हमेशा लेज़र मोड सक्षम करें]
लेज़र कटरों के लिए $32 को **हमेशा** 1 पर सेट होना चाहिए. अक्षम लेज़र
मोड अनजाने जलन और आग के खतरे पैदा कर सकता है.
:::
<!-- prettier-ignore-end -->

### $30 और $31 - लेज़र शक्ति सीमा

**$30 - अधिकतम लेज़र शक्ति (RPM)**

**$31 - न्यूनतम लेज़र शक्ति (RPM)**

**उद्देश्य:** S कमांडों के लिए शक्ति सीमा परिभाषित करता है

**सामान्य मान:**

- $30=1000, $31=0 (S0-S1000 सीमा, सबसे सामान्य)
- $30=255, $31=0 (S0-S255 सीमा, कुछ नियंत्रक)

<!-- prettier-ignore-start -->
:::tip[Rayforge कॉन्फ़िगरेशन से मेल]
आपकी [लेज़र सेटिंग्स](laser) में "अधिकतम शक्ति" सेटिंग आपके $30 मान से
मेल खानी चाहिए. यदि $30=1000, तो Rayforge में अधिकतम शक्ति 1000 सेट करें.
:::
<!-- prettier-ignore-end -->

### $130 और $131 - अधिकतम चालन

**$130 - X अधिकतम चालन (mm)**

**$131 - Y अधिकतम चालन (mm)**

**उद्देश्य:** आपकी मशीन का कार्य क्षेत्र परिभाषित करता है

**यह क्यों मायने रखता है:**

- सॉफ़्ट लिमिट ($20) टकराव रोकने के लिए इन मानों का उपयोग करते हैं
- निर्देशांक प्रणाली सीमाएँ परिभाषित करता है
- आपकी भौतिक मशीन आकार से मेल खाना चाहिए

## सेटिंग्स संदर्भ

### स्टेपर कॉन्फ़िगरेशन ($0-$6)

स्टेपर मोटर विद्युत सिग्नल और टाइमिंग नियंत्रित करता है.

| सेटिंग | विवरण                      | सामान्य मान |
| ------ | -------------------------- | ----------- |
| $0     | स्टेप पल्स समय (μs)        | 10          |
| $1     | स्टेप निष्क्रिय विलंब (ms) | 25          |
| $2     | स्टेप पल्स उलटें (मास्क)   | 0           |
| $3     | स्टेप दिशा उलटें (मास्क)   | 0           |
| $4     | स्टेप सक्षम पिन उलटें      | 0           |
| $5     | लिमिट पिन उलटें            | 0           |
| $6     | प्रोब पिन उलटें            | 0           |

### लिमिट और होमिंग ($20-$27)

लिमिट स्विच और होमिंग व्यवहार नियंत्रित करता है.

| सेटिंग | विवरण                         | सामान्य मान |
| ------ | ----------------------------- | ----------- |
| $20    | सॉफ़्ट लिमिट सक्षम            | 0 या 1      |
| $21    | हार्ड लिमिट सक्षम             | 0           |
| $22    | होमिंग चक्र सक्षम             | 0 या 1      |
| $23    | होमिंग दिशा उलटें             | 0           |
| $24    | होमिंग लोकेट फ़ीड दर (mm/min) | 25          |
| $25    | होमिंग खोज दर (mm/min)        | 500         |
| $26    | होमिंग डिबाउंस विलंब (ms)     | 250         |
| $27    | होमिंग पुल-ऑफ़ दूरी (mm)      | 1.0         |

### स्पिंडल और लेज़र ($30-$32)

| सेटिंग | विवरण               | लेज़र मान |
| ------ | ------------------- | --------- |
| $30    | अधिकतम स्पिंडल गति  | 1000.0    |
| $31    | न्यूनतम स्पिंडल गति | 0.0       |
| $32    | लेज़र मोड सक्षम     | 1         |

### अक्ष कैलिब्रेशन ($100-$102)

परिभाषित करता है कि एक मिलीमीटर गति के बराबर कितने स्टेपर मोटर स्टेप हों.

| सेटिंग | विवरण      | नोट                           |
| ------ | ---------- | ----------------------------- |
| $100   | X स्टेप/mm | पुली/बेल्ट अनुपात पर निर्भर   |
| $101   | Y स्टेप/mm | प्रायः X जैसा ही              |
| $102   | Z स्टेप/mm | अधिकांश लेज़रों पर उपयोग नहीं |

**स्टेप/mm की गणना:**

```
steps/mm = (motor_steps_per_rev × microstepping) / (pulley_teeth × belt_pitch)
```

**उदाहरण:** 200 स्टेप/rev, 16 माइक्रोस्टेपिंग, 20 दाँत पुली, GT2 बेल्ट:

```
steps/mm = (200 × 16) / (20 × 2) = 3200 / 40 = 80
```

### अक्ष चालन ($130-$132)

| सेटिंग | विवरण              | नोट                  |
| ------ | ------------------ | -------------------- |
| $130   | X अधिकतम चालन (mm) | कार्य क्षेत्र चौड़ाई |

## सामान्य कॉन्फ़िगरेशन उदाहरण

### सामान्य डायोड लेज़र (300×400mm)

```gcode
$0=10          ; Step pulse 10μs
$1=255         ; Step idle delay 255ms
$2=0           ; No step invert
$3=0           ; No direction invert
$4=0           ; No enable invert
$5=0           ; No limit invert
$10=1          ; Report WPos
$11=0.010      ; Junction deviation 0.01mm
$12=0.002      ; Arc tolerance 0.002mm
$13=0          ; Report mm
$20=1          ; Soft limits enabled
$21=0          ; Hard limits disabled
$22=1          ; Homing enabled
$23=0          ; Home to min
$24=50.0       ; Homing feed 50mm/min
$25=1000.0     ; Homing seek 1000mm/min
$26=250        ; Homing debounce 250ms
$27=2.0        ; Homing pull-off 2mm
$30=1000.0     ; Max power S1000
$31=0.0        ; Min power S0
$32=1          ; Laser mode ON
$100=80.0      ; X steps/mm
$101=80.0      ; Y steps/mm
$102=80.0      ; Z steps/mm
$110=5000.0    ; X max rate
$111=5000.0    ; Y max rate
$112=500.0     ; Z max rate
$120=500.0     ; X accel
$121=500.0     ; Y accel
$122=100.0     ; Z accel
$130=400.0     ; X max travel
$131=300.0     ; Y max travel
$132=0.0       ; Z max travel
```

## सेटिंग्स का बैकअप

### बैकअप प्रक्रिया

1. **Rayforge द्वारा:**
   - डिवाइस सेटिंग्स पैनल खोलें
   - "Export Settings" पर क्लिक करें
   - फ़ाइल को `grbl-backup-YYYY-MM-DD.txt` के रूप में सहेजें

2. **कंसोल द्वारा:**
   - `$$` कमांड भेजें
   - सारा आउटपुट टेक्स्ट फ़ाइल में कॉपी करें
   - तिथि के साथ सहेजें

### पुनर्स्थापना प्रक्रिया

1. बैकअप फ़ाइल खोलें
2. कंसोल द्वारा प्रत्येक पंक्ति भेजें (`$100=80.0` आदि)
3. `$$` कमांड से सत्यापित करें

<!-- prettier-ignore-start -->
:::tip[नियमित बैकअप]
किसी भी कैलिब्रेशन या ट्यूनिंग के बाद अपनी सेटिंग्स का बैकअप लें. बैकअप
सुरक्षित स्थान पर रखें.
:::
