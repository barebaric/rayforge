# 波前

波前自适应清除使用从口袋中心向外扩展的同心刀具路径填充闭合矢量形状，
就像池塘中的涟漪。扩展的环会自动处理内部岛屿，并产生平滑、连续的
刀具路径，没有光栅扫描那种急剧的方向反转。

## 概述

与传统光栅雕刻沿平行线来回扫描不同，波前生成从每个口袋中心辐射的
同心通道。这会产生均匀、涟漪般的光洁度，非常适合填充图案本身对视觉
效果有所贡献的应用。

波前操作：

- 用同心通道填充闭合矢量形状（口袋）
- 从口袋中心向外扩展
- 自动绕开内部岛屿（口袋内的孔洞）
- 产生无方向反转的平滑刀具路径

## 何时使用波前

波前是口袋区域的替代填充图案。其同心环比平行光栅线更具视觉美感，
扩展的图案自然契合圆形或有机形状。

对以下情况使用波前自适应清除：

- 填充矢量设计中的口袋
- 印章和模具制作——波前清除背景口袋，同时将凸起特征保留为内部岛屿
- 填充纹理在成品中可见的应用

**不要将波前用于：**

- 沿轮廓切割（改用[轮廓](contour)）
- 填充位图图像（改用[雕刻](engrave)）
- 不存在口袋的薄壁截面

## 创建波前操作

### 第 1 步：选择对象

1. 在画布上导入或绘制闭合矢量形状
2. 选择定义口袋边界的对象
3. 确保形状为闭合路径

### 第 2 步：添加波前操作

- **菜单：** 操作 → 添加波前
- **右键点击：** 上下文菜单 → 添加操作 → 波前

### 第 3 步：配置设置

调整步进和偏移以匹配您的材料和所需光洁度。

## 关键设置

步骤设置对话框包含三个选项卡：**步骤设置**、**激光**和**后处理**。设置按选项卡顺序说明如下。

### 波前设置

![波前步骤设置](/screenshots/step-settings-wavefront-general.png)

*步骤设置*选项卡上的**波前**组控制填充图案。

#### 步进

连续波前通道之间的距离（mm）。较小的值提供更密集的覆盖，通道更多、
作业时间更长。较大的值使通道间距更大，完成速度更快。

**步进默认为激光光斑大小**，范围为 0.05–50.0 mm。

| 步进    | 线密度     | 作业时间 |
| ------- | ---------- | -------- |
| 0.1 mm  | 密集、多线 | 最慢     |
| 0.3 mm  | 中等       | 中等     |
| 1.0 mm+ | 稀疏、少线 | 快速     |

大多数应用的典型值为 0.1–0.5 mm。

#### 偏移

与口袋壁的额外间隙（mm）。在最外层波前通道与边界轮廓之间创建边距。
当单独的[轮廓](contour)通道将完成边缘，或者当您想围绕口袋留下
刻意边框时，这很有用。

范围：0.0–20.0 mm。默认值为 0.0（波前通道延伸至边界）。

### 激光设置

![激光设置](/screenshots/step-settings-wavefront-laser.png)

功率、速度和激光头选择位于步骤设置对话框的**激光**页面。

**功率（%）：**

- 切割的激光强度
- 匹配材料的切割要求

**速度（mm/min）：**

- 激光移动的速度
- 匹配材料的切割速度

## 波前如何工作

1. **进入通道** — 螺旋式进入切入口袋中心，建立初始清除区域
2. **波前扩展** — 从清除的中心开始，同心环向外扩展。每个环超出前一个环配置的步进距离
3. **岛屿处理** — 随着波前增长，它会遇到并绕开任何内部岛屿，使其保持原样
4. **完成** — 扩展持续进行，直到整个口袋区域被覆盖

## 技巧与最佳实践

### 选择步进

- 更密集的覆盖（小步进）意味着更多通道和更长的作业时间
- 稀疏的覆盖（大步进）更快，但会在通道之间留下更多材料
- 根据您的应用权衡密度与作业时间

### 印章和模具制作

波前非常适合印章制作。扩展的同心环自然地清除背景口袋，同时绕开
被视为内部岛屿的凸起特征。

### 与轮廓结合

常见的工作流程是先使用波前清除口袋内部，然后用[轮廓](contour)通道
完成边界以获得干净的边缘。设置偏移以为轮廓切割留出足够的边距。
