# 扩展

![扩展设置](/screenshots/app-settings-addons.webp)

扩展页面显示已安装的扩展并允许您管理它们。

## 概述

扩展是为 Rayforge 添加功能的扩展。它们可以提供：

- 新操作
- 导入/导出过滤器
- 机器驱动程序
- UI 增强
- 材料库

## 在线服务

**启用外部扩展服务**设置用于控制对在线注册表、远程安装以及 Gumroad 和 Patreon 许可证服务的访问。禁用后，内置扩展和已在本地安装的扩展仍然可用，但 Rayforge 不会向外部扩展服务发出请求。

## 已安装的扩展

扩展列表显示所有已安装的扩展，包括：

- **名称**：扩展的显示名称
- **版本**：当前安装的版本
- **描述**：功能的简要描述
- **状态**：启用或禁用

## 扩展详情

![扩展详情视图](/screenshots/app-settings-addons-detail.webp)

点击扩展行——在已安装扩展列表中或扩展注册表对话框中——即可打开其详情视图。详情视图显示：

- **截图**：可滑动的图库（当扩展作者提供截图时）
- **描述**：扩展功能的较长描述，支持 Markdown 格式
- **作者、版本和许可证**
- 扩展仓库的链接
- 根据扩展状态显示**安装**、**更新**或**解锁**操作

截图和长描述从在线注册表加载。当外部扩展服务被禁用或无法访问注册表时，详情视图仍会显示扩展的本地信息。

## 管理扩展

### 安装扩展

1. 点击 **安装** 按钮
2. 选择扩展文件（`.zip` 或扩展存储库）
3. 确认安装（社区扩展需要确认信任警告）
4. 等待安装完成

### 更新扩展

当有更新可用时，扩展注册表对话框中会出现指示器。点击 **更新** 以安装可用更新。

### 移除扩展

1. 选择要移除的扩展
2. 点击 **移除** 按钮
3. 确认移除

<!-- prettier-ignore-start -->
:::warning
移除扩展可能会影响使用其功能的文档。
:::
<!-- prettier-ignore-end -->

## 社区扩展

非 Rayforge 团队创建的扩展会在扩展列表中以专用图标标记为社区扩展。

安装社区扩展时，确认对话框会说明该扩展并非由 Rayforge 本身提供，并显示指向该扩展存储库的链接。请在继续之前在浏览器中打开该链接，以审查代码及其作者。

<!-- prettier-ignore-start -->
:::warning
扩展拥有与 Rayforge 本身相同的计算机和文件访问权限。仅在信任作者时才安装社区扩展。
:::
<!-- prettier-ignore-end -->

## 扩展来源

扩展可以从以下位置安装：

- **存储库**：包含扩展的 Git 存储库
- **官方注册表**：Rayforge 团队策划的扩展
