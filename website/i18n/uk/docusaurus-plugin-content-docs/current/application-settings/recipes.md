# Рецепти та налаштування

![Налаштування рецептів](/screenshots/app-settings-recipes.webp)

Rayforge надає потужну систему рецептів, яка дозволяє створювати, керувати та застосовувати
узгоджені налаштування у ваших проектах лазерного різання. Цей посібник охоплює повний шлях
користувача від створення рецептів у загальних налаштуваннях до їх застосування до операцій та
керування налаштуваннями на рівні кроку.

## Огляд

Система рецептів складається з трьох основних компонентів:

1. **Керування рецептами**: Створення та керування багаторазовими пресетами налаштувань
2. **Керування заготовками**: Визначення властивостей матеріалу та товщини
3. **Налаштування кроків**: Застосування та точне налаштування параметрів для окремих операцій

## Керування рецептами

### Створення рецептів

Рецепти - це іменовані пресети, що містять всі налаштування, необхідні для конкретних операцій. Ви
можете створювати рецепти через інтерфейс основних налаштувань:

#### 1. Доступ до менеджера рецептів

Меню: Редагування → Налаштування, потім виберіть Рецепти

#### 2. Створення нового рецепту

Натисніть "Додати новий рецепт" щоб відкрити діалог редактора рецептів.

**Вкладка "Загальні"** - Встановіть назву та опис рецепту:

![Редактор рецептів - Вкладка "Загальні"](/screenshots/recipe-editor-general.webp)

Заповніть базову інформацію:

- **Назва**: Описова назва (наприклад, "Різання фанери 3мм")
- **Опис**: Опціональний детальний опис

#### 3. Визначення критеріїв застосовності

**Вкладка "Застосовність"** - Визначте, коли цей рецепт має пропонуватися:

![Редактор рецептів - Вкладка "Застосовність"](/screenshots/recipe-editor-applicability.webp)

Усі критерії є опціональними - залиште будь-яке поле у значенні "Будь-який", щоб воно збігалося з
усім:

- **Машина**: Виберіть конкретну машину або залиште "Будь-яка машина"
- **Тип завдання**: Виберіть категорію операцій, до якої застосовується цей рецепт (Різання,
  Гравірування тощо), або залиште "Будь-який", щоб застосовувати до всіх типів завдань
- **Тип кроку**: Обмежте рецепт конкретним типом операції (наприклад, "Контур" або "Растр"). Список
  фільтрується за типами кроків, що підтримують вибраний тип завдання. Залиште "Будь-який тип", щоб
  збігатися з кожним типом кроку в межах завдання
- **Матеріал**: Виберіть тип матеріалу або залиште відкритим для будь-якого матеріалу
- **Діапазон товщини**: Встановіть мінімальні та максимальні значення товщини заготовки

#### 4. Налаштування параметрів

**Вкладка "Налаштування"** - Налаштуйте потужність, швидкість та інші параметри. Коли рецепт
націлений на конкретний **тип кроку**, редактор показує дві сторінки налаштувань: сторінку "Лазер"
зі спільними параметрами процесу (потужність, повітряний асист тощо) та сторінку "Налаштування
кроку" з атрибутами, специфічними для цього типу кроку (наприклад, сторона різання, порядок
різання):

![Редактор рецептів - Вкладка "Лазер"](/screenshots/recipe-editor-laser.webp)

![Редактор рецептів - Вкладка "Налаштування кроку"](/screenshots/recipe-editor-step-settings.webp)

- Вибір лише **типу завдання** (з "Будь-який тип" як типом кроку) показує одну сторінку
  "Налаштування" з параметрами процесу для цього завдання
- Залишення обох у значенні "Будь-який" показує лише базові параметри руху (швидкість різання та
  швидкість переміщення), спільні для всіх кроків

Кожен рядок налаштувань має перемикач застосування (прапорець поруч із рядком):

- **Увімкнено**: рецепт застосовує це налаштування до кроку при застосуванні
- **Вимкнено**: рецепт залишає це налаштування кроку без змін

**Вкладка "Постобробка"** - Зберігайте параметри постобробки (введення/виведення, багатопрохідність,
перекриття та інші трансформатори) у рецепті, щоб вони застосовувалися до цільових кроків:

![Редактор рецептів - Вкладка "Постобробка"](/screenshots/recipe-editor-post-processing.webp)

Кожен трансформатор має перемикач застосування (прапорець поруч із рядком):

- **Увімкнено**: рецепт передає параметри трансформатора кроку (його власний перемикач увімкнення
  визначає, чи його буде ввімкнено чи вимкнено)
- **Вимкнено**: рецепт не впливає на цей трансформатор під час застосування

Коли рецепт націлений на кілька типів кроків, відображаються лише трансформатори, спільні для всіх
них.

### Система підбору рецептів

Rayforge автоматично пропонує та застосовує найбільш відповідні рецепти на основі:

- **Сумісність машини**: Рецепти можуть бути специфічними для машини
- **Сумісність лазерної головки**: Рецепти можуть примусово вказувати конкретну головку на машині
- **Відповідність матеріалу**: Рецепти можуть націлюватися на конкретні матеріали
- **Діапазони товщини**: Рецепти застосовуються в межах визначених обмежень товщини
- **Відповідність типу завдання**: Рецепти прив'язані до конкретних категорій операцій
- **Відповідність типу кроку**: Рецепти можуть націлюватися на конкретний тип операції (наприклад,
  лише на кроки "Контур")

Рецепт збігається лише тоді, коли виконані всі його критерії. Коли створюється новий крок, Rayforge
шукає в бібліотеці рецептів відповідні рецепти та автоматично застосовує найкращий. Система
використовує алгоритм оцінки специфічності для пріоритизації найбільш релевантних рецептів:

1. Специфічні для машини рецепти мають вищий рейтинг, ніж загальні
2. Специфічні для лазерної головки рецепти мають вищий рейтинг
3. Специфічні для матеріалу рецепти мають вищий рейтинг
4. Специфічні для товщини рецепти мають вищий рейтинг
5. Специфічні для типу кроку рецепти мають вищий рейтинг

### Застосування рецептів до кроків

Рецепти застосовуються до кожного кроку окремо. Відкрийте налаштування будь-якого кроку та знайдіть
рядок "Рецепт" у розділі "Загальні":

- **Вибрати...**: Відкриває фільтрований список рецептів. Використовуйте поле пошуку або перемикач
  "Показувати лише сумісні рецепти", щоб звузити список; сумісні рецепти відповідають типу завдання
  кроку, типу кроку, машині та заготовкам у документі. Вибір рецепта застосовує всі його
  налаштування до кроку.
- **Зберегти як...**: Відкриває редактор рецептів, попередньо заповнений поточними налаштуваннями
  кроку, машиною, матеріалом та товщиною. Збереження нового рецепта одразу застосовує його до кроку.
- **Оновити**: З'являється, коли налаштування кроку відхилилися від рецепта, який був застосований
  до нього (наприклад, після ручної зміни значення). Натискання перезаписує збережений рецепт
  поточними налаштуваннями кроку.

Назва поточного застосованого рецепта відображається в цьому рядку. Кроки без застосованого рецепта
позначені як "Ручні налаштування".
