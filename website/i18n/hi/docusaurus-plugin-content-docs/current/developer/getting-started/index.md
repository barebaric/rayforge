# कोड प्राप्त करें

यह गाइड विकास के लिए Rayforge स्रोत कोड प्राप्त करने का तरीका कवर करती है.

## रिपॉज़िटरी फ़ोर्क करें

बदलाव करने के लिए अपनी स्वयं की प्रतिलिपि बनाने के लिए GitHub पर
[Rayforge रिपॉज़िटरी](https://github.com/barebaric/rayforge) फ़ोर्क करें.

## अपना फ़ोर्क क्लोन करें

```bash
git clone https://github.com/YOUR_USERNAME/rayforge.git
cd rayforge
```

## अपस्ट्रीम रिपॉज़िटरी जोड़ें

बदलावों का ट्रैक रखने के लिए मूल रिपॉज़िटरी को अपस्ट्रीम रिमोट के रूप में जोड़ें:

```bash
git remote add upstream https://github.com/barebaric/rayforge.git
```

## रिपॉज़िटरी सत्यापित करें

जाँचें कि रिमोट सही ढंग से कॉन्फ़िगर हैं:

```bash
git remote -v
```

आपको अपना फ़ोर्क (origin) और अपस्ट्रीम रिपॉज़िटरी दोनों दिखने चाहिए.

## अगले चरण

कोड प्राप्त करने के बाद, अपना विकास वातावरण कॉन्फ़िगर करने के लिए [सेटअप](setup) के साथ जारी रखें.
