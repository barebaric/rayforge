# 工件定位指南

本指南涵盖了 Rayforge 中所有可用于精确定位工件和在切割或雕刻前对齐设计的方法。

## 概述

精确的工件定位对于以下方面至关重要：

- **防止浪费**：避免在错误的位置切割
- **精确对齐**：在预打印材料上定位设计
- **可重复的结果**：一致地多次运行相同的作业
- **多部件作业**：在单张材料上对齐多个部件

Rayforge 提供了几种互补的定位工具：

| 方法         | 用途         | 最适用于             |
| ------------ | ------------ | -------------------- |
| **对焦模式** | 查看激光位置 | 快速视觉对齐         |
| **边框预览** | 预览作业边界 | 验证设计是否适合材料 |
| **WCS 零点** | 设置坐标原点 | 可重复定位           |
| **相机叠加** | 视觉设计放置 | 在现有特征上精确对齐 |

## 对焦模式（激光指示器）

对焦模式以低功率级别开启激光，充当"激光指示器"，帮助您准确查看激光头所在的位置。

### 启用对焦模式

1. **连接到您的机器**
2. **点击工具栏中的对焦按钮**（激光图标）
3. 激光以配置的对焦功率级别开启
4. **移动激光头**以查看光束在材料上的位置
5. **完成后再次点击对焦按钮**以关闭

<!-- prettier-ignore-start -->
:::warning[安全警告]
即使在低功率下，激光也可能损伤眼睛。切勿直视光束或将其指向反射表面。佩戴适当的护目装备。
:::
<!-- prettier-ignore-end -->

### 配置对焦功率

对焦功率决定了激光点的亮度：

1. 转到 **设置 → 机器 → 激光**
2. 找到 **对焦功率** 设置
3. 设置一个使点可见但不会标记材料的值
   - 典型值：大多数材料为 1-5%
   - 设置为 0 以禁用该功能

<!-- prettier-ignore-start -->
:::tip[寻找合适的功率]
从 1% 开始并逐渐增加。点应该可见但不会在材料上留下任何痕迹。较暗的材料可能需要更高的功率才能清楚地看到点。
:::
<!-- prettier-ignore-end -->

### 何时使用对焦模式

- **快速对齐检查**：查看激光是否大致在您期望的位置
- **查找材料边缘**：移动到角落以验证材料放置
- **设置 WCS 原点**：在设置 WCS 之前将激光定位到所需的零点
- **验证原点位置**：检查归位是否正常工作

## 指示激光偏移

某些机器配有一个专用的指示激光（一个红色小点激光器），它与切割光束之间有固定距离。当您用指示光点对齐材料时，切割光束实际上会落在偏离该点的位置——除非 Rayforge 进行补偿。

激光设置[指示激光偏移](../machine/laser.md)让您可以输入该距离并开启或关闭补偿。启用后：

- **在当前位置设为工作原点**（以及 X 置零 / Y 置零）会将工作原点放在指示光点的位置。
- 画布会在红色光束点旁边显示一个黄色指示光点，标示指示光点在材料上的位置。
- 移动弹出框（位置读数旁边的指南针图标）中会出现一个**指示激光对齐**开关。

### 指示激光对齐

**指示激光对齐**开启后，每一项绝对定位操作——移动到、角落快捷方式、前往 WCS 原点、点击移动、移动激光头到此、边框预览——都会让_指示光点_落在目标位置上，因此您可以完全凭借可见光点来定位材料。弹出框中的坐标输入会预填指示光点的位置；对齐开启时，画布上的指示光点显示为实心，关闭时显示为空心。

该工作流程与通过指示光点置零完美配合：原点位于指示光点标记的位置，瞄准将每个目标偏移相应的偏移量，而加工本身不偏移——用光点对齐、用光束切割因此保持一致。

对齐开启时按**发送**，每次发送都会出现警告（没有“不再询问”选项）：任务以光束在 WCS 位置切割，永远不会偏移。您可以选择_关闭并加工_、_仍然加工_或取消。

点动移动和任务永远不会因该开关而偏移：点动是相对移动，而且无论对齐开关是否开启，G 代码输出都完全相同。该开关仅对当前会话有效——不会保存到机器配置文件中，切换机器时会重置。

指示激光偏移对超出激光床尺寸的材料（穿透式加工）尤其有用，此时您需要反复将设计对齐到移动材料上的参考标记。

## 边框预览

边框预览以低（或零）功率追踪作业的边界矩形，准确显示设计将被切割或雕刻的位置。

### 如何边框预览

1. **在 Rayforge 中加载并定位您的设计**
2. **点击 机器 → 边框** 或按 `Ctrl+F`
3. 激光头追踪作业的边界框
4. **验证轮廓**是否适合您的材料

### 边框设置

在 **设置 → 机器 → 激光** 中配置边框行为：

- **边框速度**：边框期间激光头移动的速度（较慢 = 更容易看到）
- **边框功率**：边框期间的激光功率
  - 设置为 0 进行空跑边框（激光关闭，仅移动）
  - 设置为 1-5% 在材料上留下可见痕迹

<!-- prettier-ignore-start -->
:::tip[空跑边框与低功率边框]
- **空跑边框（0% 功率）**：对任何材料都安全，但您只能看到头部移动
- **低功率边框**：留下微弱的可见痕迹，适用于在深色材料上精确对齐
:::
<!-- prettier-ignore-end -->

### 何时边框预览

- **每次作业前**：快速验证设计是否适合
- **位置更改后**：确认新位置正确
- **昂贵材料**：在执行前再次检查
- **多部件作业**：验证所有部件都适合材料

有关更多详细信息，请参阅 [作业边框预览](framing-your-job)。

## 设置 WCS 零点（工件坐标系）

工件坐标系（WCS）允许您为作业定义自定义"零点"。这使得将作业对齐到材料位置变得容易。

### 快速 WCS 设置

1. **移动激光头**到材料的角落（或所需的原点）
2. **打开控制面板**（`Ctrl+L`）
3. **选择一个 WCS**（G54 是默认的工件坐标系）
4. **点击 零点 X 和 零点 Y** 将当前位置设置为原点
5. 您的设计的 (0,0) 点现在将与该位置对齐

### 理解坐标系

Rayforge 使用多个坐标系：

| 系统        | 描述                       |
| ----------- | -------------------------- |
| **G53**     | 机器坐标（固定，无法更改） |
| **G54**     | 工件坐标系 1（默认）       |
| **G55-G59** | 附加工件坐标系             |

<!-- prettier-ignore-start -->
:::tip[多个工作区域]
为不同的夹具位置使用不同的 WCS 插槽。例如：

- G54 用于床的左侧
- G55 用于右侧
- G56 用于旋转附件
:::
<!-- prettier-ignore-end -->

### 何时设置 WCS 零点

- **新材料放置**：将原点对齐到材料角落
- **夹具工作**：将原点设置为夹具参考点
- **可重复作业**：相同的作业，不同的位置
- **生产运行**：多个工件的一致定位

有关完整文档，请参阅 [工件坐标系](../general-info/coordinate-systems.md)。

## 基于相机的定位

相机叠加显示材料的实时视图，您的设计叠加在上面，实现精确的视觉对齐。

### 设置相机

1. **在工作区域上方连接 USB 相机**
2. 转到 **设置 → 相机** 并添加您的相机设备
3. **启用相机**以在画布上查看叠加
4. **对齐相机**使用对齐程序（准确定位所需）

### 相机对齐

相机对齐将相机像素映射到现实世界坐标：

1. 打开 **相机 → 对齐相机**
2. 在已知位置放置对齐标记（至少 4 个点）
3. 输入每个点的现实世界 X/Y 坐标
4. 点击 **应用** 计算变换

<!-- prettier-ignore-start -->
:::tip[对齐精度]
- 使用分布在整个工作区域的点
- 用尺子仔细测量世界坐标
- 使用机器位置（移动到已知坐标）以获得最佳精度
:::
<!-- prettier-ignore-end -->

### 使用相机叠加定位

1. **启用相机叠加**以查看您的材料
2. **导入您的设计**
3. **拖动设计**以与相机中可见的特征对齐
4. **微调**使用箭头键进行像素级精确定位
5. **边框预览以验证**在运行作业之前

### 何时使用相机定位

- **预打印材料**：将切割对齐到现有打印
- **不规则材料**：在非矩形件上定位
- **精确放置**：亚毫米精度要求
- **复杂布局**：具有特定间距的多个元素

有关完整文档，请参阅 [相机集成](../machine/camera.md)。

## 推荐工作流程

### 基本定位工作流程

对于矩形材料上的简单作业：

1. **放置材料**在激光床上
2. **启用对焦模式**并移动以验证材料位置
3. **在材料角落设置 WCS 零点**
4. **在画布中定位您的设计**
5. **边框预览作业**以验证放置
6. **运行作业**

### 精确对齐工作流程

对于在预打印或标记材料上的精确放置：

1. **设置并对齐相机**（一次性设置）
2. **放置材料**在激光床上
3. **启用相机叠加**以查看材料
4. **在相机图像上视觉导入并定位设计**
5. **禁用相机**并边框预览以验证
6. **运行作业**

### 穿透式工作流程

对于比激光床更长的材料（分段穿过机器进给），**指示激光偏移**免去了手动计算：

1. 正常**切割设计的第 1 段**。
2. 将材料**向前进给**穿过穿透通道，使下一段位于激光床上。
3. **移动机器**，直到指示光点标记材料上的参考点（例如已切割特征的角）。
4. **设置 WCS 零点**（或 X 置零 / Y 置零）——启用指示激光偏移后，原点会正好落在指示光点指向的位置。
5. 在画布中**将设计的下一段**相对于该原点进行定位。
6. **边框预览验证**，然后**运行任务**。
7. 对其余每个段从第 2 步开始重复。

### 生产工作流程

用于运行多个相同的作业：

1. **在激光床上设置夹具**
2. **设置与夹具对齐的 WCS 零点**（例如 G54）
3. **加载并配置**您的设计
4. **边框预览以验证**与夹具的对齐
5. **运行作业**
6. **更换材料**并重复（WCS 保持不变）

### 多位置工作流程

用于在不同位置运行相同的作业：

1. **设置多个 WCS 位置**：
   - 移动到位置 1，设置 G54 零点
   - 移动到位置 2，设置 G55 零点
   - 移动到位置 3，设置 G56 零点
2. **加载您的设计**（所有位置使用相同的设计）
3. **选择 G54**，边框预览并运行
4. **选择 G55**，边框预览并运行
5. **选择 G56**，边框预览并运行

## 故障排除

### 对焦模式下激光点不可见

- **在激光设置中增加对焦功率**
- **深色材料**可能需要更高的功率（5-10%）
- **检查激光连接**并确保机器有响应
- **验证对焦功率**未设置为 0

### 相机叠加未对齐

- **使用更多参考点重新运行相机对齐**
- **检查相机安装** - 它可能已移动
- **验证世界坐标**是否准确测量
- **参阅相机故障排除**在相机集成文档中
