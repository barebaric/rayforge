# ऐड-ऑन

![ऐड-ऑन सेटिंग्स](/screenshots/app-settings-addons.webp)

ऐड-ऑन पृष्ठ इंस्टॉल किए गए एक्सटेंशन ऐड-ऑन दिखाता है और आपको उन्हें प्रबंधित करने देता है.

## अवलोकन

ऐड-ऑन एक्सटेंशन हैं जो Rayforge में कार्यक्षमता जोड़ते हैं. वे दे सकते हैं:

- नए ऑपरेशन
- आयात/निर्यात फ़िल्टर
- मशीन ड्राइवर
- UI संवर्द्धन
- सामग्री लाइब्रेरी

## इंस्टॉल किए गए ऐड-ऑन

ऐड-ऑन सूची सभी इंस्टॉल किए गए ऐड-ऑन इनके साथ दिखाती है:

- **नाम**: ऐड-ऑन का प्रदर्शन नाम
- **संस्करण**: वर्तमान इंस्टॉल संस्करण
- **विवरण**: कार्यक्षमता का संक्षिप्त विवरण
- **स्थिति**: सक्षम है या अक्षम

## ऐड-ऑन प्रबंधित करना

### ऐड-ऑन इंस्टॉल करना

1. **Install** बटन पर क्लिक करें
2. एक ऐड-ऑन फ़ाइल (`.zip` या ऐड-ऑन रिपॉज़िटरी) चुनें
3. इंस्टॉलेशन की पुष्टि करें
4. इंस्टॉलेशन पूरा होने की प्रतीक्षा करें

### ऐड-ऑन अपडेट करना

जब अपडेट उपलब्ध हों, तो ऐड-ऑन रजिस्ट्री संवाद में एक सूचक दिखाई देता है. उपलब्ध अपडेट इंस्टॉल करने
के लिए **Update** पर क्लिक करें.

### ऐड-ऑन हटाना

1. हटाने के लिए ऐड-ऑन चुनें
2. **Remove** बटन पर क्लिक करें
3. हटाने की पुष्टि करें

## ऐड-ऑन स्रोत

ऐड-ऑन से इंस्टॉल किए जा सकते हैं:

- **रिपॉज़िटरी**: ऐड-ऑन युक्त Git रिपॉज़िटरी
- **आधिकारिक रजिस्ट्री**: Rayforge टीम के चुने हुए ऐड-ऑन
