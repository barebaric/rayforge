# रेखाएँ मर्ज करें

जब आप ओवरलैपिंग पाथ वाला डिज़ाइन आयात करते हैं, तो लेज़र उसी रेखा को एक से अधिक बार काट सकता है.
इससे समय बर्बाद होता है, अत्यधिक झुलसन हो सकती है, और कर्फ़ आपके इरादे से अधिक चौड़ा हो सकता है.

**रेखाएँ मर्ज करें** पोस्ट-प्रोसेसर ओवरलैपिंग और संपाती पाथ खंडों का पता लगाता है और उन्हें एक एकल
पास में मर्ज कर देता है. लेज़र प्रत्येक अद्वितीय रेखा का पालन केवल एक बार करता है.

## कब उपयोग करें

यह सबसे अधिक तब आता है जब:

- आप ऐसा SVG या DXF आयात करते हैं जहाँ आकृतियाँ किनारे साझा करती हैं (उदाहरण के लिए, एक ग्रिड पैटर्न
  या टेसेलेशन)
- आप कई वर्कपीस जोड़ते हैं जिनकी आउटलाइन ओवरलैप करती है
- आपका डिज़ाइन सॉफ़्टवेयर डुप्लिकेट पाथ निर्यात करता है

## कब उपयोग न करें

यदि ओवरलैपिंग कट जानबूझकर हैं — उदाहरण के लिए, मोटी सामग्री काटने के लिए उसी रेखा पर कई पास करना —
तो रेखाएँ मर्ज करें अक्षम छोड़ दें. उस स्थिति में, आप इसके बजाय [मल्टी-पास](multi-pass) सुविधा उपयोग
करना चाह सकते हैं, जो पास की संख्या पर स्पष्ट नियंत्रण देती है.
