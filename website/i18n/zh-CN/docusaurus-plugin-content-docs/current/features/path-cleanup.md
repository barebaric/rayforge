# 清理路径

来自其他软件的标志和图纸并不总是干净的。轮廓可能在距起点不到一毫米的地方就停止了，一个形状可能由多段开放的片段组成，或者同一条路径在文件中出现了两次。Rayforge 会按原样切割这些路径：看起来闭合但实际未闭合的形状会被当作开放路径处理，重复的路径会被切割两次。

路径清理工具可以修复所选工件中的这些问题。您可以在**对象**菜单中，以及画布右键菜单的**清理路径**下找到它们。每个工具都是一个撤销步骤。

## 闭合路径

**闭合路径…**会闭合所有起点与终点距离小于您输入的公差的开放路径。缺口由两个现有点之间的一条直线连接，因此形状不会移动，也不会改变大小。

## 连接开放路径

**连接开放路径…**会把端点距离小于公差的开放路径连接成更长的路径。必要时会反转片段方向，因此片段的绘制顺序和方向都无关紧要。如果连接后的路径首尾相接，该路径也会被闭合。

两个工具都会在本次会话中记住您上次使用的公差。对大多数导入的文件来说，0.05 mm 到 0.2
mm 之间的公差即可。

## 删除重复项

**删除重复项**会删除与同一工件中另一条路径完全重合的路径，无论其方向或起点如何。如果您选择了多个工件，与另一个所选工件位置相同且完全相同的工件也会被删除。

只有部分长度重叠的路径会被保留。生成作业时，[合并线条](merge-lines)后处理器会处理这些路径。

## 打散

**打散**会把工件的每条路径都变成一个独立的工件，包括孔和开放路径。这与**分割**不同，分割会把一个岛与它的孔保留在一起。

路径清理只适用于导入和描摹得到的工件。来自草图的工件请在[草图编辑器](sketcher/index)中编辑。
