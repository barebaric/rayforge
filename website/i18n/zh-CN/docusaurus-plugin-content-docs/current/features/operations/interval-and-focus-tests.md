# 线间距与焦距测试

除了[材料测试网格](material-test-grid.md)，工具菜单还提供另外两种校准作业。三者的用法相同：**工具 → 创建 …** 会以默认设置在新图层上添加测试并选中它，其设置显示在右侧项目属性面板的 **Test Settings** 下。在那里的每次修改都会立即重建测试，并作为一个可撤销的步骤，因此你可以边调整边查看结果。测试是普通内容：你可以像其他内容一样移动、走边框和预览。每个单元格或每条线都有自己的操作，你也可以手动微调，但之后在 Test Settings 中的修改会重建这些操作。

## 线间距测试

**工具 → 创建线间距测试**会雕刻一排填充方块。每个方块都有自己的**雕刻**操作和自己的线间距，从你输入的最小值到最大值均匀分布，而所有方块的功率和速度都相同。每个方块下方的标签显示以毫米为单位的线间距，以及对应的每英寸线数（LPI）。

![线间距测试](/screenshots/interval-test.webp)

选择填充均匀、看不到线条且没有烧得过深的方块，在该材料上雕刻时使用它的线间距。标签会在方块之前用单独的低功率操作切割。

## 焦距测试

**工具 → 创建焦距测试**用于找到光束最锐利的高度。正偏移表示激光头与材料之间的距离更大。最细的线即为最佳焦点。

![焦距测试](/screenshots/focus-test.webp)

| 方法                   | 高度如何变化                                           |
| ---------------------- | ------------------------------------------------------ |
| **Z 轴步进**           | 激光头通过相对 Z 移动到达每个偏移，最后回到起始高度    |
| **手动（线之间暂停）** | 每条线之前作业暂停（`M0`）；你手动移动激光头后按“继续” |
| **斜坡（倾斜材料）**   | 一条带距离刻度的长线；你把平板条的一端垫高             |

Z 轴步进仅在具有 Z 轴的机器上提供；Z 轴步进和手动方法都需要 G-code 控制器，因为它们在线之间使用[命令](command.md)操作。偏移限制在起始高度的 ±10
mm 以内。新建的焦距测试会按上表的顺序，使用机器支持的第一种方法。

使用手动方法时，先像平常一样对焦激光。标签在该高度雕刻。第一次暂停时，把激光头调到起始偏移；之后每次暂停时移动一个步进。在依赖此方法之前，请确认你的控制器会在
`M0` 处停止，并且“继续”按钮可以继续作业，例如以 0% 功率空跑一次。

使用斜坡时，线上任一点下方的高度由板条的升高推算：在升高 _h_ 的板条上，沿长度为 _L_ 的线距离起点 _d_
处，材料比起点高 _h_ × _d_ / _L_。
