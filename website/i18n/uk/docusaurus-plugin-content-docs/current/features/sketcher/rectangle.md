# Прямокутник та прямокутник із заокругленими кутами

Ескізер пропонує два інструменти прямокутників, які використовують ті самі жести та
клавіші-модифікатори: інструмент **прямокутника** (`G+R`) та інструмент **прямокутника із
заокругленими кутами** (`G+O`).

![Прямокутник та прямокутник із заокругленими кутами](/screenshots/addons-sketcher-tool-rectangle.webp)

## Малювання прямокутників

Накресліть прямокутник, вказавши два протилежні кути, або натисніть у першому куті, перетягніть і
відпустіть у протилежному. Клавіші- модифікатори працюють однаково для обох інструментів:

- Утримуйте `Shift`, щоб розмістити прямокутник симетрично навколо початкової точки.
- Утримуйте `Ctrl`, щоб обмежити його до квадрата.

Кожен прямокутник автоматично створює **центральну точку**, обмежену до геометричного центру, тож до
середини фігури можна прив'язатися або задати її розмір.

Поки попередній перегляд активний, можна ввести точний розмір: рядок стану показує поля `W` та `H`
(плюс `R` для радіуса кутів прямокутників із заокругленими кутами). Введіть значення, натисніть
`Tab`, щоб переміщатися між полями, і `Enter`, щоб застосувати. Обидва інструменти приймають жест із
двома клацаннями та жест клацнути-і-перетягнути взаємозамінно; `Esc` скасовує перегляд.

Радіус кутів прямокутника із заокругленими кутами можна змінити й пізніше, редагуючи його обмеження
— кути повністю обмежені, тож радіус лишається регульованим.
