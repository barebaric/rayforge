## सिस्टम आवश्यकताएँ

| संसाधन     | इंस्टॉल   | अनुशंसित          |
|------------|-----------|-------------------|
| डिस्क स्थान| < 1 GB    | परियोजना अनुसार   |
| RAM        | 1 GB      | परियोजना अनुसार   |

वास्तविक डिस्क और मेमोरी आवश्यकताएँ परियोजना जटिलता पर निर्भर करती हैं. सरल परियोजनाओं को इंस्टॉल
फ़ुटप्रिंट से परे थोड़ा ही चाहिए होता है, जबकि जटिल परियोजनाएँ आसानी से 10 GB RAM या अधिक का उपभोग
कर सकती हैं और महत्वपूर्ण अतिरिक्त डिस्क स्थान चाहती हैं.

## Linux CPU आवश्यकता (x86-64-v2)

Linux पैकेज अपना NumPy साथ लाते हैं, जिसे x86-64-v2 निर्देश सेट स्तर (SSE4.2
और POPCNT) की आवश्यकता होती है. यह Snap, Flatpak और AppImage पैकेज के
साथ-साथ PyPI से pip इंस्टॉलेशन पर भी लागू होता है. पुराने x86-64 CPU
(Intel Core 2 या उससे पुराने, AMD Phenom या उससे पुराने) पर Rayforge
प्रारंभ नहीं होता, आमतौर पर बिना किसी त्रुटि संदेश के. Intel के Nehalem
(2008) और बाद के तथा AMD के Bulldozer (2011) और बाद के CPU x86-64-v2 का
समर्थन करते हैं.

जाँचने के लिए कि आपका CPU यह आवश्यकता पूरी करता है या नहीं, चलाएँ:

```bash
grep -m1 flags /proc/cpuinfo | grep -o -w -E 'sse4_2|popcnt' | sort -u
```

अगर कमांड दोनों फ़्लैग नहीं दिखाती, तो Rayforge को Ubuntu PPA से या अपने
डिस्ट्रीब्यूशन के पैकेज रिपॉज़िटरी से इंस्टॉल करें. ये संस्करण आपके
डिस्ट्रीब्यूशन के साथ आने वाले NumPy का उपयोग करते हैं, जो पुराने CPU पर
भी चलता है.
