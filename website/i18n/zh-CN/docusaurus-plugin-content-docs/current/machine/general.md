# 常规设置

机器设置中的"常规"页面包含机器名称、驱动程序选择和连接设置，以及速度参数。

![常规设置](/screenshots/machine-settings-general.webp)

## 机器名称

为你的机器起一个描述性的名称。当你配置了多台机器时，这有助于在机器选择下拉菜单中识别该机器。

## 驱动程序

选择与你的机器控制器匹配的驱动程序。驱动程序负责 Rayforge 与硬件之间的通信。

GRBL 设备可以通过 USB/串口或网络连接：

- **GRBL (USB/Serial)**
  — 带缓冲计数、死锁检测和 stall 恢复的驱动程序。其 GRBL 协议栈在 Rust 中运行。推荐用于大多数 GRBL 设备
- **GRBL (USB/Serial — compatibility mode)**
  — 乒乓协议驱动程序。发送一行，等待 "ok"，再发送下一行。无缓冲管理，无死锁检测。仅当标准驱动程序导致误报或通信错误时才需要
- **GRBL (Bluetooth)** — 用于操作系统中已配对控制器的蓝牙经典 SPP/RFCOMM 连接
- **grblHAL (Telnet)** — 原始 TCP/telnet 连接，适用于联网的 grblHAL 控制器以及 ESP3D 的 telnet 桥接
- **FluidNC / ESP3D (Web API)** — 用于 FluidNC 和 ESP3D
  v3 控制器的 HTTP/WebSocket 驱动程序，支持文件上传和设备设置

通过 Wi-Fi 连接的 xTool 机器使用它们自己的实验性驱动程序；D1/D1 Pro 和 M2 请参阅
[xTool Wi-Fi](xtool)。

基于 Ruida 的控制器由 **Ruida RPA** 驱动程序支持，它可以直接通过 USB 或 UDP 连接，或通过 TUI
RPC 经由 Ruida Protocol
Analyzer 连接。它的 USB 字段提供已连接设备的下拉列表（带 VID:PID 匹配），并遵循每个步骤的 Power
Mode 设置——Dynamic 启用控制器的功率缩放，Constant 将其禁用。功率行为通过驱动程序的 **Power
Scaling**、**VECTOR power floor** 和 **IMAGE power bias**
选项调节：功率缩放会在层的切割速度降低时提高发出的最小功率，矢量功率下限补偿线段端部的过烧，图像偏置则补偿在极低功率下不点火的 CO2 激光管。

### Epilog

带以太网端口的 Epilog 激光机（Zing 16、Zing 24/6030、Helix 18 和 Helix 24）使用 **Epilog Zing** 或
**Epilog Helix**
驱动。作业会编码为 Epilog 打印作业并上传
到机器的打印队列，请在激光机的作业列表中启动。该驱动需要 IP 地址、打印端口（默认 515）、打印队列名称（默认为空；仅在您的打印服务器需要时填写）、可选的作业名前缀、光栅分辨率
（Zing：100–1000 DPI；Helix：75–1200 DPI）和矢量频率（10–5000 Hz）。

打印协议不提供远程控制，因此 Rayforge 无法在这类机器上回零、点动、查询状态或移动激光头，对焦和吹气需
在激光机上设置。作业语言始终以左上角为原点，因此坐标原点固定为 **左上**。**发送**
会上传作业，**框选**
会上传关光束的轮廓作业，启动方式相同。速度会换算为机器的
百分比刻度：Rayforge 以 6000 mm/min 作为 100% 基准，因此 600
mm/min 即 10%。抖动和阈值雕刻以原生 1 位
光栅行发送；功率调制（灰度）雕刻使用机器的逐点功率模式。不支持旋转作业。

### 串口绑定

串口字段除了设备路径（例如 `/dev/ttyUSB0` 或 `COM3`）外，还接受 USB `VID:PID` 标识符，例如
`0403:6001`。当机器按 VID:PID 绑定时，在操作系统重新枚举 USB 设备后（例如重启后，或拔下并重新插入后），自动重连会跟随机器前往其新端口。你可以在
`lsusb` 输出（Linux）或设备管理器 → 硬件 ID（Windows）中找到设备的 VID:PID。

选择驱动程序后，选择器下方会出现特定于连接的设置（例如串口、波特率）。这些设置因所选驱动程序而异。

### 自定义波特率

波特率选择器列出了常见速率，但接受 300 到 4000000 比特/秒之间的任意值。在列表末尾选择
**自定义...**，然后输入固件使用的速率——例如 `500000`。已配置的自定义速率会保持显示在选择器中。

## 速度与加速度

这些设置控制最大速度和加速度，用于作业时间估算和路径优化。

### 最大空移速度

激光关闭且机头移动到新位置时，快速（非切割）移动的最大速度。

- **典型范围**：2000–5000 mm/min
- **注意**：实际速度还受固件设置的限制。如果所选 G-code 方言不支持指定空移速度，此字段将被禁用。

### 最大切割速度

切割或雕刻操作期间允许的最大速度。

- **典型范围**：500–2000 mm/min
- **注意**：个别操作可能会使用较低的速度

### 加速度

机器加速和减速的速率，用于时间估算和计算默认过扫描距离。

- **典型范围**：500–2000 mm/s²
- **注意**：必须与固件中的加速度设置一致或更低

<!-- prettier-ignore-start -->
:::tip
从保守的速度值开始，然后逐步增加。观察你的机器是否出现皮带跳齿、电机失步或定位精度下降的情况。
:::
<!-- prettier-ignore-end -->

## 导出机器配置

点击设置对话框标题栏中的分享图标，导出当前的机器配置。选择一个保存文件夹。系统将创建一个 ZIP 文件，其中包含机器设置及其 G-code 方言，可以分享给其他用户或在另一台系统上导入。
