# उपयोग ट्रैकिंग

Rayforge में वैकल्पिक गुमनाम उपयोग ट्रैकिंग शामिल है ताकि हमें समझने में मदद मिले कि एप्लिकेशन का
उपयोग कैसे होता है और भविष्य के विकास को प्राथमिकता कैसे दी जाए. यह पृष्ठ समझाता है कि हम क्या ट्रैक
करते हैं, यह कैसे काम करता है, और आपकी गोपनीयता.

## केवल ऑप्ट-इन

उपयोग ट्रैकिंग **पूरी तरह वैकल्पिक** है. जब आप पहली बार Rayforge शुरू करते हैं, तो आपसे पूछा जाएगा
कि क्या आप भाग लेना चाहते हैं:

- **हाँ**: गुमनाम उपयोग डेटा हमारे एनालिटिक्स सर्वर को भेजा जाएगा
- **नहीं**: कोई डेटा कभी एकत्र या प्रेषित नहीं होता

आप यह पसंद किसी भी समय सामान्य सेटिंग्स में बदल सकते हैं.

## हम क्या ट्रैक करते हैं

सक्षम होने पर, हम केवल गुमनाम पृष्ठ दृश्य डेटा एकत्र करते हैं - वेबसाइट एनालिटिक्स के समान. यहाँ वह
है जो हम देख सकते हैं:

| डेटा                | उदाहरण                     |
| ------------------- | -------------------------- |
| स्क्रीन रेज़ोल्यूशन | 1920x1080                  |
| मशीन प्रकार         | grbl, डायोड लेज़र, 430x400 |
| भाषा सेटिंग         | en-US                      |
| देखे गए पृष्ठ/संवाद | /machine-settings/general  |
| पृष्ठ पर बिताया समय | 6m 3s                      |
| सत्र ID             | a1b2c3d4-e5f6-...          |

सत्र ID एक यादृच्छिक पहचानकर्ता है जो हर बार Rayforge शुरू होने पर जनरेट होता है. यह हमें ट्रैकिंग
पूरी तरह गुमनाम रखते हुए भिन्न उपयोग सत्रों में अंतर करने देता है.

## हम क्या देखते हैं

एनालिटिक्स डैशबोर्ड कैसा दिखता है, इसका एक उदाहरण यहाँ है:

| पथ                        | आगंतुक | भेंट | दृश्य | बाउंस दर | भेंट अवधि |
| ------------------------- | ------ | ---- | ----- | -------- | --------- |
| /                         | 1      | 1    | 5     | 0%       | 27m 35s   |
| /machine-settings/general | 1      | 1    | 5     | 0%       | 27m 27s   |
| /view/3d                  | 1      | 1    | 2     | 0%       | 25m 14s   |
| /camera-alignment-dialog  | 1      | 1    | 2     | 0%       | 6m 3s     |
| /machine-settings/camera  | 1      | 1    | 2     | 0%       | 6m 16s    |
| /settings/general         | 1      | 1    | 2     | 0%       | 16m 36s   |
| /step-settings/rasterizer | 1      | 1    | 2     | 0%       | 11s       |

## हम क्या ट्रैक नहीं करते

हम आपकी गोपनीयता के प्रति प्रतिबद्ध हैं:

- **कोई व्यक्तिगत जानकारी नहीं** - कोई नाम, ईमेल, या खाते नहीं
- **कोई फ़ाइल सामग्री नहीं** - आपके डिज़ाइन और परियोजनाएँ निजी रहती हैं
- **कोई मशीन पहचानकर्ता नहीं** - कोई सीरियल नंबर या अद्वितीय ID नहीं
- **कोई IP पते संग्रहीत नहीं** - हम Umami एनालिटिक्स उपयोग करते हैं जो IP संग्रहीत नहीं करता
- **कोई क्रॉस-साइट ट्रैकिंग नहीं** - डेटा केवल Rayforge तक सीमित है

## हम क्यों ट्रैक करते हैं

उपयोग डेटा हमें मदद करता है:

- **लोकप्रिय सुविधाएँ पहचानें** - जानें कि क्या अच्छा काम कर रहा है
- **दर्द बिंदु खोजें** - देखें कि उपयोगकर्ता कहाँ समय बिताते या अटकते हैं
- **विकास को प्राथमिकता दें** - उन सुविधाओं पर ध्यान दें जिनका लोग वास्तव में उपयोग करते हैं
- **विविधता समझें** - जानें कि कौन सी भाषाएँ और स्क्रीन आकार समर्थित करने हैं

## यह कैसे काम करता है

Rayforge [Umami](https://umami.is/) उपयोग करता है, एक ओपन-सोर्स, गोपनीयता-केंद्रित एनालिटिक्स
प्लेटफ़ॉर्म. ट्रैकिंग:

- पृष्ठभूमि में छोटे HTTP अनुरोध भेजती है
- एप्लिकेशन प्रदर्शन को प्रभावित नहीं करती
- ऑफ़लाइन काम करती है (विफल अनुरोध चुपचाप अनदेखा किए जाते हैं)
- इसे आपके ऑपरेटिंग सिस्टम से मेल खाते ब्राउज़र-शैली User-Agent के साथ भेजती है

## ट्रैकिंग अक्षम करना

आप किसी भी समय ट्रैकिंग अक्षम कर सकते हैं:

1. **Settings** → **General** खोलें
2. **Send anonymous usage statistics** बंद करें

अक्षम होने पर, बिल्कुल कोई डेटा नहीं भेजा जाता.
