# कर्फ़ क्षतिपूर्ति

कर्फ़ कटिंग के दौरान लेज़र बीम द्वारा हटाई गई सामग्री है. कर्फ़ क्षतिपूर्ति इसकी गिनती में टूलपाथ
समायोजित करती है, यह सुनिश्चित करते हुए कि कटे हुए पार्ट अपनी डिज़ाइन विमाओं से मेल खाते हैं.

## कर्फ़ क्या है?

**कर्फ़** = कटिंग प्रक्रिया द्वारा हटाई गई सामग्री की चौड़ाई.

**उदाहरण:**

- लेज़र स्पॉट आकार: 0.2mm
- सामग्री संपर्क: प्रत्येक तरफ़ ~0.1mm जोड़ता है
- **कुल कर्फ़:** ~0.4mm

---

## कर्फ़ क्षतिपूर्ति कैसे काम करती है

कर्फ़ क्षतिपूर्ति सामग्री हटाने की गिनती में **टूलपाथ को भीतर या बाहर ऑफ़सेट** करती है:

**बाहरी कटों के लिए (एक पार्ट काटना):**

- पाथ को कर्फ़ चौड़ाई के आधे से **बाहर** ऑफ़सेट करें
- परिणाम: अंतिम पार्ट सही आकार का है

**भीतरी कटों के लिए (एक छेद काटना):**

- पाथ को कर्फ़ चौड़ाई के आधे से **भीतर** ऑफ़सेट करें
- परिणाम: अंतिम छेद सही आकार का है

**0.4mm कर्फ़ के साथ उदाहरण:**

```
Original path:  50mm square
Compensation:   Offset outward by 0.2mm (half kerf)
Laser follows:  50.4mm square
After cutting:  Part measures 50.0mm (perfect!)
```

---

## कर्फ़ मापना

**सटीक कर्फ़ मापन प्रक्रिया:**

1. **एक परीक्षण फ़ाइल बनाएँ:**
   - एक 50mm x 50mm वर्ग बनाएँ
   - एक वृत्त बनाएँ (कोई भी आकार, भीतरी कट परीक्षण के लिए)

2. **परीक्षण काटें:**
   - अपनी सामान्य कटिंग सेटिंग्स उपयोग करें
   - पूरी तरह काटकर गुज़रें
   - सामग्री को ठंडा होने दें

3. **मापें:**
   - **बाहरी वर्ग (पार्ट):** कैलिपर से मापें
     - यदि < 50mm, कर्फ़ बाहर हटाया गया
     - कर्फ़ = (50 - मापा गया) x 2
   - **भीतरी वृत्त (छेद):** व्यास मापें
     - यदि > डिज़ाइन व्यास, कर्फ़ भीतर हटाया गया
     - कर्फ़ = (मापा गया - डिज़ाइन) / 2

4. **औसत:** कई मापों का औसत उपयोग करें

**कर्फ़ को प्रभावित करने वाले चर:**

- लेज़र शक्ति (अधिक = चौड़ा)
- कटिंग गति (धीमी = चौड़ा)
- सामग्री प्रकार और घनत्व
- फ़ोकस दूरी
- एयर असिस्ट दबाव

## मैन्युअल कर्फ़ क्षतिपूर्ति

यदि स्वतः कर्फ़ क्षतिपूर्ति उपलब्ध नहीं है, तो अपने डिज़ाइन सॉफ़्टवेयर में क्षतिपूर्ति करें:

**Inkscape:**

1. **पाथ चुनें**
2. **Path → Dynamic Offset** (Ctrl+J)
3. अपनी कर्फ़ माप के आधे से **ऑफ़सेट के लिए खींचें**
   - पार्ट के लिए बाहर (पाथ बड़ा करने के लिए)
   - छेदों के लिए भीतर (पाथ छोटा करने के लिए)
4. अंतिम रूप देने के लिए **Path → Object to Path**

**Illustrator:**

1. **पाथ चुनें**
2. **Object → Path → Offset Path**
3. **ऑफ़सेट मान दर्ज करें:** (कर्फ़ / 2)
   - बाहर के लिए धनात्मक, भीतर के लिए ऋणात्मक
4. लागू करने के लिए **OK**

**Fusion 360 / CAD:**

- निर्यात से पहले स्केच एंटिटी ऑफ़सेट करें
- कर्फ़/ऑफ़सेट विमा उपयोग करें
