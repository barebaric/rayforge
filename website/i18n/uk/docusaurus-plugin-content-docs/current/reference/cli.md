# Командний рядок

Повне посилання на опції командного рядка.

```
rayforge [опції] [файли...]
```

---

## Позиційні аргументи

| Аргумент | Опис                            |
| -------- | ------------------------------- |
| `файли`  | SVG або зображення при запуску. |

---

## Опції

| Опція               | Опис                                       |
| ------------------- | ------------------------------------------ |
| `--version`         | Вивести версію та вийти.                   |
| `-h`, `--help`      | Показати довідку та вийти.                 |
| `--loglevel РІВЕНЬ` | Рівень журналу. За замовчуванням: `INFO`.  |
| `--config КАТАЛОГ`  | Кастомний каталог конфігурації.            |
| `--exit`            | Вийти після імпорту.                       |
| `--vector`          | Примусовий імпорт як прямих векторів.      |
| `--trace`           | Примусовий імпорт через трасування bitmap. |
| `--script СКРИПТ`   | Ранній скрипт запуску.                     |
| `--uiscript СКРИПТ` | Скрипт UI (після завантаження).            |

---

## Приклади

### Відкрити файл

```bash
rayforge мійпроект.ryp
```

### Відкрити кілька файлів

```bash
rayforge деталь1.svg logo.png дизайн.ryp
```

### Імпорт з трасуванням

```bash
rayforge --trace фото.png
```

### Запустити ранній скрипт і вийти

```bash
rayforge --exit --script реєстрація.py \
    мійпроект.ryp
```

### Скрипт UI (автоматизація)

```bash
rayforge --exit --uiscript скриншот.py \
    мійпроект.ryp
```

### Пакетна обробка

```bash
rayforge --exit --vector вхід.svg
```

## Ранні скрипти (`--script`)

Прапор `--script` запускає Python скрипт **синхронно під час
запуску**, до завантаження аддонів та до створення головного
вікна. Підходить для:

- Реєстрації плагінів з менеджером `pluggy`
- Налаштування контексту додатку
- Реєстрації функцій шаблонів для текстових полів
- Встановлення змінних середовища перед запуском

Скрипт має доступ до контексту через `get_context()`:

```python
from rayforge.context import get_context

ctx = get_context()
```

### Приклад: Реєстрація кастомної функції шаблону

```python
"""Реєстрація кастомної функції для шаблонів тексту.

Запуск: rayforge --script реєстрація_fn.py
"""
from sketcher.core.template_functions import (
    register_template_function,
)

register_template_function("мій_id", lambda: "ДЕТАЛЬ-001")
```

Тепер `{мій_id()}` працює в будь-якому текстовому полі.

Див.
[Кастомні функції шаблонів](../features/sketcher/expressions.md#custom-template-functions)
у документації скетчера для повного підручника.

## Скрипти UI (`--uiscript`)

Прапор `--uiscript` запускає Python скрипт **після повного
завантаження головного вікна**, у фоновому потоці. Підходить
для:

- Автоматизованого тестування UI
- Зняття скріншотів додатку
- Робочих процесів від початку до кінця

Скрипт може імпортувати додаток і вікно безпосередньо:

```python
from rayforge.uiscript import app, win
```

Скрипт працює у **фоновому потоці** — будь обережний з
потокобезпекою при доступі до віджетів GTK
(використовуй `GLib.idle_add` для операцій GTK).

### Приклад: Зняття скріншота

```python
"""Зняття скріншота головного вікна."""
from rayforge.uiscript import app, win

import gi
gi.require_version("Gtk", "4.0")
from gi.repository import GLib

def capture():
    surface = win.get_surface()
    if surface:
        surface.write_to_png("/tmp/rayforge_screenshot.png")
    return GLib.SOURCE_REMOVE

GLib.idle_add(capture)
```

## Використання обох прапорів

`--script` та `--uiscript` можна використовувати разом.
`--script` запускається першим (синхронно), потім
завантажується вікно, і потім запускається `--uiscript`:

```bash
rayforge --script раннє_налаштування.py \
    --uiscript автоматизація.py \
    мійпроект.ryp
```

Це корисно, коли тобі потрібно спочатку зареєструвати
плагіни, а потім керувати інтерфейсом пізніше.
