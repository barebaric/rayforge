# आयात और निर्यात

## ऑब्जेक्ट निर्यात करना

आप किसी भी चयनित वर्कपीस को विभिन्न वेक्टर फ़ॉर्मेट में निर्यात कर सकते हैं:

1. कैनवस पर एक वर्कपीस चुनें
2. **Object → Export Object...** चुनें (या राइट-क्लिक करके संदर्भ मेनू से चुनें)
3. निर्यात फ़ॉर्मेट चुनें:
   - **RFS (.rfs)**: Rayforge का नेटिव पैरामीट्रिक स्केच फ़ॉर्मेट - सभी कॉन्स्ट्रेंट सुरक्षित रखता
     है और संपादन के लिए पुनः आयात किया जा सकता है
   - **SVG (.svg)**: मानक वेक्टर फ़ॉर्मेट - डिज़ाइन सॉफ़्टवेयर के साथ व्यापक रूप से संगत
   - **DXF (.dxf)**: CAD इंटरचेंज फ़ॉर्मेट - अधिकांश CAD एप्लिकेशन के साथ संगत

## स्केच सहेजना

आप अपने 2D स्केच को अन्य परियोजनाओं में पुनः उपयोग के लिए फ़ाइलों में सहेज सकते हैं. सहेजते समय सभी
पैरामीट्रिक कॉन्स्ट्रेंट सुरक्षित रहते हैं, जिससे आपके डिज़ाइन अपने ज्यामितीय संबंध बनाए रखते हैं.

## स्केच आयात करना

सहेजे गए स्केच किसी भी कार्यक्षेत्र में आयात किए जा सकते हैं, जिससे आप सामान्य रूप से उपयोग होने
वाले डिज़ाइन तत्वों की एक लाइब्रेरी बना सकते हैं. आयात प्रक्रिया सभी कॉन्स्ट्रेंट और विमीय संबंध
बनाए रखती है.
