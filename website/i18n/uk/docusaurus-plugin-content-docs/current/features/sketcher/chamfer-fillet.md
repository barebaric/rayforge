# Фаска та скруглення

Ескізер надає два інструменти для модифікації кутів, у яких
зустрічаються дві лінії:

- **Фаска** (`C+H`): замінює гострий кут на зрізаний край.
- **Скруглення** (`C+F`): замінює гострий кут на заокруглений край.

![Прямокутник із фаскою поруч із прямокутником зі скругленням](/screenshots/addons-sketcher-tool-chamfer-fillet.webp)

Щоб застосувати один із них:

1. Виберіть точку з'єднання, де зустрічаються рівно дві лінії.
2. Натисніть `C+H` для фаски або `C+F` для скруглення, або виберіть
   інструмент у круговому меню.

Кут замінюється за один крок. Дві лінії вкорочуються, і між ними
вставляється новий край разом з обмеженнями, які утримують вкорочені
сегменти колінеарними з оригіналами, а кут — симетричним. У фаски
довжина зрізу типово становить частку коротшої з прилеглих ліній; у
скруглення радіус дуги підбирається так, щоб уміститися. Перетягування
кінцевих точок вставленого краю згодом змінює його розмір, причому
обмеження зберігають кут недоторканим.
