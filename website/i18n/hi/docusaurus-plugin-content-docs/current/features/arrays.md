# ऐरे

ऐरे सुविधा चयनित वर्कपीस की कई प्रतिलिपियाँ तीन भिन्न लेआउट मोड से बनाने देती है. प्रत्येक मोड एक
नॉन-मोडल संवाद खोलता है, इसलिए पैरामीटर समायोजित करते समय आप कैनवस के साथ बातचीत जारी रख सकते हैं —
पूर्वावलोकन वास्तविक समय में अपडेट होता है.

ऐरे संवाद खोलने के लिए, कैनवस पर एक या अधिक वर्कपीस चुनें, फिर टूलबार या राइट-क्लिक संदर्भ मेनू से
ऐरे मोड चुनें.

<!-- prettier-ignore-start -->
:::tip
सभी ऐरे मोड नॉन-मोडल हैं. संवाद खुला होने पर आप कैनवस पर आइटम खींच सकते हैं, और पूर्वावलोकन नई
स्थितियों को दर्शाने के लिए लाइव अपडेट होगा.
:::
<!-- prettier-ignore-end -->

## ग्रिड

ग्रिड मोड प्रतिलिपियों को पंक्तियों और कॉलम के आयताकार मैट्रिक्स में व्यवस्थित करता है, कॉन्फ़िगर
योग्य क्षैतिज और लंबवत स्पेसिंग के साथ.

![ग्रिड ऐरे](/screenshots/main-array-grid.webp)

### सेटिंग्स

| सेटिंग              | विवरण                                                                                                |
| ------------------- | ---------------------------------------------------------------------------------------------------- |
| **पंक्तियाँ**       | पंक्तियों की संख्या (1–360)                                                                          |
| **कॉलम**            | कॉलम की संख्या (1–360)                                                                               |
| **स्पेसिंग मोड**    | _अंतर_ (प्रतिलिपियों के बीच जगह) या _पिच_ (प्रत्येक प्रतिलिपि के किनारे-से-किनारे दूरी) में से चुनें |
| **कॉलम स्पेसिंग**   | कॉलमों के बीच क्षैतिज स्पेसिंग                                                                       |
| **पंक्ति स्पेसिंग** | पंक्तियों के बीच लंबवत स्पेसिंग                                                                      |

## पॉइंट रोटेशन

पॉइंट रोटेशन प्रतिलिपियों को चयन के अपने केंद्र के चारों ओर जगह पर घुमाकर बनाता है. यह वृत्तीय
पैटर्न बनाने के लिए उपयोगी है जहाँ प्रत्येक प्रतिलिपि मूल स्थिति पर रहती है लेकिन कुल कोण के अंश से
घूम जाती है.

![पॉइंट रोटेशन ऐरे](/screenshots/main-array-point-rotation.webp)

### सेटिंग्स

| सेटिंग            | विवरण                                                 |
| ----------------- | ----------------------------------------------------- |
| **गिनती**         | प्रतिलिपियों की संख्या (1–360)                        |
| **कुल कोण (deg)** | सभी प्रतिलिपियों का कुल कोणीय विस्तार (−360° से 360°) |

<!-- prettier-ignore-start -->
:::info
चूँकि घूर्णन चयन के अपने केंद्र के चारों ओर है, संवाद खुला रहने पर कैनवस पर वर्कपीस खींचने से
सभी प्रतिलिपियाँ साथ चलती हैं.
:::
<!-- prettier-ignore-end -->

## वृत्तीय

वृत्तीय मोड प्रतिलिपियों को एक केंद्र बिंदु के चारों ओर वृत्तीय चाप पर रखता है. कैनवस पर एक
क्रॉसहेयर मार्कर केंद्र दिखाता है, और संवाद खुला होने पर आप उसे नई स्थिति में खींच सकते हैं.

![वृत्तीय ऐरे](/screenshots/main-array-circular.webp)

### सेटिंग्स

| सेटिंग                  | विवरण                                                                             |
| ----------------------- | --------------------------------------------------------------------------------- |
| **गिनती**               | प्रतिलिपियों की संख्या (1–360)                                                    |
| **कुल कोण (deg)**       | चाप का कोणीय विस्तार (−360° से 360°)                                              |
| **केंद्र X**            | वृत्त केंद्र का X निर्देशांक                                                      |
| **केंद्र Y**            | वृत्त केंद्र का Y निर्देशांक                                                      |
| **त्रिज्या**            | वृत्तीय पाथ की त्रिज्या                                                           |
| **प्रतिलिपियाँ घुमाएँ** | सक्षम होने पर, प्रत्येक प्रतिलिपि चाप स्पर्श रेखा का पालन करने के लिए घूम जाती है |

<!-- prettier-ignore-start -->
:::tip[केंद्र खींचना]
कैनवस पर क्रॉसहेयर वृत्त केंद्र दर्शाता है. ऐरे को इंटरैक्टिव रूप से पुनः स्थित करने के लिए
उसे खींचें — संवाद के केंद्र X और केंद्र Y फ़ील्ड स्वतः अपडेट हो जाएँगे.
:::
<!-- prettier-ignore-end -->

<!-- prettier-ignore-start -->
:::tip[वर्कपीस खींचना]
आप कैनवस पर मूल वर्कपीस भी खींच सकते हैं. प्रतिलिपियों को केंद्र से उनकी वर्तमान दूरी पर रखने
के लिए त्रिज्या स्वतः अपडेट हो जाएगी.
:::
<!-- prettier-ignore-end -->
