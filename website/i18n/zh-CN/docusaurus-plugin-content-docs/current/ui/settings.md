# 设置

![常规设置](/screenshots/app-settings-general.webp)

自定义 Rayforge 以匹配您的工作流程和偏好。通过 **编辑 → 设置** 或按 <kbd>ctrl+comma</kbd>
打开设置对话框。

## 常规

常规页面包含应用程序范围设置。

### 外观

在**系统**、**浅色**或**深色**主题之间选择，以匹配您的桌面环境或个人偏好。您还可以配置**操作颜色**，使用激光颜色或图层颜色在画布上进行视觉区分。

### 单位

配置整个应用程序中使用的显示单位。您可以为**长度**（毫米、英寸等）、
**速度**（mm/min、mm/sec、inches/min 等）和**加速度**（mm/s² 等）分别设置单位。

### 行为

默认情况下，操作在每次更改后会自动重新计算。如果您在较慢的机器上工作或处理非常复杂的文档，可以禁用**自动更新操作**，改为通过工具栏按钮手动触发重新计算。

Rayforge 可以在启动时**自动检查更新**。启用后，当有新版本可用时会通知您。

您还可以配置**启动行为**
— 以空白工作区启动、重新打开上次的项目或始终打开特定的项目文件。请注意，命令行指定的文件将始终覆盖这些设置。

### 隐私

Rayforge 可以发送匿名使用数据以帮助改进应用程序。不会收集任何个人信息。您可以随时开启或关闭**报告匿名使用**。请参阅
[使用追踪](https://rayforge.org/docs/general-info/usage-tracking)页面，了解更多关于收集哪些数据以及如何使用这些数据的信息。

## 鼠标手势

鼠标手势页面允许您重新绑定 2D 画布、3D 画布和草图编辑器的导航手势。每个条目显示当前分配的鼠标按键组合。点击一个条目即可捕获新的绑定：按下所需的鼠标按键（可按住或不按住修饰键）或使用滚轮，绑定将立即生效。

- **平移视图** — 按住已绑定的鼠标键并移动鼠标进行平移。
- **缩放视图** — 使用鼠标滚轮进行缩放。
- **环绕 / 旋转（3D 画布）** — 拖动以环绕场景或绕 Z 轴旋转。
- **打开上下文菜单** — 2D 画布的上下文菜单或草图编辑器的工具菜单。
- **重置视图** — 重新适配视图。默认未绑定。

绑定可以通过**取消分配**移除，或通过**恢复默认**还原。如果手势已被同一视图中的其他操作使用，分配将被拒绝，因此鼠标按键组合绝不会同时触发两个操作。扩展可以提供额外的手势配置，这些配置将作为额外的分区显示在此页面上。
