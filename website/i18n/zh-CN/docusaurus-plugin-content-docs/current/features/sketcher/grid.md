# 网格

网格工具（`G+G`）创建均匀的构造线网格——行列整齐排列、间距相等的参考线，作为绘图脚手架使用，例如布置穿孔图案或对齐重复元素。

![一个 4x6 的构造网格](/screenshots/addons-sketcher-tool-grid.webp)

1. 从饼形菜单或 **草图** 菜单中选择网格工具，或按 `G+G`。
2. 对话框要求输入 **行** 和 **列** 的数量。
3. 确认后将在草图原点创建单元格为 10 mm 的网格。

网格由构造几何组成：它以虚线绘制，像其他任何几何图形一样作为捕捉和对齐参考，并在草图加工时被排除在刀具路径之外（参见
[构造几何](index.md#construction-geometry)）。单条线可以像其他几何图形一样移动或删除，选中它们并按
`G+N` 切换构造模式，即可把脚手架变成真实几何图形。
