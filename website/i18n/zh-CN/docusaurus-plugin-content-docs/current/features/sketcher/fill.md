# 填充区域

填充工具（`G+F`）用实心区域填充草图的闭合区域。填充对将要作为整体雕刻的区域非常有用。

![一个已填充的矩形](/screenshots/addons-sketcher-tool-fill.webp)

## 创建和移除填充

1. 绘制一个或多个闭合轮廓（例如使用[矩形](rectangle.md)或 [路径](path.md)工具）。
2. 从饼形菜单或 **草图** 菜单中选择填充工具，或按 `G+F`。
3. 点击闭合区域内的任意位置即可填充它。
4. 再次点击已填充的区域即可移除其填充。

在文本框内部点击会切换文字字形的填充，而不是创建区域填充。

## 填充颜色

新填充的填充颜色通过草图绘制器工具栏中的 **填充颜色**
按钮选择。现有填充会保持其颜色，直到被移除并重新创建。

与草图绘制器中的一切一样，填充与其边界绑定：调整周围几何图形的大小，填充会随之变化。
