# 弧与椭圆

草图绘制器提供两种曲线形状工具：用于圆弧的**弧工具**和用于椭圆与圆
的**椭圆工具**。

![由各自工具创建的弧和椭圆](/screenshots/addons-sketcher-tool-arc-ellipse.webp)

## 弧工具

弧工具（`G+A`）通过三次点击创建一条弧：

1. 点击**中心**点。
2. 点击**起点**——它到中心的距离决定半径。
3. 移动光标预览在两点之间扫过的弧，并点击**终点**位置。

预览处于活动状态时，你可以输入数字来精确固定半径；按 `Tab` 或
`Enter` 应用。输入前按 `Tab` 可切换磁性捕捉。

## 椭圆工具

椭圆工具（`G+C`）通过两次点击创建椭圆和圆：第一次确定中心，第二次
确定边缘点。你也可以在中心按下、拖动并在边缘释放——两种手势可以
互换使用。

- 按住 `Ctrl` 可将形状约束为正圆。
- 按住 `Shift` 可将起点用作椭圆的中心。

## 两次点击或拖动

与[矩形](rectangle.md)工具一样，椭圆工具也接受两种可互换的手势：
点击第一个点、移动、再点击第二个点，或在第一个点按下、拖动并在
第二个点释放。没有移动的快速点击只会预激活工具并等待第二个点，
因此误点击绝不会留下退化的几何图形。预览处于活动状态时，状态栏会
显示可用的修饰键，`Esc` 可取消预览。
