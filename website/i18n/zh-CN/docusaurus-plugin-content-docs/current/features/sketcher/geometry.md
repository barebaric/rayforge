# 创建 2D 几何图形

草图绘制器支持创建以下基本几何元素：

- **路径（直线和贝塞尔曲线）**：使用统一的路径工具绘制直线和平滑的
  贝塞尔曲线。点击放置点，拖动创建贝塞尔手柄。
- **圆弧**：通过指定中心点、起点和终点来绘制圆弧
- **椭圆**：通过定义中心点并拖动来设置大小和纵横比来创建椭圆（和圆）。
  拖动时按住 `Ctrl` 可约束为正圆。
- **矩形**：通过指定两个对角来绘制矩形。每个矩形自动创建一个中心点
  （约束到几何中心），以便您可以对其进行标注或捕捉。绘制时按住 `Shift`
  可围绕起点对称放置矩形，与椭圆工具类似。
- **圆角矩形**：绘制带圆角的矩形
- **文本框**：向草图中添加文本元素。文本内容支持参数化模板表达式（见
  [文本模板](../text.md)）。
- **填充**：填充闭合区域以创建实心区域

这些元素构成了 2D 设计的基础，可以组合创建复杂的形状。填充对于创建将作为
单个零件雕刻或切割的实心区域特别有用。

## 使用贝塞尔曲线

路径工具支持贝塞尔曲线，用于创建平滑的有机形状：

### 绘制贝塞尔曲线

1. 从饼形菜单中选择路径工具，或使用键盘快捷键
2. 点击放置点——每次点击创建一个新点
3. 点击后拖动以创建贝塞尔手柄，实现平滑曲线
4. 继续添加点以构建路径
5. 按 Escape 或双击以完成路径

### 编辑贝塞尔曲线

- **移动点**：点击并拖动任意点以重新定位
- **调整手柄**：拖动手柄端点以修改曲线形状
- **连接到现有点**：编辑路径时，可以捕捉到草图中的现有点
- **平滑/对称**：通过重合约束连接的点可以设为平滑（连续切线）或对称
  （镜像手柄）

### 将曲线转换为直线

使用**直线化工具**将贝塞尔曲线转换回直线。当您需要干净、简单的几何图形
时，这非常有用。选择要转换的贝塞尔段并应用直线化操作。
