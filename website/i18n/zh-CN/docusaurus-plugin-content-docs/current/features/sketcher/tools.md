# 草图绘制器工具

## 键盘快捷键

草图绘制器提供了高效的键盘快捷键：

### 工具快捷键

- `Space`：选择工具
- `G+P`：路径工具（直线和贝塞尔曲线）
- `G+A`：圆弧工具
- `G+C`：椭圆工具
- `G+R`：矩形工具
- `G+O`：圆角矩形工具
- `G+F`：区域填充工具
- `G+T`：文本框工具
- `G+Y`：圆形阵列工具
- `G+W`：沿曲线阵列工具
- `G+G`：网格工具（从选中内容创建副本网格）
- `G+N`：切换选中对象的构造模式

### 操作快捷键

- `O+F`：偏移所选轮廓
- `C+H`：添加倒角
- `C+F`：添加圆角
- `C+S`：将选中的贝塞尔曲线直线化为直线
- `M+V`：垂直镜像选中内容
- `M+H`：水平镜像选中内容
- `Ctrl+D`：原位复制选中内容

### 约束快捷键

- `H`：应用水平约束
- `V`：应用垂直约束
- `N`：应用垂直（正交）约束
- `T`：应用相切约束
- `E`：应用等长约束
- `O` 或 `C`：应用对齐约束（重合）
- `S`：应用对称约束
- `K+D`：应用距离约束
- `K+R`：应用半径约束
- `K+O`：应用直径约束
- `K+A`：应用角度约束
- `K+X`：应用纵横比约束

### 通用快捷键

- `Ctrl+Z`：撤销
- `Ctrl+Y` 或 `Ctrl+Shift+Z`：重做
- `Ctrl+D`：复制选中的元素
- `Delete`：删除选中的元素
- `方向键`：微调选中的实体（按住 `Shift` 以更大的步长移动）
- `Escape`：取消当前操作或取消选择
- `F`：适应视图至内容

## 镜像、复制和微调

多个变换工具作用于当前选中内容：

- **垂直/水平镜像**（`M+V` / `M+H`）：在原位沿选中内容边界框的中心进行镜像。
  跨越选中边界的约束会被移除；内部约束会被保留。
- **复制**（`Ctrl+D`）：原位复制选中内容。副本获得新的 ID 并重新映射内部约束；
  之后只有副本保持选中状态。撤销会移除它们。
- **微调**：选中实体后，**方向键**可移动选中内容。按住 `Shift` 以更大的步长
  移动。

这些工具可从工具栏和**草图**菜单中使用。

## 构造模式

构造模式允许您将实体标记为"构造几何"——用于指导设计的辅助元素，但不属于
最终输出的一部分。构造实体的显示方式不同（通常为虚线），在草图用于激光
切割或雕刻时不包含在内。

切换构造模式：

- 选择一个或多个实体
- 按 `N` 或 `G+N`，或在饼形菜单中使用构造选项

构造实体适用于：

- 创建参考线和参考圆
- 定义用于对齐的临时几何图形
- 从引导框架构建复杂形状

## 可见性控制

网格会适应缩放级别，并始终可作为尺寸参考；捕捉的工作方式在[草图
绘制器概述](index.md#grid-and-snapping)中描述。

草图绘制器工具栏包含用于控制可见性的切换按钮：

- **显示/隐藏构造几何**：切换构造实体的可见性
- **显示/隐藏约束**：切换约束标记的可见性

这些控件有助于在处理复杂草图时减少视觉杂乱。

### 创建时自动约束

许多绘图工具在创建几何图形时会自动应用约束。当捕捉参考线在绘图过程中
显示对齐时，路径工具会创建水平和垂直约束，这有助于从一开始就保持
草图整洁，而不是事后修补。

### 轴约束移动

拖动点或几何图形时，按住 `Shift` 可将移动限制到最近的轴（水平或垂直）。
这在调整时保持对齐非常有用。

## 轮廓偏移

偏移工具会按给定距离放大或缩小所选轮廓，或将开放路径扩展为槽形。选择构成
轮廓的实体（或双击选择相连的几何图形），然后按 `O+F`，或使用饼形菜单中的
**偏移** 项。

![轮廓偏移对话框](/screenshots/addons-sketcher-offset-dialog.webp)

对话框会询问偏移距离，并在输入时于画布上实时预览结果：

- **闭合轮廓**在距离为正时放大，为负时缩小。会导致轮廓塌缩的偏移会被拒绝。
- **开放路径**会变为给定宽度、两端呈圆弧的闭合槽形轮廓。

![贝塞尔轮廓](/screenshots/addons-sketcher-offset-before.webp)
![贝塞尔偏移为槽形](/screenshots/addons-sketcher-offset-after.webp)

偏移会用结果替换所选轮廓：

- 独立的圆、圆弧和椭圆会保留其实体类型并就地更新，因此仍像之前一样可编辑、
  可约束。
- 相连线段链（包括贝塞尔曲线）会被多边形实体替换。多边形作为整体编辑：
  拖动中心点可移动它，拖动手柄点可旋转或等比缩放它。

如果选择包含多个互不相连的轮廓，每个轮廓会在一步中独立偏移。

## 倒角和圆角

草图绘制器提供了修改几何图形角的工具：

- **倒角**：用斜边替换尖角。选择一个连接点（两条线相交处）并应用倒角
  操作。
- **圆角**：用圆弧边替换尖角。选择一个连接点（两条线相交处）并应用圆角
  操作。

使用倒角或圆角：

1. 选择两条线相交的连接点
2. 按 `C+H` 倒角或 `C+F` 圆角
3. 使用饼形菜单或键盘快捷键应用修改
