# xTool через Wi-Fi

Rayforge містить експериментальні драйвери для машин xTool, підключених через Wi-Fi. Вони
використовують пропрієтарний мережевий API xTool замість інтерфейсів GRBL Telnet чи FluidNC / ESP3D,
тому машину потрібно налаштувати з її власним драйвером xTool.

## Підтримувані машини

| Профіль          | Драйвер          | Що вміє                                                                                                                  |
| ---------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **xTool D1 Pro** | xTool (Wi-Fi)    | Завантажувати й запускати завдання, виконувати хоумінг, джог, паузу, продовження та скасування                           |
| **xTool M2**     | xTool M2 (Wi-Fi) | Спостерігати за машиною, виконувати хоумінг, джог і ставити на паузу, продовжувати або скасовувати підготовлене завдання |

Обидва драйвери позначені як **експериментальні**. Перевірте їх на обрізку матеріалу, перш ніж
покладатися на них у виробництві, і повідомляйте про проблеми з доданим журналом налагодження.

## Налаштування машини xTool

1. Підключіть машину до тієї ж мережі, що й комп'ютер, і дізнайтеся її IP-адресу (наприклад, у
   застосунку xTool або в списку пристроїв роутера).
2. Додайте машину й виберіть профіль **xTool D1 Pro** або **xTool M2**. Профіль уже налаштовує
   драйвер і розміри машини.
3. Введіть **Ім'я хоста або IP-адресу** машини.
4. Залиште порти типовими, якщо ваша мережа не вимагає іншого:
   - D1 Pro: HTTP-порт `8080`, WebSocket-порт `8081`
   - M2: порт `28900`
5. Підключіться.

Якщо Rayforge повідомляє, що жодна машина xTool не відповіла, перевірте IP-адресу, живлення машини
та те, що комп'ютер і машина в одній мережі.

## D1 і D1 Pro

Драйвер **xTool (Wi-Fi)** завантажує завдання на машину, запускає його й відстежує прогрес через
події завдання WebSocket. Хоумінг, джог і абсолютні переміщення, пауза, продовження та скасування
працюють як зазвичай.

Мережевий API машини не повідомляє позицію, тому Rayforge веде показ позиції за станом завдання.
Хоумінг доступний лише для всіх осей одразу; хоумінг окремих осей вимкнено. Запис налаштувань
прошивки, зміщення робочих координат і зондування цим драйвером не підтримуються.

## xTool M2

Драйвер **xTool M2 (Wi-Fi)** підключається до TLS-сервісу M2 на порту `28900`. Він стежить за станом
машини та підтримує хоумінг, джог, а також паузу, продовження або скасування завдання, уже
підготовленого на машині.

Мережевий API M2 ще не приймає G-code, тому Rayforge не може надсилати йому власні завдання.
Підготуйте завдання в xTool Studio, запустіть його там, а Rayforge використовуйте для спостереження
й керування. Переміщення Z, зміна інструмента, віддалене керування потужністю лазера, налаштування
прошивки та зміщення робочих координат не підтримуються.

## TLS-сертифікати

Драйвер M2 перевіряє TLS-сертифікат машини. Якщо машина використовує самопідписаний сертифікат,
увімкніть **Дозволяти недійсні TLS-сертифікати** в налаштуваннях драйвера. Робіть це лише в мережі,
якій довіряєте.
