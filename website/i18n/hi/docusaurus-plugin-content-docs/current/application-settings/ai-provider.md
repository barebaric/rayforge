# AI प्रदाता

![AI प्रदाता सेटिंग्स](/screenshots/app-settings-ai.webp)

AI प्रदाता कॉन्फ़िगर करें जिन्हें ऐड-ऑन Rayforge में बुद्धिमान सुविधाएँ जोड़ने के लिए उपयोग कर सकें.

## यह कैसे काम करता है

ऐड-ऑन अपनी API कुंजियों की आवश्यकता के बिना कॉन्फ़िगर AI प्रदाताओं का लाभ उठा सकते हैं. इससे आपका AI
कॉन्फ़िगरेशन केंद्रीकृत होता है और आप नियंत्रित करते हैं कि कौन से प्रदाता ऐड-ऑन को उपलब्ध हैं.

## प्रदाता जोड़ना

1. नई प्रदाता कॉन्फ़िगरेशन बनाने के लिए **Add Provider** पर क्लिक करें
2. इस प्रदाता की पहचान के लिए एक **नाम** दर्ज करें
3. **Base URL** को अपनी AI सेवा के API एंडपॉइंट पर सेट करें
4. प्रमाणीकरण के लिए अपनी **API कुंजी** दर्ज करें
5. इस प्रदाता के साथ उपयोग के लिए एक **डिफ़ॉल्ट मॉडल** निर्दिष्ट करें
6. अपनी कॉन्फ़िगरेशन काम करती है सत्यापित करने के लिए **Test** पर क्लिक करें

## प्रदाता प्रकार

### OpenAI संगत

यह प्रदाता प्रकार किसी भी सेवा के साथ काम करता है जो OpenAI API फ़ॉर्मेट उपयोग करती है. इसमें
विभिन्न क्लाउड प्रदाता और स्व-होस्टेड समाधान शामिल हैं.

डिफ़ॉल्ट बेस URL OpenAI के API पर सेट है, लेकिन आप इसे किसी भी संगत सेवा की ओर इंगित करने के लिए बदल
सकते हैं.

## प्रदाता प्रबंधित करना

- **सक्षम/अक्षम करें**: प्रदाता को हटाए बिना चालू/बंद टॉगल करें
- **डिफ़ॉल्ट के रूप में सेट करें**: किसी प्रदाता को डिफ़ॉल्ट बनाने के लिए चेक आइकन पर क्लिक करें
- **हटाएँ**: कोई प्रदाता जिसकी अब आवश्यकता नहीं उसे हटाएँ
