# 图像编辑

图像编辑插件可以在不改动导入文件的情况下更改工件图像的外观。每次编辑都与工件一起保存，因此您可以撤销它、稍后移除它，或者将同一文件以不同的编辑放置多次。

画布、3D 预览和每个操作都使用编辑后的图像。您在画布上看到的就是激光雕刻的内容。

## 反转图像

选择一个或多个工件，然后选择 **Tools - Invert
Image**。浅色区域变深，深色区域变浅；透明区域保持透明，因此背景仍然不会被雕刻。

![导入的灰度山湖照片](/images/image-edit-invert-before.webp)

![Invert Image 之后的同一张照片](/images/image-edit-invert-after.webp)

再次选择它即可取消反转。对于混合选择，尚未反转的工件会被反转，使整个选择最终保持一致。

在雕刻操作中将其用于石版画和浮雕（浅色区域应雕刻得较深），或者在深色背景上雕刻浅色图案。

## 调整图像

选择一个或多个工件，然后选择 **Tools - Adjust Image...**，在雕刻或描摹之前校正照片：

- **Brightness**（亮度）使图像变亮或变暗。
- **Contrast**（对比度）使色调远离或靠近中灰。
- **Gamma** 大于 1 时提亮中间调，小于 1 时压暗中间调；黑色和白色保持不变。
- **Sharpen**（锐化）增强边缘和细节（USM 锐化）。**Sharpen Radius**
  以毫米为单位设置这些细节的大小，因此无论行间距或缩放如何，结果都相同。

编辑时画布会实时显示更改。**Apply** 将其作为一个撤销步骤保留；不应用就关闭对话框会放弃更改，
**Reset** 将所有值恢复为中性。透明区域保持透明。

对话框打开时显示第一个所选工件的值，Apply 会为所有所选工件设置相同的值。锐化在色调校正之前进行，Invert
Image 等其他编辑保持原位。

## 旧项目

在此插件出现之前，反转是雕刻操作的一个设置。当您打开使用过该设置的旧项目时，Rayforge 会将该设置移动到该图层的工件上，因此输出保持不变。

## 插件被禁用时

当插件被禁用或未安装时，项目会保留其图像编辑。Rayforge 会提示项目使用了不可用的功能，并在插件重新启用之前显示未应用这些编辑的图像。
