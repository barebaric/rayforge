# 设置

![常规设置](/screenshots/app-settings-general.webp)

自定义 Rayforge 以匹配您的工作流程和偏好。通过 **编辑 → 设置** 或按 <kbd>ctrl+comma</kbd>
打开设置对话框。

## 常规

常规页面包含应用程序范围设置。

### 外观

在**系统**、**浅色**或**深色**主题之间选择，以匹配您的桌面环境或个人偏好。您还可以配置**操作颜色**，使用激光颜色或图层颜色在画布上进行视觉区分。

**车间模式**将底部面板的控制标签页替换为触控友好的操作界面：每轴大号位置读数与置零按钮、偏置卡片、超大点动速度/步长步进器，以及大按钮点动与作业网格。专为站在机器旁操作而设计，默认关闭。

### 单位

配置整个应用程序中使用的显示单位。您可以为**长度**（毫米、英寸等）、
**速度**（mm/min、mm/sec、inches/min 等）和**加速度**（mm/s² 等）分别设置单位。

### 行为

默认情况下，操作在每次更改后会自动重新计算。如果您在较慢的机器上工作或处理非常复杂的文档，可以禁用**自动更新操作**，改为通过工具栏按钮手动触发重新计算。

Rayforge 可以在启动时**自动检查更新**。启用后，当有新版本可用时会通知您。

在 Windows 上，**自动下载更新**会在后台下载新版本，以便通知中一键安装：Rayforge 将关闭、静默运行安装程序，然后以新版本重新启动。在其他平台上，通知会改为链接到版本下载页面。

Rayforge 还可以在启动时**自动检查扩展更新**。禁用此选项不会阻止在“扩展”页面中手动检查更新。

启用**监视导入文件**（Watch imported
files）后，Rayforge 会监视导入工件背后的文件，并在它们在磁盘上发生更改时提议重新加载。详情请参阅
[保持导入文件同步](../files/importing.md#保持导入文件同步)。

启用**任务期间防止睡眠**后，Rayforge 会在任务运行期间阻止系统自动睡眠，以免与机器的连接中断。手动挂起或合上盖子仍会生效。

您还可以配置**启动行为**
— 以空白工作区启动、重新打开上次的项目或始终打开特定的项目文件。请注意，命令行指定的文件将始终覆盖这些设置。

### 隐私

Rayforge 可以发送匿名使用数据以帮助改进应用程序。不会收集任何个人信息。您可以随时开启或关闭**报告匿名使用**。请参阅
[使用追踪](https://rayforge.org/docs/general-info/usage-tracking)页面，了解更多关于收集哪些数据以及如何使用这些数据的信息。

## 鼠标手势

![鼠标手势设置](/screenshots/app-settings-gestures.webp)

鼠标手势页面允许您重新绑定 2D 画布和 3D 画布的导航手势；草图编辑器使用与 2D 画布相同的手势。每行提供一个下拉菜单，列出可用的鼠标按键组合：

- **2D 画布** — _平移视图_（默认：中键拖动；左键拖动已保留给框选，因此不提供）。
- **3D 画布** — _环绕相机_（中键拖动）、_平移相机_（Shift + 中键拖动）和_绕 Z 轴旋转_（左键拖动）。

缩放（鼠标滚轮）、上下文菜单（右键）以及重置视图（2D 画布上的 `1`
键）是固定的，无法更改。对已绑定按键的普通点击仍会执行其固定操作：当平移绑定到鼠标右键时，按住右键拖动可平移视图，而普通右键点击仍会打开上下文菜单。选择**未绑定**将禁用手势，已被同一画布上其他操作使用的组合不会提供。扩展可以提供额外的手势配置，这些配置将作为额外的分区显示在此页面上。

## 其他设置

设置对话框还包含管理应用程序其他部分的页面。每个页面都有自己的专门文档：

- [机器](../application-settings/machines.md) — 添加、移除和配置您的激光切割机（也可以通过 **机器 →
  Manage Machines…** 访问）
- [材料](../application-settings/materials.md) — 管理您的材料库
- [配方](../application-settings/recipes.md) — 管理保存的操作配方
- [颜色规则](../application-settings/color-rules.md) — 将 SVG 颜色映射到步骤类型
- [AI 提供者](../application-settings/ai-provider.md) — 配置供扩展使用的 AI 提供者
- [扩展](../application-settings/addons.md) — 安装、更新和移除扩展
