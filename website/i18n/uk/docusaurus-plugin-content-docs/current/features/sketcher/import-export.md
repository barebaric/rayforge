# Імпорт та експорт

## Експорт об'єктів

Ви можете експортувати будь-яку вибрану заготовку в різні векторні формати:

1. Виберіть заготовку на полотні
2. Виберіть **Об'єкт → Експортувати об'єкт...** (або натисніть правою кнопкою миші та виберіть у
   контекстному меню)
3. Виберіть формат експорту:
   - **RFS (.rfs)**: Власний параметричний формат ескізів Rayforge — зберігає всі обмеження і може
     бути повторно імпортований для редагування
   - **SVG (.svg)**: Стандартний векторний формат — широко сумісний з програмами для дизайну
   - **DXF (.dxf)**: Формат обміну САПР — сумісний з більшістю програм САПР

## Збереження ескізів

Ви можете зберігати свої 2D-ескізи у файли для повторного використання в інших проектах. Усі
параметричні обмеження зберігаються під час збереження, гарантую- чи, що ваші проекти збережуть свої
геометричні зв'язки.

## Імпорт ескізів

Збережені ескізи можна імпортувати в будь-який робочий простір, що дозволяє створювати бібліотеку
часто використовуваних елементів дизайну. Процес імпорту зберігає всі обмеження та розмірні зв'язки.
