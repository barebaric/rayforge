# 阵列

草图绘制器提供两种阵列工具来创建参数化阵列：**圆形阵列**和**沿曲线阵列**。

## 圆形阵列

**圆形阵列**工具（`G+Y`）从当前选中内容创建参数化极坐标图案：

1. 选择要阵列的实体。
2. 从工具栏、**草图 → 阵列**菜单或 `G+Y` 激活工具。
3. 画布上出现引导圆，并打开一个非模态对话框，带有实时预览。
4. 设置**数量**和**总角度**。副本围绕引导圆的中心参数化生成。
5. 拖动引导圆的中心以重新定位阵列，或拖动原始实体以更改半径——
   对话框字段会实时更新。
6. 引导圆的**半径尺寸**可调整整个阵列的大小。**双击**引导圆可重新打开
   编辑对话框并重新生成缺失的或重新分配成员。

副本是无求解器约束的静态烘焙几何图形：编辑阵列时会从模板重新生成。
删除成员只会移除该成员的几何图形，绝不会重新分配剩余成员。

## 沿曲线阵列

**沿曲线阵列**工具将一个或多个实体的副本沿引导路径（直线、圆弧或贝塞尔
曲线）分布。副本直接放置在路径上，并跟随其在每个位置的切线方向。

### 创建沿曲线阵列

1. 绘制要分布的形状（种子）和要跟随的引导路径。
2. 选择两者：首先点击**引导路径**，然后按住 Shift 点击**种子实体**。
3. 从工具栏、**草图 → 阵列**菜单或 `G+W` 激活工具。
4. 打开非模态对话框，显示沿路径分布的副本的实时预览。
5. 调整**数量**（包括路径起始处模板在内的总成员数）或设置**间距**值，
   以便从路径长度自动推导出数量。
6. 可选启用**与切线对齐**，使每个副本旋转以跟随其位置处的路径方向。
7. 使用**从起点偏移**来跳过路径的前导部分，然后再放置第一个副本。

### 编辑沿曲线阵列

- **双击**引导路径（或点击工具栏中的**编辑**）以重新打开对话框并
  更改数量、间距、偏移或对齐设置。
- 拖动引导路径的任何端点以重塑它。释放时，所有副本会自动沿新的
  路径几何图形重新分布——包括启用*与切线对齐*时的旋转更新。
- 种子形状可以像任何其他草图几何图形一样编辑；更改会在下次更新时
  传播到所有副本。

### 工作原理

副本是静态烘焙几何图形——它们不通过求解器约束链接到模板。当编辑引导
路径时，`sync_arrays` 检测更改并使用当前路径几何图形从头开始
重新生成所有副本。这保持更新快速并避免求解器开销。

模板（插槽 0）放置在路径起始处。其位置和方向会在编辑路径时自动更新。
创建阵列时会删除原始种子实体；撤销会恢复它们。
