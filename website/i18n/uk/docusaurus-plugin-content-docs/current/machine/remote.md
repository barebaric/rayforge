# Віддалені пристрої

Керуйте машиною з невеликого комп'ютера біля обладнання (наприклад, Raspberry Pi у майстерні), поки
Rayforge працює на вашому ноутбуці чи настільному комп'ютері. Завдання виконуються на хості пристрою
й тривають, навіть якщо Rayforge відключається; повторне підключення точно синхронізує прогрес.

## Як це працює

- **Демон raydriver** обслуговує з'єднання з машиною біля обладнання.
- Rayforge зберігає конфігурацію вашої машини та надсилає завдання через LAN.
- Кожен драйвер G-code (GRBL serial, GRBL telnet, GRBL simple, Smoothie, Marlin) працює локально або
  віддалено — віддалений режим це налаштування з'єднання, а не окремий драйвер.

## Налаштування хоста пристрою

1. Встановіть raydriver на хості пристрою: `pip install raydriver` (додайте `[daemon]` для виявлення
   в мережі).
2. Виконайте `raydriver daemon --setup`. Це записує `~/.config/raydriver/daemon.json` зі
   згенерованим токеном і виводить команду для сертифіката.
3. Для доступу через LAN створіть сертифікат за виведеною командою `openssl` і задайте `tls_cert` та
   `tls_key` у конфігурації. Демон на адресі, що не є loopback, не запускається без токена й TLS.
4. Запустіть `raydriver daemon` або працюйте з ним як зі службою systemd (приклад юніта є в
   документації raydriver).

## Підключення Rayforge

- Майстер машин виявляє демони в мережі та перелічує їхні пристрої.
- Або увімкніть **Віддалений пристрій** у налаштуваннях з'єднання драйвера й введіть ім'я хоста,
  порт, токен і TLS-сертифікат демона.
- Зондування працює через віддалене з'єднання, тож майстер може визначити обладнання, яке не
  підключене до вашого комп'ютера.

## Завдання та повторні підключення

- Надіслане завдання виконується до завершення на хості пристрою, навіть якщо Rayforge закрито або
  мережа зникла.
- Підключіться знову, щоб бачити точний прогрес. Керування утримує один клієнт за раз; інші можуть
  спостерігати.

## Камери на хості пристрою

Відео не передається через канал керування. Використовуйте [мережеві камери](camera.md) Rayforge з
потоком, доступним на хості пристрою:

- **IP-камера**: додайте її URL потоку безпосередньо.
- **USB-камера на хості пристрою**: запустіть стандартний стример, як-от `ustreamer`, і додайте його
  MJPEG URL як камеру HTTP-потоку.

Демон оголошує налаштовані кінцеві точки камер, щоб майстер міг попередньо заповнити URL.

## Примітки безпеки

- Лише LAN (або тунель) — без хмари, без облікових записів.
- Токен і TLS обов'язкові для будь-якого демона, що не є loopback.
- Тримайте потоки камер лише в LAN або за фаєрволом; вони відокремлені від каналу керування TLS.
