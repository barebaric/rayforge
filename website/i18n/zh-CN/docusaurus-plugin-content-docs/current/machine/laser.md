# 激光设置

机器设置中的激光页面配置您的激光头及其属性。

![激光设置](/screenshots/machine-settings-laser.webp)

## 激光头

Rayforge 支持具有多个激光头的机器。每个激光头都有自己的配置。

### 添加激光头

点击 **添加激光** 按钮创建新的激光头配置。

### 激光头属性

每个激光头具有以下设置：

#### 名称

此激光头的描述性名称。

示例：

- "10W 二极管"
- "CO2 管"
- "红外激光"

#### 工具编号

此激光头的工具索引。在 G 代码中与 T 命令一起使用。

- 单头机器：使用 0
- 多头机器：分配唯一编号（0、1、2 等）

#### 最大功率

激光的最大功率值。

- **GRBL 典型**：1000（S0-S1000 范围）
- **某些控制器**：255（S0-S255 范围）
- **百分比模式**：100（S0-S100 范围）

此值应与您的固件 $30 设置匹配。

#### 框选功率

用于框选操作的功率级别（描绘轮廓而不切割）。

- 设置为 0 以禁用框选
- 根据您的激光和材料调整

#### 框选速度

激光头在框选过程中移动的速度。此设置针对每个激光头单独配置，因此如果您的机器配备多个不同特性的激光器，可以为每个激光器选择合适的速度。较慢的速度使框选路径更容易用肉眼追踪。

#### 对焦功率

启用对焦模式时使用的功率级别。对焦模式以低功率开启激光，作为"激光指示器"用于定位。

- 设置为 0 以禁用对焦模式功能
- 用于视觉对齐和定位

<!-- prettier-ignore-start -->
:::tip[使用对焦模式]
点击工具栏中的对焦按钮（激光图标）以切换对焦模式。激光将在此功率级别下开启，帮助您准确查看激光的位置。有关更多信息，请参阅[工件定位](../features/workpiece-positioning.md)。
:::
<!-- prettier-ignore-end -->

#### 光斑大小

聚焦激光束的物理大小，以毫米为单位。

- 输入 X 和 Y 尺寸
- 大多数激光具有圆形光斑（例如，0.1 x 0.1）
- 影响雕刻质量计算

<!-- prettier-ignore-start -->
:::tip[测量光斑大小]
要测量光斑大小：

1. 在测试材料上以低功率发射短脉冲
2. 用卡尺测量产生的标记
3. 使用多次测量的平均值
:::
<!-- prettier-ignore-end -->

#### 颜色

用于在画布和 3D 预览中显示此激光操作（切割和雕刻）的颜色。这有助于在使用多个激光头时直观地区分哪个激光将执行哪个操作。

- 点击颜色样本打开颜色选择器
- 选择与材料预览对比度好的颜色
- 默认颜色自动分配

<!-- prettier-ignore-start -->
:::tip[多激光工作流程]
使用多个激光头时，为每个激光分配不同的颜色可以轻松查看哪些操作将由哪个激光执行。例如，主切割激光使用红色，次级雕刻激光使用蓝色。
:::
<!-- prettier-ignore-end -->

#### 激光类型

从下拉菜单中选择激光头的类型：

- **二极管**：标准二极管激光器（业余机器中最常见）
- **CO2**：CO2 管激光器
- **光纤**：光纤激光器

选择 CO2 或光纤时，会显示额外的
**PWM 设置**（见下文）。对于二极管激光器，PWM 部分会隐藏，因为不适用。

激光类型还会在下方未输入显式值时设置默认**波长**（供物理灼烧模型使用）。

#### 波长（nm）

您激光的发射波长，以纳米为单位。它为 3D 预览中的[物理灼烧模型](../ui/3d-preview.md#physical-burn-model)提供数据：与材料的[吸收率](../application-settings/materials.md#absorption)数据一起，它决定了毛坯吸收多少激光能量。

设置为 0 时，Rayforge 回退到所选激光类型的典型波长（例如二极管为 445 nm，光纤为 1064
nm，CO2 为 10600 nm）。

#### 最大光学功率（W）

激光全功率时的光学输出功率，以瓦为单位。这是实际的光输出，而非电输入。与光斑大小和扫描速度一起，它决定了[物理灼烧模型](../ui/3d-preview.md#physical-burn-model)
使用的注量（J/cm²）。

设置为 0 时，使用中端桌面默认值。

#### PWM 设置

选择 CO2 或光纤激光类型时，会出现以下 PWM 控件：

- **PWM 频率**：此激光头的默认 PWM 频率（Hz）。典型值范围从 500
  Hz 到数千 Hz，具体取决于您的控制器和电源。
- **最大 PWM 频率**：频率设置的上限。防止输入硬件无法处理的值。
- **脉冲宽度**：默认脉冲宽度（微秒）。控制每个周期中脉冲开启的时间长度。
- **最小/最大脉冲宽度**：脉冲宽度设置的边界。

这些默认值会传递到您的操作步骤中，如有需要可在每个步骤中覆盖。

#### 指示激光偏移

如果您的机器配有一个独立的指示激光（一个红色小点激光器），它与切割光束之间有固定距离，您可以将该距离告诉 Rayforge，让它进行补偿。

- **启用指示激光偏移**：开启补偿。默认关闭。
- **指示激光偏移 X / Y**：沿机器 X 轴和 Y 轴方向，从切割光束光斑到指示光点的距离（毫米）。

启用后有三点变化：

1. **在当前位置设为工作原点**（以及“X 置零 /
   Y 置零”按钮）会将工作原点放在_指示光点_标记材料的位置，而不是（不可见的）切割光束所在的位置。
2. 画布会在红色光束点旁边显示一个黄色指示光点，标示指示光点在材料上的位置。
3. 移动弹出框中将提供一个**指示激光对齐**开关（见下文）。

#### 指示激光对齐

指示激光对齐是移动弹出框（位置读数旁边的指南针图标）中的一个运行时开关。开启后，所有绝对定位操作——移动到、角落快捷方式、前往 WCS 原点、点击移动、移动激光头到此、边框预览——都会偏移，使 _指示光点_落在目标位置上。对齐开启时，画布上的指示光点显示为实心；关闭时显示为空心。

典型工作流程：

1. 移动机器，直到指示光点标记材料上的参考点。
2. 在那里**设置工作零点**——启用指示激光偏移后，原点会正好落在指示光点指向的位置。
3. 在移动弹出框中开启**指示激光对齐**。
4. 用指示光点进行边框预览和移动：您瞄准的一切都由指示激光标记。
5. 按**发送**时，警告会提醒您任务将以光束在 WCS 位置进行加工——您可以选择关闭对齐并加工、仍然加工，或取消。

有两样东西永远不会偏移：**手动点动**（相对移动无需补偿）和**任务**——切割始终以光束在 WCS 位置进行，因此无论对齐开关是否开启，G 代码输出都完全相同。与通过指示光点置零配合使用时，一切保持一致：原点位于
`光束 + 偏移` 处，瞄准将每个目标偏移 `-偏移`，而加工本身不偏移。

指示激光对齐是会话级设置：它不会保存到机器配置文件中，切换机器时会重置。

<!-- prettier-ignore-start -->
:::tip[测量偏移量]
1. 移动机器，直到指示光点标记材料上一个可见的点。
2. 开启对焦模式并移动，直到*切割光束*在完全相同的位置烧出标记（或在焦点功率下小心地将光束移到
   那里）。
3. 偏移量等于指示光点位置减去光束位置。例如，如果指示光点标记在 X=100，而您需要将光束移动到
   X=88 才能命中同一点，请输入 X = 12.0——指示光点位于光束前方 12 mm 处。

如果试切结果有偏移，请将相应轴的符号取反。
:::
<!-- prettier-ignore-end -->

<!-- prettier-ignore-start -->
:::note[旋转模式]
旋转附件启用时，Y 轴会被旋转滚轮取代，因此指示激光偏移的 Y 分量不再适用。旋转任务请将其设为 0。
:::
<!-- prettier-ignore-end -->

#### 3D 模型

每个激光头可以分配一个 3D 模型。此模型在 [3D 视图](../ui/3d-preview.md)
中渲染，并在仿真过程中沿刀具路径移动。

点击模型选择行以浏览可用模型。选择模型后，您可以调整其比例、旋转（X/Y/Z）和焦距以匹配您的物理激光头。
