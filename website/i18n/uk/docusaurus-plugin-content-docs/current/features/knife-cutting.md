# Різання ножем

Rayforge може керувати не лише лазерами, а й тримачами ножів. Два вбудовані кроки ріжуть векторні
контури ножем: **Різання драг-ножем** для тримача з вільною кромкою та **Різання тангенціальним
ножем** для моторного поворотного леза. Кроки ножа з'являються лише на машинах із відповідною
головкою ножа, тож одна машина може поєднувати лазерні операції та різання ножем в одному проєкті.

## Вимоги

- Машина з головкою **Драг-ніж** або **Тангенціальний ніж**. Додайте головку в
  [Налаштування машини → Головки](../machine/general.md) через **Додати головку**.
- G-code-контролер, здатний рухати машину без лазера. Кроки ножа ріжуть по осьовій лінії та не
  використовують потужність лазера.
- Вбудований додаток Drag Knife. Він постачається з Rayforge; якщо його вимкнено, увімкніть його в
  **Налаштування → Додатки**.

## Налаштування головки ножа

1. Відкрийте **Машина → Поточні налаштування машини → Головки**.
2. Натисніть **Додати головку** і виберіть **Драг-ніж** або **Тангенціальний ніж**.
3. Дайте головці назву. Для драг-ножа вкажіть **Зміщення леза**: відстань між кінчиком леза та
   точкою повороту машини.
4. Закрийте налаштування. Тепер відповідні кроки ножа пропонуються під час додавання операції.

Головка ножа також є можливістю машини: операції, яким потрібен ніж, доступні лише тоді, коли
активна машина має таку головку.

## Різання драг-ножем

У драг-ножа лезо йде позаду точки повороту. Rayforge автоматично компенсує зміщення, щоб лезо йшло
по контуру, а не за точкою повороту.

1. Виберіть контури для різання.
2. Додайте операцію **Різання драг-ножем**.
3. Виберіть головку **Ніж** і задайте **Зміщення леза**, **Безпечну висоту Z**, **Кут повороту** та
   швидкість різання.

![Налаштування різання драг-ножем](/screenshots/step-settings-drag-knife-general.webp)

Крок переписує кожен контур у шлях, яким має рухатися машина: вхідна дуга вирівнює лезо за першим
напрямком різання, прямі сегменти зсуваються вперед на зміщення леза, кути в межах кута повороту
обходяться з опущеним лезом, гостріші кути піднімають лезо для повороту в повітрі, а вихідна дуга
прорізає далі за кінець шляху.

Задайте **Зміщення леза** за документацією тримача або виміряйте його. Замале значення залишає
заокруглені кути; завелике - перевищує їх. **Кут повороту** обмежує, наскільки лезо повертається
опущеним; гостріші кути спершу піднімають ніж, щоб лезо не тяглося боком.

## Різання тангенціальним ножем

У тангенціального ножа є мотор, який повертає лезо, щоб воно весь час було дотичним до шляху. Крок
додає напрямок шляху як значення осі **A** до кожного руху різання, щоб контролер міг повертати
лезо.

1. Виберіть контури для різання.
2. Додайте операцію **Різання тангенціальним ножем**.
3. Виберіть головку **Ніж** і задайте **Допуск кута**, **Допуск радіуса**, **Оберти шпинделя**,
   **Безпечну висоту Z** та швидкість різання.

![Налаштування різання тангенціальним ножем](/screenshots/step-settings-tangential-knife-general.webp)

Зміни напрямку, більші за **Допуск кута**, або дуги, тісніші за **Допуск радіуса**, піднімають ніж
на безпечну Z, повертають його й знову опускають. Менші зміни повертають лезо на місці з опущеним
ножем. **Оберти шпинделя** видаються як команда M3 для мотора леза; Rayforge ніколи не використовує
M4, бо мотор леза обертається лише за годинниковою стрілкою.

## Поради

- Спершу виконуйте завдання на зниженій швидкості, особливо на товстому чи волокнистому матеріалі.
- Використовуйте підкладку для різання або малу глибину, щоб лезо не дряпало стіл.
- Кроки ножа - це звичайні G-code-операції: їх можна поєднувати з лазерними кроками, змінювати
  порядок, дублювати та зберігати в рецептах, як будь-яку іншу операцію.
