# 创建 2D 几何图形

草图绘制器支持创建以下基本几何元素：

- **路径（直线和贝塞尔曲线）**：使用统一的路径工具绘制直线和平滑的
  贝塞尔曲线。点击放置点，拖动创建贝塞尔手柄。
- **圆弧**：通过指定中心点、起点和终点来绘制圆弧
- **椭圆**：通过两次点击创建椭圆（和圆）：第一次点击设定中心点，第二次
  点击设定边缘点。也可以在中心点按下、拖动并在边缘点释放——两种手势可以
  互换使用。按住 `Ctrl` 可约束为正圆，按住 `Shift` 可将起点用作椭圆的
  中心。
- **矩形**：通过指定两个对角来绘制矩形，也可以在第一个角按下、拖动并在
  对角释放。每个矩形自动创建一个中心点（约束到几何中心），以便您可以
  对其进行标注或捕捉。绘制时按住 `Shift` 可围绕起点对称放置矩形，按住
  `Ctrl` 可约束为正方形。
- **圆角矩形**：使用与矩形工具相同的手势和修饰键绘制带圆角的矩形：
  两次点击或按住拖动，`Shift` 围绕起点对称放置，`Ctrl` 约束为正方形。
  圆角半径可以通过输入尺寸来设置（`0-9`，字段 W、H、R）。
- **文本框**：向草图中添加文本元素。文本内容支持参数化模板表达式（见
  [表达式](expressions.md#template-expressions-in-text-boxes)）。
- **填充**：填充闭合区域以创建实心区域

这些元素构成了 2D 设计的基础，可以组合创建复杂的形状。填充对于创建将作为
单个零件雕刻或切割的实心区域特别有用。

## 两次点击或拖动

形状创建工具（椭圆、矩形、圆角矩形）支持两种可互换的手势：点击第一个点、
移动后点击第二个点，或者在第一个点按下、拖动并在第二个点释放。没有移动的
快速点击只会让工具保持待命并等待第二个点，因此误点不会留下退化的几何图形。
预览激活时，状态栏会显示可用的修饰键，按 `Esc` 可取消预览。

## 使用贝塞尔曲线

路径工具支持贝塞尔曲线，用于创建平滑的有机形状：

### 绘制贝塞尔曲线

1. 从饼形菜单中选择路径工具，或使用键盘快捷键
2. 点击放置点——每次点击创建一个新点
3. 点击后拖动以创建贝塞尔手柄，实现平滑曲线
4. 继续添加点以构建路径
5. 按 Escape 或双击以完成路径

### 编辑贝塞尔曲线

- **移动点**：点击并拖动任意点以重新定位
- **调整手柄**：拖动手柄端点以修改曲线形状
- **连接到现有点**：编辑路径时，可以捕捉到草图中的现有点
- **平滑/对称**：通过重合约束连接的点可以设为平滑（连续切线）或对称
  （镜像手柄）

### 将曲线转换为直线

使用**直线化工具**将贝塞尔曲线转换回直线。当您需要干净、简单的几何图形
时，这非常有用。选择要转换的贝塞尔段并应用直线化操作。
